# 07. デザイン素材集（スライド用パーツ集テンプレート）

スライド作成時にコピーして使う装飾パーツ・図解部品の詰め合わせ。テキスト情報は少なく、大半はビジュアル素材（図形）のカタログ。

## 収録パーツ一覧

| スライド | パーツ | 用途 |
|---|---|---|
| 2 | 数字（Point1/2/3、No.1/2/3 など各種スタイル） | ポイント列挙・順位表示の番号バッジ |
| 3 | 数字・日付（01/02/03、POINT 01、2022、5/25、曜日など） | セクション番号・日付表示のバリエーション |
| 4 | ランキング（第1位〜第3位、王冠・メダル風、「SNS運用担当者が選ぶ No.1」訴求枠） | 実績・受賞・調査結果の訴求 |
| 5 | 背景に使える図形（ドットパターン等） | 表紙・セクション扉の装飾 |
| 6 | デバイスモックアップ（画面に画像を挿入して使用） | プロダクト画面の見せ方 |
| 7 | 枠付きテキスト | 見出し・ラベルの装飾枠 |
| 8 | 吹き出し | 顧客の声・コメント表示 |
| 9 | 記号 | チェック・矢印などのアイコン的記号 |
| 10-12 | 線・矢印 | フロー・因果関係・遷移の表現 |
| 13-15 | 見出しとテキスト（3パターン） | 「見出し＋本文」ブロックのレイアウト各種（枠あり / ▍縦棒見出し / カード型） |
| 16 | 箇条書き・その他 | 階層付き箇条書き（マーカー自動調整） |

## 使い方のポイント

- 数字・ランキングパーツは「業界最多」「No.1」など実績訴求スライドで使用
- 見出し＋テキストブロックは、▍（縦棒）付き見出しやカード型など複数スタイルから資料のトーンに合わせて選ぶ
- 吹き出しはお客様の声・社員の声スライドで使用
- 線・矢印パーツはBefore→After、フロー図、ロジックツリーの接続に使用
