## テンプレート全体に共通する設計パターン

資料作成時に踏襲すべき共通ルール:

1. **1スライド＝1メッセージ**
   スライド上部に「スライドメッセージ」を1〜2行で置く。理想は50〜60文字以内で、明確な主張を含める。
2. **英語のセクションラベル＋日本語見出し**
   例: `Product | ABCエージェントとは？`、`Flow | 導入までの流れ`、`Mission & Vision / ミッション・ビジョン`。
3. **数字を大きく見せる**
   実績・効果は「導入企業5,000社」「顧客満足度96.8%」のように数字を主役にする。
4. **Before → After / ご利用前 → ご利用後 の対比表**
   課題と解決を左右対比で見せる。
5. **表で構造化**
   サマリー（現状の問題／原因／解決策／費用／期待効果／実行計画）、競合比較、課題×優先度×担当、施策×数値目標×担当など。
6. **強調はメリハリ**
   重要箇所のみ目立たせる。何でも強調すると逆に伝わらない。
7. **フッター**
   ページ番号＋コピーライト（例: `©ABC Company ,inc.All Right Reserved.` / `© 2025 Company Name. All Right Reserved.`）。
8. **目次（INDEX / CONTENTS）** を表紙直後に置く。
