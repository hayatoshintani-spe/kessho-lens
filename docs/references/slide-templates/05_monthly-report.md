# 05. 月次報告資料（マーケティング月次レポート テンプレート）

架空の「2024年11月 マーケティング月次報告」（プログラミングスクール事業）を題材にした、月次報告資料のテンプレート。

## 資料構成（ストーリーライン）

1. 表紙（作成者・作成日時・CONFIDENTIAL）
2. 目次（INDEX 01〜10）
3. エグゼクティブサマリー（KPI表＋ポイント＋最重要課題＋来月の重点施策）

8. 来月の方針・アクションプラン（戦略の大枠＋具体施策×数値目標×担当）

## 特徴的なパターン

- **エグゼクティブサマリーで結論を最初に**（KPI達成状況→課題→来月施策）
- KPIは必ず「目標・実績・達成率・前月比・コメント（要因）」をセットで示す
- 施策評価は ◯△× で一目で分かるように
- 【結果】【要因】【対策】、【課題】【強み】のような**隅付き括弧ラベル**で情報を構造化
- 課題には必ず「担当者」を割り当てる
- 数値目標は「現在値→目標値」の形式で書く（例: CPA -15%（30,000円→25,500円））

## スライド 11：方針アップデート

**メッセージ:** 安易な値下げではなく"高付加価値"で勝負し、広告費も含めた全体のコスト構造を見直すことで、持続的かつ高収益な体制を築く

- **現状の方針:** 転職コースのPR（成功事例・講師実績をSNS/LPで紹介）/ 広告チャンネル分散 / オウンドメディア強化（SEO）
- **市場動向:** IT人材不足で市場拡大の一方、大手の大規模出稿でCPC急上昇。低価格プラン・転職保証・後払いが増え価格競争が激化
- **競合動向:** スクールA=インフルエンサー・マス広告でブランド認知を急拡大、"転職保証"が強み / スクールB=料金後払いで転職層を吸収、SNSで転職実績を拡散
- **自社分析:** 【強み】講師の専門性・コミュニティ支援の質が高くNPS上昇中【課題】高付加価値コース（転職コース）の認知不足、客単価が伸び悩む
- **修正後の方針:** 高単価コース周知強化（数字・事例で「値段以上の価値」を明示）/ 広告費最適化（高騰KW除外、動画広告へ再配分、オウンド週3→週5更新）/ コミュニティをPR素材化し"安売り"路線を回避
