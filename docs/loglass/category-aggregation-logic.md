# カテゴリ別実績集計ロジック定義（叩き台）

ログラス側のMTGメモ（2026-08-13）に埋め込まれた質問（※印）が実質的な質問リストなので、それを軸に整理する。

## 前提（2026-08-13 MTGでの合意）

- 実績は原則 **ラベル／タグ区分** でLoglassに取り込む（論点②）
- Loglassは固定比率・基準勘定の按分は可能、**実額指定の振替は不可**。実額が必要な箇所は「配賦率を計算科目で算出→固定比率配賦」または「調整仕訳投入」で対応
- ダッシュボード軸: 全社／事業セグメント別（ライセンス・MD・映像イベント・グローバルマーケティング）／地域別（国内・中国・アジア・その他）／差異要因分析／KPI

## ログラスからの質問事項（MTGメモの※印より）— 回答すべきリスト

### 1. ライセンス・カテゴリ別（国内）: 広告、食品、オンライン、ファッション、書籍、その他
> ※TPC開示用作業_2027.03期-2.xlsx や総勘定元帳にも区分が見当たらなかったため、実施する場合は区分の仕方をご教示ください

- **要回答**: カテゴリ区分がどの帳票・マスタに存在するか（契約管理台帳？ 案件管理？）。存在しない場合、区分を新設するか、このカテゴリ軸を見送るかの判断

### 2. MD・チャネル別: イベント物販、EC、一般流通、その他
> ※おそらく物販のデータが他に存在するかと思いますので、データ連携いただいた上、区分の方法をご教示ください

- **要回答**: 物販の実績データソース（販売管理システム／ECモールレポート等）の特定と連携可否

### 3. カード事業のSKU別
> ※カード元帳のセグメントで判断でしょうか

- **要回答**: カード元帳のセグメント項目で判定可能かの確認（なおSKU別のダッシュボード出力自体は不要と決定済み。取込粒度の論点としてのみ残る）

### 4. 映像/イベント: ライブ、番組販売、IMAGI-NATION、Blu-ray DVD等、その他調整
> ※おそらく元帳以外のデータが他に存在するかと思いますので、データ連携いただいた上、区分の方法をご教示ください

- **要回答**: 興行・番販等の実績データソース（イベント収支管理等）の特定と連携可否

### 5. 地域別・中国の中分類: トイ＆ホビー／ライフスタイル／パブリッシング／FMCG／カードゲーム／その他（ゲーム・広告）
> ※海外ローデータの中分類を元に区分していると認識していますが、齟齬があればご教示ください

- **要回答**: 認識の正誤確認のみ（海外ローデータの中分類でOKか）

## 各カテゴリで確定させる項目（テンプレート）

1. **集計元データ**: 総勘定元帳／販売管理／案件・契約管理／海外ローデータ 等
2. **判定キー**: 部門コード／セグメント／勘定科目／取引先／商品区分（または組合せ）
3. **付与タイミング**: 起票時に付与済みか、月次で後付け割り振りか
4. **按分の有無**: 複数カテゴリに跨がる取引の按分ルール（固定比率か、計算科目による実額比率か）
5. **「その他」の定義**: タグなし＝その他か、能動的に付与か
6. **例外処理**: 判定キー欠損データの扱い

## 実績振替の具体例（論点②で確認済みのパターン）

- 流通営業部の売上高: NX_店舗RYの金額を「店舗RY」へ、残りを「物販」へ
  - 現状ロジック: 流通営業部物販売上高 ＝ 流通営業部売上高 − 流通営業部店舗RY
  - Loglass上は「NX_店舗RYを取込み、計算科目で配賦率（店舗RY/売上高）を算出→固定比率配賦」で再現可能
- 新規開拓営業部（国内／海外）、ライセンス営業部（国内）等も同様のパターン
