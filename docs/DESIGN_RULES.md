# 資料デザインルール

社内資料(スライド・レポート類)を作成する際の共通デザインルール。
参照元テンプレート: emocri 製 PowerPoint テンプレート一式
(02 サービス紹介 / 03 提案書 / 04 会社説明 / 05 月次報告 / 07 デザインパーツ集)。

今後 AI・人間を問わず資料をアウトプットする場合は、本ルールに従うこと。

---

## 1. 基本原則

1. **1スライド1メッセージ** — 各スライドの冒頭に「結論を言い切る文」をメッセージとして置く。体言止めの見出しではなく、「〜である。」「〜が急務。」のような主張文にする。
2. **モノトーン+1アクセント** — 白背景・濃グレー文字を基調とし、テーマカラー1色(+補助1色)だけで強調する。多色使いはしない。
3. **キーワードだけ色で強調** — メッセージ文中の重要語句のみアクセント色(または色付き下線マーカー)にする。文全体を色付けしない。
4. **数字で語る** — 実績・効果は大きな数字(スタットカード)で見せる。数字は欧文フォントで大きく、単位(%・万・円)は小さく添える。
5. **構造の反復** — 全スライドで同じヘッダー・フッター構造を守り、資料全体をひとつのシステムとして見せる。

---

## 2. キャンバスと共通構造

- **スライドサイズ**: 16:9(13.333 × 7.5 インチ / 33.87 × 19.05 cm)
- **余白**: 左右 0.5 インチ以上。本文ブロック間は 0.3〜0.5 インチ。

### 各スライドの共通レイアウト

| 要素 | 位置 | 仕様 |
|---|---|---|
| セクション番号 | 左上 (約 x=0.45in, y=0.4in) | 丸囲み数字 01〜、16pt |
| セクション名 | 番号の右 (約 x=0.9in) | 18pt 太字(例: 現状分析、解決策・打ち手) |
| ロゴ | 右上 | 小さく配置 |
| スライドメッセージ | 上部 (y≈0.9〜1.2in)、幅ほぼ全面 | 20〜24pt 太字、1〜2行の結論文。キーワードをアクセント色に |
| 本文エリア | メッセージの下 | 図解・表・チャート中心 |
| コピーライト | 左下または右下 | `© 20XX Company Name. All Right Reserved.` 9pt グレー |
| ページ番号 | 右下 | 14pt |

### 定型スライド

- **表紙**: 細枠で全面を囲む、またはアクセント色ベタ。タイトル大(36〜54pt 太字)、作成者・作成日、必要に応じ `CONFIDENTIAL` 表記。
- **目次 (INDEX / CONTENTS)**: 丸囲み番号 01〜 + 項目名の2列リスト。
- **結び**: アクセント色全面の CTA スライド(お問い合わせ先・採用サイト等)。白文字+白カードで連絡先を並べる。

---

## 3. タイポグラフィ

- **日本語**: 游ゴシック (Yu Gothic)。強調は太字または Yu Gothic Medium。
- **欧文・数字**: Arial(数字強調は Arial 太字。英字ラベルは Segoe UI Semibold も可)。
- 真っ黒 `#000000` は使わず、本文は濃グレー(`#333333`〜`#404040`)。

| 用途 | サイズ | 太さ |
|---|---|---|
| 表紙タイトル | 36〜54pt | 太字 |
| スライドメッセージ(結論文) | 20〜24pt | 太字 |
| セクション見出し(ヘッダー) | 18pt | 太字 |
| カード見出し・小見出し | 14〜16pt | 太字 |
| 本文 | 14pt(高密度な報告書は 12pt) | 標準 |
| 補足・注釈・出典 | 9〜11pt | 標準・グレー |
| スタット数字(実績・KPI) | 28〜40pt(表紙級は 60pt 超も可) | Arial 太字 |
| 英字キャッチ(セクションの英語ラベル) | 10〜12pt | 細め・アクセント色またはグレー |

## 4. カラー

### 共通ニュートラル

| 役割 | 色 |
|---|---|
| 背景 | `#FFFFFF` |
| 本文テキスト | `#333333` / `#404040` |
| 罫線・薄背景 | `#E8E8E8` |
| 濃色ブロック(表の行ラベル・比較表ヘッダー) | `#333333` |

### 資料タイプ別アクセント

| 資料タイプ | メイン | 補助・強調 | トーン |
|---|---|---|---|
| サービス紹介 | 緑 `#16A085` | 橙 `#F39C12`(数字ハイライト) | 明るく信頼感 |
| 提案書 | 青 `#0399D8` | 桃 `#F76892`(注意・対比) | クリーンで論理的 |
| 会社説明 | 青 `#1457D9` | 明青 `#017AFE` | ビビッドで先進的 |
| 月次報告・分析 | 濃グレー `#333333` 基調 | ポジ: 青 `#0172DB` / 淡青 `#97C6F7`<br>ネガ: 赤 `#E51F08` / 淡赤 `#F3A39C` | 高密度・実務的 |

- 色はスライドマスターの「テーマの色」に設定し、配色変更だけでテーマを切り替えられる作りにする。
- 報告書系では**青=良い/改善、赤=悪い/課題**のセマンティクスを厳守する。
- 淡色(`#97C6F7` 等)は塗り背景・帯・マーカーに、濃色は文字・線・強調に使う。

## 5. スライドパターン集

用途に応じて以下の型を使う(毎スライド同じ型を繰り返さない)。

| パターン | 使いどころ | 作り方 |
|---|---|---|
| 課題提起3カード | 冒頭の「こんなお悩みありませんか?」 | アクセント色カード3枚+丸囲み番号、下に解決宣言の帯 |
| サービス概要図 | 仕組み・関係図 | 円(登場人物)+矢印+中央に自社サービス |
| スタットカード | 実績・KPI | カード3枚横並び。上部に色帯タイトル、中央に大きな数字(28〜40pt Arial)+単位小さく、下に補足 |
| 掛け算・数式図 | 提供価値の整理 | `Point 01 × Point 02 = 成果` を図式化。結果は円形バッジで強調 |
| Before/After 棒 | 効果試算 | 濃グレー(Before)→アクセント色(After)の2本棒+増減率を大きく |
| 競合比較表 | 優位性 | 自社列のみアクセント色ヘッダー+セル色付け。他社はグレー |
| ○×△比較表 | 定性比較 | 記号: ○=良い / △=一部 / ×=不可。列ごとに評価 |
| 導入フロー | ステップ説明 | 左に番号 01〜04 の帯付き行、右に説明。番号はアクセント色 |
| FAQ | よくある質問 | `Q.` をアクセント色にした枠カードを 2×2 配置 |
| 料金カード | プラン提示 | 大きな金額+補足。キャンペーン等はバッジで添える |
| グラフ+洞察 | 現状分析 | グラフは左右どちらか、洞察テキストを対に置く |
| ガントチャート | スケジュール | 月グリッド+アクセント色バー |
| 体制図 | 組織・チーム | 色帯ヘッダーのボックス+メンバー列挙 |
| サマリー表 | 論点整理・再掲 | 左端に濃色(#333)の行ラベル列、右に内容。冒頭と末尾で同じ表を再掲すると効果的 |
| 写真+メッセージ | 声・CEOメッセージ | 半面写真+白カードにメッセージ。引用は大きめ太字で冒頭に |

### チャートのルール

- 棒グラフ: 過去・比較対象は**グレー**、注目期間・自社は**アクセント色**で塗り分ける。
- データラベルを直接表示し、補足は角丸四角の吹き出しで添える。
- 凡例は最小限。軸ラベル・目盛りはグレー小さめ。出典・注記は下部に 9〜10pt グレー。
- 円・ドーナツはアクセント色の濃淡グラデーションで構成する。

## 6. デザインパーツ(07 パーツ集より)

- **番号**: 丸囲み数字(白抜き/塗り)、`No.1`、`Point 01`、日付バッジ。塗りはアクセント色か濃グレー。
- **ランキング**: 王冠・メダル・月桂樹(金 1位 / 銀 2位 / 銅 3位)。
- **枠付きテキスト**: 角丸・角型・楕円。塗り(白文字)か枠線(色文字)の2系統。
- **吹き出し**: 補足・注意の挿入に。控えめな線または塗り。
- **記号**: ✓(可)・×(不可)・△(一部)・○(良)・!(注意)。丸囲みまたは単体。
- **矢印**: シェブロン(》)、実線矢印、手描き風矢印。進行方向・成長表現に。
- **見出しブロック**: 見出しを「色文字」「左縦棒付き」「下線付き」「色帯」のいずれかで統一し、本文と組み合わせる。
- **箇条書き**: 第1階層 `●` 太字可、第2階層 `-`(ハイフン)小さめ。マーカー強調(色帯ハイライト)も可。
- **デバイスモックアップ**: PC・スマホ枠に画面画像をはめてプロダクトを見せる。

---

## 7. 禁止・注意事項

- 多色使い(3色以上のアクセント)をしない。
- 文章だけのスライドを作らない — 図解・表・カードに構造化する。
- 本文の中央揃えをしない(タイトル・カード内を除く)。左揃え基本。
- 真っ黒 `#000000` の文字・原色ベタは使わない。
- メッセージ行なしで本文を始めない。
- 表・グラフで自社/注目対象を強調しないまま並列に見せない。
- フォントを游ゴシック+Arial 以外に増やさない。
- スライドごとに構造(ヘッダー・フッター位置)を変えない。

---

## 8. スライド以外の資料への適用

HTML レポート・ダッシュボード・ドキュメント類にも同じ設計思想を適用する:

- 白背景+濃グレー文字+資料タイプに応じたアクセント1色。
- 見出しは「結論を言い切る文」をメッセージファーストで。
- 数字は大きく(スタットカード)、ポジ=青/ネガ=赤のセマンティクス。
- 表は左ラベル列を濃色、罫線は `#E8E8E8` の薄グレー。
- 日本語は游ゴシック系(Yu Gothic / Noto Sans JP 代替可)、数字は Arial 系。
