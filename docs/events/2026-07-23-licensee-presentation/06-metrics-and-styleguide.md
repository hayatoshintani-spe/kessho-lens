# 06. “100万人”の再定義・スタイルガイド/監修フローの見せ方

---

## Part A:“100万人”の見せ方

### 原則

100万人を**マスリーチの数字として見せてはいけない**。
ソフトバンクのような数千万ユーザー規模の会社や大手広告代理店から見ると、単純リーチとしての100万人は大きく見えない。
見せるべきは**熱量あるリアル接点**。

### 推奨表現

> **年間約70万〜100万人規模のリアル接点を通じて、ウルトラマンは“直接会いに来るファン”との濃い関係を持っています。**

補足として:

> **テレビ・配信・SNSで広く接点を作り、イベント・ショー・グリーティングで熱量を高め、流通・商品化で購買につなげる。この一連の流れが、ウルトラマンの強みです。**

### ファネルで見せる(数字は単独で出さない)

| レイヤー | 役割 | 例 |
| --- | --- | --- |
| マス接点 | 認知を広げる | テレビ、映画、YouTube、SNS、PR |
| 熱量接点 | ファン化する | ウルサマ、ライブ、ヒーローショー、グリーティング |
| 購買接点 | 商品化につなげる | 店頭、POPUP、ウルトラマート、EC、キャンペーン |
| 継続接点 | 次の商品・次の作品へ戻す | 新シリーズ、映画、イベント、限定商品 |

### 補強データ収集リスト(数字の裏付け)

- [ ] 有料イベント来場者数
- [ ] フリーショー来場推計
- [ ] グリーティング・撮影会参加数
- [ ] 会場稼働率
- [ ] 満席率
- [ ] 物販購買率
- [ ] 客単価
- [ ] リピート率
- [ ] 抽選倍率や満席による機会損失
- [ ] 地域展開数
- [ ] 年間実施回数

### 判断基準

キャパに対して満席が多いなら、強く言える:

> **キャパシティ上限に近い形で、年間約100万人規模のリアル接点を生み出している。**

裏付けなしの「100万人に届きます」単体は弱い。使わない。

## Part B:スタイルガイド戦略の見せ方

スタイルガイドは最後に軽く触れるだけではもったいない。ライセンシーにとって**“商品化できるかどうか”の安心材料**。

### 当日の言い方

> **今回のコンテンツ展開に合わせて、ライセンシーの皆さまがすぐ企画化できるよう、カテゴリー別のスタイルガイドと素材提供体制を整えていきます。**

### 見せるべき項目

| 項目 | 内容 |
| --- | --- |
| ブランドガイド | ロゴ、世界観、コピー、NG表現 |
| キャラクターガイド | ヒーロー、怪獣、歴代キャラ、新作関連キャラ |
| カテゴリー別ガイド | 食品、アパレル、雑貨、文具、広告、流通 |
| シーズン別ガイド | 映画期、夏休み、年末年始、周年施策 |
| 商品化テンプレート | パッケージ例、POP例、販促例、SNS例 |
| 監修フロー | 企画提出、初稿確認、修正、承認までの流れ |
| 開示区分 | 当日開示、NDA後開示、個別商談時開示 |

### 見せ方の要点

「素材があります」ではなく、

> **企画しやすいように、カテゴリー別に使える形にしてあります**

と見せる。「作りたい」→「作れる」への転換がこのパートの役割。
