## コンテンツ戦略パートの語り方(スライド6〜12)

ライセンシーは「作品がたくさんあります」では動かない。ライセンシーが知りたいのは:

- いつ盛り上がるのか
- 何の商品を作れるのか
- どのキャラクターを使えるのか
- どのターゲットに売れるのか
- どの販路で売れるのか
- いつ企画を始めれば間に合うのか

### 基本メッセージ

> **2027年度以降、ウルトラマンは単発の作品展開ではなく、テレビ、映画、イベント、YouTube、流通、IPコラボを連動させた“面の展開”に入ります。**

### 柱1:新しいテレビシリーズ(スライド8)

「3年連続」「同じ世界線」と断定できない場合の対外表現:

> **2027年度以降のテレビシリーズでは、キャラクターや世界観の継続性をより重視し、ファンが次の展開を追い続けたくなる構造を強化していきます。**

「テレビ局が変わるかも」などの話は**絶対に触れない**。

### 柱2:映画・特別編・ゼロ関連(スライド9)

> **映画館、配信、イベント、商品化を連動させ、作品接点を売場・キャンペーンに接続していきます。**

ここで食品、外食、流通、アパレル、広告代理店に「映画タイミングで一緒にやれる」という絵を見せる。

### 柱3:ギャラファイ/YouTube系展開(スライド10)

単独ヒーローだけでなく、歴代ヒーロー・怪獣・人気キャラを横断的に使える点がライセンシーにとって使いやすい。

> **YouTube・配信領域では、幅広いヒーローとキャラクターを活用し、コアファンにも新規層にも届く接点を再強化します。**

## NG表現集(社外向け)

| NG表現 | 理由 |
| --- | --- |
| 3年連続で同じ世界線です | 未確定・社外開示リスクがある |
| テレビ局が変わるかもしれません | 不要な不安を与える |
| まだ委員会確認していません | 信頼感が落ちる |
| 詳細は出せませんが色々あります | 期待値だけ上げて中身がない印象になる |
| 100万人に届きます | 接点定義が曖昧だと突っ込まれる |
| 過去にこれをやりました(だけ) | 過去実績だけでは商談につながらない |

### 安全で強い定型表現

> **2027年度以降は、テレビ・映画・イベント・配信・流通・商品化を連動させ、年間を通じてウルトラマンとの接点を作り続けます。**

## IPコラボの見せ方(スライド21〜22)

モフサンド、ベイブレード、サンリオを同じ棚に並べると雑に見える。**2つに分ける**:

### スライド21:過去・現在の60周年実績

- モフサンド / ベイブレード / その他既存コラボ / 既存商品化・イベント・流通施策

> **60周年では、異なるファン層・異なる売場に向けて、すでに多様なコラボが動いています。**

### スライド22:これからの大型機会

- サンリオコラボ / ゼロ映画連動 / 新テレビシリーズ連動 / YouTube・ギャラファイ系 / ウルトラマート・流通展開

> **ここからは、皆さまと一緒に商品化・売場化していきたい領域です。**

**サンリオの扱い**:発表可能範囲が確認できているなら目玉になる。ただし「決まりました」ではなく、ライセンシー側の参加余地を見せる形で:

> **サンリオコラボ実現時には、両IPの魅力を活かした商品化・売場展開をライセンシーの皆さまと広げていきます。**

---

## 流通・ウルトラマート(スライド23)

単なる紹介ではなく、**ライセンシーが商品を作る理由**として見せる。

> **ウルトラマンの商品を売る場所を、円谷側でも増やしていきます。だから、商品化したものを展開できる場が広がっています。**

ライセンシーの関心:「作っても売る場所があるのか?」「棚が取れるのか?」「イベントや映画と連動できるのか?」

盛り込む要素:

- ウルトラマートの方向性
- POPUP展開
- 量販店・専門店での売場展開
- 映画・イベント期の店頭施策
- 既存商品の売場事例
- 今後募集したい商品カテゴリー
- 小売・流通と一緒に作りたい売場企画
