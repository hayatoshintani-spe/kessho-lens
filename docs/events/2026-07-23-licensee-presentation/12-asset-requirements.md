# 12. 写真・モック素材 要件定義書 — ULTRAMAN BUSINESS PARTNERS MEETING 2026

**デッキv5(21枚)の各ビジュアルゾーン実寸から逆算した、素材の内容イメージ・点数・必要ピクセル数の確定版。**
撮影担当・デザイナー・モック制作会社にそのまま渡せる仕様書。

---

## 1. 共通要件

### 解像度の考え方

スライドは16:9(13.333×7.5in)。会場投影を**4K(3840×2160)基準**で設計し、FHD(1920×1080)を最低ラインとする。

> **換算式:必要px = ゾーンの幅(in) × 288(4K基準)/ 最低ライン = × 144(FHD基準)**

配布資料(A4印刷)に流用する素材は、**印刷サイズで300dpi以上**を別途確保する(投影用より要求が高い。例:A4横半分に使う写真は 2480×1750px 程度)。

### サイズクラス(発注時はこのクラス名で指定)

| クラス | 用途 | 推奨(4K基準) | 最低(FHD基準) |
| --- | --- | --- | --- |
| **BG** | 全面背景・キービジュアル | **3840×2160** | 1920×1080 |
| **L** | 大型ゾーン(横幅いっぱい・高さ1in超) | **長辺3520px** | 長辺1760px |
| **M** | ゾーン内の個別写真・メインモック | **長辺1600px** | 長辺1200px |
| **S** | 小物モック・アイコン・サムネイル | **長辺800px** | 長辺600px |
| **QR** | QRコード | **1100×1100** | 600×600 |

### フォーマット・色

| 項目 | 要件 |
| --- | --- |
| 写真 | JPEG(圧縮率 高品質80以上)または PNG。sRGB。過度なシャープ・圧縮ノイズ不可 |
| モック・ロゴ・切り抜き | **PNG(背景透過)**。ダーク背景(#000714)に載せるため、白フチ・アンチエイリアスの残りに注意 |
| 図版(フロー図・カレンダー帯・ハブ図) | 編集可能データ(PowerPoint作図/AI/SVG)を優先。画像化する場合はLクラス |
| QRコード | 誤り訂正レベルH、余白(クワイエットゾーン)4モジュール以上、**ダーク背景上で読めるよう白地タイル付き** |
| 動画切り出し | 使用不可(解像度不足・ブレのため)。必ず静止画原本を手配 |

### 写真のトーン指定(全スライド共通)

- **「商品単体」ではなく「売場・人・熱量」が写っているものを最優先**(スライド4は商品単体写真の使用禁止)
- 明るい表情の親子・来場者。後ろ姿・手元カットは肖像権処理が軽く使いやすい
- 横位置(ランドスケープ)基本。帯ゾーンに入れるため**上下に切れても成立する構図**
- 会場の暗がり写真はダーク背景に沈むため、**被写体が明るい写真**を選ぶ

### 権利・開示確認(全素材必須)

1. 肖像権:来場者が写る写真は掲出許諾済みのものに限定(未許諾はボカシ処理)
2. コラボ先(モフサンド/ベイブレード/サンリオ等):**先方監修・掲出許諾の確認**
3. 未発表素材:開示区分(投影可/配布可/NDA後/不可)を7/14確認会で確定
4. モックには「イメージ」表記を入れる(実在商品と誤認させない)

## 4. 納品ルール

| 項目 | ルール |
| --- | --- |
| ファイル命名 | `s{スライド番号2桁}_{連番}_{内容}_{クラス}.{拡張子}` 例:`s07_01_tshirt-adult_M.png` |
| フォルダ | `assets/photo/`(実写)`assets/mock/`(モック)`assets/kv/`(合成KV)`assets/qr/` |
| 締切 | **第1便:7/15(水)**=写真・既存素材(7/16スライド初稿に反映)/**第2便:7/18(土)**=新規モック・合成KV(7/21リハで投影確認) |
| 確認 | 各素材に開示区分(投影可/配布可/NDA後/不可)のタグ付け必須。7/14確認会で不明分を確定 |
| 予備 | 各ゾーンとも採用数の1.5倍を候補納品(現場で差し替え判断) |

## 5. 不足時の代替方針(優先順)

1. 実写がない → **モック新規制作**(「イメージ」表記)
2. モックが間に合わない → **ダークパネル+テキストによる企画名表示**(現行デッキの状態のまま=破綻しない設計にしてある)
3. 開示不可素材 → 歴代・既存素材に差し替え、詳細は「個別商談時にご案内」へ誘導
