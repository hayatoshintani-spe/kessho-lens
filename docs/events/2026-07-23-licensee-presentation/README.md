## イベントの定義

本イベントは作品発表会ではなく、**ライセンシー向けの商談創出イベント**である。
2027年度以降のウルトラマン事業に、既存ライセンシーと新規見込み企業を巻き込むための**営業起点イベント**として設計する。

### ゴール

> **2027年度以降、ウルトラマンは映像・映画・イベント・流通・IPコラボ・スタイルガイドを連動させて、商品化し続けられるIPになる。今、企画に入った企業が、次の売場とキャンペーンの主導権を取れる。**

### 目的(2つ)

1. **既存ライセンシー**:2027年度以降の商品化・販促投資を増やしてもらう(売上アップ、SKU拡大、発注数拡大、キャンペーン連動、売場強化)
2. **新規見込み企業**:「自社でもウルトラマンで企画できる」と感じさせ、商談化する(広告代理店、SP会社、流通、食品、アパレル、雑貨、外食、デジタル系)

### 着地点

> **「すごかった」で終わらせず、「うちも作りたい。相談したい」で終わらせる。**

参加者は必ずしも決裁者中心ではない。よって当日のプレゼンは「経営判断させる資料」ではなく、**担当者が社内に持ち帰って「これは商品化したいです」と言える材料を渡す資料**にする。

## 勝ち筋(この順番)

1. **熱量を体感させる** — 動画とヒーローショーで「ウルトラマンは人を動かすIPだ」と最初に感じさせる
2. **戦略を理解させる** — 2027年度以降、テレビ・映画・イベント・YouTube・IPコラボ・流通展開が面で動くことを示す
3. **商品化を想像させる** — 業種カテゴリー別に「うちならこう作れる」と思わせる
4. **実行可能だと安心させる** — スタイルガイド、素材、監修フロー、企画相談窓口を提示する
5. **すぐ動かす** — 個別商談予約、企画募集、カテゴリー別相談に誘導する

## 最重要リスク(要旨 — 詳細は 07)

1. **コンテンツ素材が薄い** — 450人を呼んで「新しい話がほとんどない」が最悪。制作部・IP側から出せる素材を必ず引き出す
2. **営業パートが過去実績紹介で終わる** — 「今後募集したい企画」とカテゴリー別提案に必ず変換する
3. **100万人の数字が弱く見える** — 単純リーチではなく熱量あるリアル接点として見せる
4. **スタイルガイドが曖昧** — 素材と監修フローが見えないと動けない。最低限の見せ方を当日までに用意
5. **誰が話すかが曖昧** — コンテンツ戦略は権威ある人、営業戦略は営業トップが語る
