# 04. オープニング動画 — 制作会社向け修正発注ブリーフ

**発注方針の変更:「60周年TOPICS動画」→「マーケティングカレンダー動画」**

現行の「60周年TOPICS動画」では足りない。必要なのは、2027年度以降の商機を直感的に伝える**マーケティングカレンダー動画**。

---

## 動画の目的

60周年の盛り上がりと、2027年度以降の商機を直感的に伝え、ライセンシーに「今乗らないと機会を逃す」と感じてもらう。

## コアメッセージ

> **60周年はもう始まっている。
> でも、まだ間に合う。
> 2027年度以降に向けて、今乗った企業が次の商機を取れる。**

## 動画の方向性

単なるイベント紹介動画ではなく、ウルトラマンが映像・イベント・商品・広告・流通・IPコラボで**年間を通じて展開されていること**を見せる“マーケティングカレンダー動画”にする。

## 尺・上映位置

- 尺:約2分(進行表 0:02〜0:04)
- 上映位置:MCオープニング直後、ヒーローアクションの直前(会場の温度を上げる導入)

---

## 入れるべき素材(領域別)

| 領域 | 入れるべき内容 |
| --- | --- |
| イベント | ウルサマ、ライブ、展覧会、ヒーローショー、グリーティング |
| 商品化 | 食品、アパレル、雑貨、玩具、文具、コレクション系 |
| 広告・販促 | タイアップ、店頭施策、企業キャンペーン |
| 国内外展開 | 国内イベント、海外展開、グローバル感 |
| 流通 | ウルトラマート、POPUP、量販店、専門店、売場展開 |
| IPコラボ | モフサンド、ベイブレード、サンリオなど、出せる範囲で |
| 映像 | 2027年以降のテレビ、新作、映画、特別編、YouTube展開など |
| 未来感 | 2027年以降の商機カレンダー、商品化チャンスのタイミング |
