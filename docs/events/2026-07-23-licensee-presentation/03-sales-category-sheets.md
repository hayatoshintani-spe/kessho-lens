# 03. 業種カテゴリー別営業シート(募集型)

営業パートは過去実績の羅列では弱い。**「今後こういう企画を一緒にやりたい」という募集型の営業パート**にする。

## 構成の型(全カテゴリー共通)

> **過去実績 → 今後の商機 → 募集したいカテゴリー → 具体企画例 → 相談導線**

---

## 食品・飲料(スライド14)

| 項目 | 内容 |
| --- | --- |
| 商機 | 夏映画、ウルサマ、親子需要、店頭キャンペーン |
| 企画例 | 限定パッケージ、購入特典、親子キャンペーン、映画半券連動、夏休み販促 |

> **メッセージ:夏のウルトラマン接点を、親子向け食品・飲料キャンペーンに変えられます。**

## 外食・カフェ(スライド15)

| 項目 | 内容 |
| --- | --- |
| 商機 | イベント来場前後、映画公開期、ファミリー来店 |
| 企画例 | コラボメニュー、ノベルティ、来店特典、ヒーローグリーティング連動 |

> **メッセージ:来場・視聴の熱量を、店舗送客に接続できます。**

## アパレル(スライド16)

| 項目 | 内容 |
| --- | --- |
| 商機 | 大人ファン、親子リンク、女性向け、ストリート、怪獣デザイン |
| 企画例 | Tシャツ、スウェット、バッグ、キャップ、親子コーデ、限定コレクション |

> **メッセージ:ウルトラマンは子ども向けだけでなく、大人が着られるデザインIPとして展開できます。**

## 雑貨・生活用品(スライド17)

| 項目 | 内容 |
| --- | --- |
| 商機 | 日常接点、ギフト、オフィス、家庭用品 |
| 企画例 | タンブラー、タオル、ステーショナリー、インテリア、ガジェット小物 |

> **メッセージ:ウルトラマンを“毎日使う商品”に落とし込めます。**

## 文具・教育・出版(スライド18)

| 項目 | 内容 |
| --- | --- |
| 商機 | キッズ、親子、学習、読書、夏休み |
| 企画例 | 学習帳、絵本、図鑑、ワークブック、読書キャンペーン |

> **メッセージ:勇気、成長、仲間、正義というテーマを教育・文具領域に広げられます。**

## 流通・小売(スライド19)

| 項目 | 内容 |
| --- | --- |
| 商機 | ウルトラマート、POPUP、量販店、専門店、売場ジャック |
| 企画例 | 専用棚、期間限定売場、購入特典、スタンプラリー、限定商品 |

> **メッセージ:商品を作るだけでなく、売場を作る準備があります。**

## 広告代理店・SP会社(スライド20)

| 項目 | 内容 |
| --- | --- |
| 商機 | 企業キャンペーン、地域創生、ファミリー向け販促、周年施策 |
| 企画例 | 企業タイアップ、店頭キャンペーン、交通広告、SNSキャンペーン、イベント協賛 |

> **メッセージ:クライアント課題に合わせて、ウルトラマンを広告・販促装置として活用できます。**

---

## 各カテゴリーの相談導線(スライド26〜27に接続)

- カテゴリー別の企画募集テーマとして再掲する
- 個別商談予約QRから「希望カテゴリー」を選択できる形にする
- 当日配布資料にカテゴリー別の窓口・相談方法を明記する
