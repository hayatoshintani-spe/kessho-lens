## 2. 迷ったときの入口

- **どれが最新版か分からない** → 資料一覧_最新版.md（全資料の正本一覧。◎だけ使う）
- **これはSTOが受けるべき依頼か** → STO設計書2章（やらないこと＋受付5条件）。迷ったら受けずに新谷へ
- **判断に迷った** → 金曜を待たずに新谷へ。24時間ルール（抱える方が失点）
