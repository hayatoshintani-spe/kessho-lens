# データ基盤メモ：財務実数による営業改革の根幹づけ

**作成：営業改革事務局（社外秘・取扱注意）**
**元データ：柳沼さん提供「TPC作品利益率一覧」61/62/63/65期（64期欠落）＋取引先マスタ9,622件×2**
**詳細分析：`findata/analysis_summary.md`（集計の検算済み。金額単位は円）**

---

## 1. 何が実数で裏付けられたか——グランドデザインの仮説との突合

### ①「なぜ今か」が数字になった（最重要）

| 期 | 総売上 | 総粗利 | 粗利率 |
|---|---|---|---|
| 61期（2022.03） | 53.4億円 | 26.3億円 | 49.3% |
| 62期（2023.03） | 104.4億円 | 65.9億円 | **63.2%** |
| 63期（2024.03） | 99.0億円 | 58.7億円 | 59.3% |
| 65期（2026.03） | 87.4億円 | 35.1億円 | **40.2%** |

- 62期に売上が約2倍に急伸した後、**売上は漸減（ピーク比▲16%）、粗利率は23ポイント低下**（63.2%→40.2%）
- 原価は横ばい〜増加の中で売上構成が低採算側へシフト——**「機会の多面化とともに収益性が薄まっている」というグランドデザインの中心仮説が、全社レベルの実数で裏付けられた**
- ただし「低収益案件が現場工数を圧迫している」の工数側はまだ未計測（90日の工数記録で検証）

### ② 二極化の実在——高採算IPライセンスと低採算事業

- **高採算の柱**：海外事業部（4期計140億円・粗利率94%）、中国事業（97%）、国内ライセンス（93%）、印税・配信（90%超）。利益は海外IPライセンスに強く依存
- **低採算・赤字側**：製作グループ（▲21億円）、LSS（▲4.4億円）、音楽・カード・イベント・物販系は原価先行
- 解釈上の注意：制作系は作品制作費を集約する**コストセンター**であり「やめる対象」ではない（IPの源泉＝投資。石塚さんのIP投資判断基準の議論と接続）。イベント・カード等の低粗利は、田中さん・宍戸さんの指摘通り**CRM・ブランド価値を含めた総合評価が必須**という設計の妥当性を逆に補強する

### ③ 高集中構造の実在

- 上位3セグメントで売上の52〜72%、上位10で81〜92%
- 65期はセグメント数が68に増え集中度は低下（上位3＝52%）——**領域が広がりながら低採算化している**という構図で、①と整合
- 粗利率の四分位（売上100万円超・n=79）：Q1=20% / 中央値=45% / Q3=67%——**評価軸なしに全案件を同じ熱量で扱うことの機会損失が大きい**分布

## 2. 改革設計への反映（確定事項）

| 設計要素 | 反映 |
|---|---|
| KPIベースライン | 全社：売上87.4億・粗利35.1億・**粗利率40.2%**（65期）を基点に確定。北極星「粗利/営業工数」の分子データを確保（分母は工数計測開始待ち） |
| 顧客棚卸しの名寄せ基盤 | **取引先マスタ9,622件を採用**（外部コード重複ゼロ）。表記ゆれ約116キーの正規化を事務局作業に追加。2ファイルは完全同一のためどちらか一方を正とする |
| 粗利算定ルール | 2層方式を採用：**案件・顧客レベル＝NXグロス×契約上の配分構造**で推計／**全社・領域レベル＝財務純額（他社分消去済み）**で検証。※本データは既に純額のため作品別実効率は単独算出不可（下記ギャップ参照） |
| 評価軸の妥当性 | 「海外展開価値」軸（利益の柱の実態と一致）、「CRM/ブランド価値」軸（低粗利領域の正当評価に必須）の両方がデータで正当化された |
| 部長会・経営向け資料 | 「なぜ今か」に粗利率推移（63%→40%）を掲載可能（社内秘資料に限定） |

## 3. データギャップ→追加依頼（柳沼さん・青山さん宛）

1. **64期（2025.03）**の同一覧——トレンドの穴を埋めるため
2. **取引先別の売上明細**（NX出力または販売管理データ）——顧客ランク「取引実績」の金額閾値（上位10%/25%）確定と顧客棚卸し下書きに必須。本データはセグメント別のため取引先別が見えない
3. **作品別のグロス収入と委員会別配分率**（または委員会契約の一覧）——案件別実効粗利の推計テーブル作成のため。消去は「取消用」の純額表示でグロスが別掲されない
4. **親セグメント名称と作品・部門の対応表**——「作品」と「事業部門・コストセンター」が混在しているため、営業領域別の集計に必要

## 4. 留意事項

- 64期欠落のため、直近トレンドは63期→65期の比較になる
- 親セグメントには収益部門とコストセンターが混在。部門・作品タイトル単位の損益ではない
- 数値はすべて内部管理データ。社外・全社公開資料への転載は不可（部長会・経営会議の社外秘資料まで）
