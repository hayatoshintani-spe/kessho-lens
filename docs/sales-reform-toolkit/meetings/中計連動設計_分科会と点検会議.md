# 中計連動設計 — 3分科会の議題と点検会議のアジェンダ

**作成：新谷（STO・社外秘）**
**位置づけ：グループ中期経営計画（FY2026-2028）を軸に、3分科会が何を議論し、何を点検会議に上げるかを定める。点検会議の標準アジェンダは本書が最新版（会議運用設計書3.2と会議体別アジェンダ詳細設計5章の旧アジェンダを置き換える）**

## 1. 考え方

中計は「収益化の不足」と「価値創造の不足」の2つの課題に対し、10の打ち手を掲げている。3つの分科会はこの打ち手の円谷プロ側の実行部隊として位置づける。点検会議は、中計の実行が進んでいるかを山本会長が月次で確認し、会長の承認が必要な事項を決める場とする。

## 3. 点検会議の標準アジェンダ（月次60分・議長：山本会長）

| 時間 | 項目 | 中身 |
|---|---|---|
| 0:00-0:10 | 1. 業績の報告 | 営業事業本部の予算比実績と通期見込み（黒・青・赤の確度つき）、5億ブリッジの進捗（レバー別）、中計数値計画との対比。数字はSTOが作成し柳沼さんが検証 |
| 0:10-0:15 | 2. 前回決定事項の確認 | 決定ログの消し込み。遅延は理由と対策のみ |
| 0:15-0:45 | 3. 分科会からの共有（各10分×3） | 各分科会リーダーが次の3分類で共有する。**決議事項**（分科会・戦略会議で決定済みのこと。報告のみ、蒸し返さない）／**報告事項**（進捗と数字。判断は不要）／**承認事項**（会長の承認が必要なこと。選択肢と推奨案を1枚で提示） |
| 0:45-0:55 | 4. 承認事項の決定 | 承認事項をまとめて審議し、会長がその場で決める。全体で3件以内。持ち帰りが出た場合は期限と再上程日をその場で決める |
| 0:55-0:60 | 5. 次回までの確認 | 決定・担当・期限の読み上げ。24時間以内に決定ログへ記録し全関係者へ展開 |

### 3分類の定義（分科会リーダー向け）

- **決議事項**：分科会または戦略会議で決定権限の範囲内で決めたこと。点検会議では変更しない。会長への透明性のための共有
- **報告事項**：進捗・数字・実験結果など、判断を求めないもの。1件1分以内
- **承認事項**：基準の制定、投資、部門をまたぐ方針、撤退など、会長の判断が必要なもの。論点1枚の型（問い、選択肢2案以上、推奨と理由、決めていただきたいこと）で提出。全体で3件以内、なければ無しでよい

### 資料のルール（変更なし）

キーチャート5枚以内、作成上限2時間、前日までに会長・社長へ送付、1ページ目は「本日の承認事項」の一覧。

## 4. 運用の流れ

分科会（隔週）で議論 → 決められることは決める（決議事項に）→ 決め切れないものは戦略会議（隔週・社長）で決める → 会長の判断が必要なものだけが承認事項として点検会議（月次）へ。同じ論点を二度議論しない、下位で決めたことを上位で蒸し返さない、という原則は従来どおり。

初回の点検会議の想定承認事項（現時点の候補）
1. 顧客ランク統合の基本方針（ライセンス営業改革）
2. 接点づくりのゴール指標と、データ統合の段階的投資方針（接点づくり）
3. 成果目標（予算比＋5億円）のスコープ確認と5億ブリッジの枠組み（STO）
