# トップ外交 48時間登録メモ（経営陣用・1分で書ける型）

> 使い方：経営陣は面談後48時間以内に、以下の型でSTOへ送る（メール・チャット・音声メモ可）。
> きれいに書く必要はない。**記録化・追跡・担当アサインはSTOの仕事。** 経営陣の仕事は「忘れないうちに投げる」ことだけ。

---

## 送信フォーマット（コピーして使用）

```
【外交メモ】
相手：（企業名・氏名・役職）
日時：
同席：
話したテーマ：
先方の関心・温度感：
機会になりそうな話：
（複数あれば箇条書き。確度が低くても書く）
次の約束・宿題：
担当のイメージ：（あれば。なければSTOに一任と書く）
```

## 記入例

```
【外交メモ】
相手：大手流通C社 ○○社長
日時：6/10 会食
同席：△△役員
話したテーマ：周年企画の話から、キャラクターキャンペーンの話に
先方の関心・温度感：全国キャンペーンに前向き。秋までに枠を決めたいらしい
機会になりそうな話：
・全国店舗でのキャンペーン＋限定MD
・C社のアプリ会員へのデジタル施策（CRM連携できるかも）
次の約束・宿題：企画の骨子を7月上旬までにこちらから
担当のイメージ：STOに一任
```

---

## STO側の処理（SLA）

| 期限 | 処理 |
|---|---|
| 受領後24時間 | トップ外交管理ボードに登録（外交ID採番）、機会を分解して1機会=1行に |
| 72時間以内 | 担当営業＋スポンサー役員をアサインし、本人へ通知 |
| 30日以内 | 初動アクション実行（担当営業）。実行日をボードに記録 |
| 月次会議 | 冒頭10分でパイプラインをレビュー。期限超過は必ず対処を決める |
| 随時 | 「次に会うべき相手・テーマ」を外交逆提案リストへ起案し、経営陣に提案 |

## 運用の約束

- 登録された機会が案件にならなくても、**登録した経営陣・追った担当者の評価は下がらない**（案件化率は仕組みのKPIであり、個人のKPIではない)
- 消滅させる場合も「消滅」として記録する（黙って消さない。翌年の再挑戦の種になる）
