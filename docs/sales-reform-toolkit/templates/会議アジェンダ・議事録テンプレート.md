# 会議アジェンダ・議事録テンプレート（週次／月次／四半期）

原則：**報告はダッシュボード・マスタの事前共有で済ませ、会議では決定だけを行う。会議のための資料は作らない。**
決定はすべて「決定ログ」（Excel 03 / Notion決定ログDB）に記録し、翌回冒頭で実行確認する。

---

## 1. 週次パイプライン会議（30分／領域ごと）

**出席**：営業マネージャー＋担当者　**投影**：案件マスタ（自領域フィルタ）

| 時間 | アジェンダ | 見るもの | 決めること |
|---|---|---|---|
| 0-5分 | 前回アクションの確認 | 前回メモ | 未実行の理由と対処 |
| 5-15分 | 今週の重点商談 | S/A案件・期限が近い案件 | 今週の一手・同行/支援要否 |
| 15-25分 | 停滞案件 | 停滞フラグ抽出 | 次アクション・期限・支援者（その場でマスタ更新） |
| 25-30分 | 上申事項 | - | 月次会議へのエスカレーション項目 |

**議事メモ型（マスタ更新で代替。残すのは3行だけ）**
```
■ 週次（領域：　　）YYYY-MM-DD
・エスカレーション：
・支援要請：
・共有事項：
```

---

## 2. 月次ポートフォリオ会議（90分）

**出席**：経営陣＋営業部門長＋STO　**議長**：新谷　**投影**：ダッシュボード＋案件マスタ

| 時間 | アジェンダ | 見るもの | 決めること |
|---|---|---|---|
| 0:00-0:10 | トップ外交レビュー | 外交管理ボード | 初動遅延の対処／逆提案の承認 |
| 0:10-0:30 | S/A案件・経営支援 | 案件区分S/A抽出 | 経営支援を入れる案件の指定 |
| 0:30-0:50 | 停滞案件の打開 | 停滞フィルタ | 打開アクション・支援者・期限 |
| 0:50-1:10 | 撤退・省力化トリアージ | 要トリアージ抽出＋STO起案書 | 撤退／省力化／継続の決定＋解放工数の再配分先 |
| 1:10-1:20 | 新規成長領域枠（固定） | 領域別サマリー | 新規領域案件の重点指定・障害除去 |
| 1:20-1:30 | 決定事項の確認 | 決定ログ | 決定の読み上げ・責任者・期限の確定 |

**STO起案書の型（トリアージ1件につきこの5行）**
```
案件名／顧客：
データ：粗利　千円・年間工数　h・粗利/工数　千円/h・スコア　点
起案区分：撤退 ／ 省力化 ／ 継続（理由付き）
撤退・省力化の場合の顧客への伝え方（別れ方の標準3点セット）：
解放される工数の再配分先案：
```

---

## 3. 四半期経営レビュー（半日）

**出席**：経営陣＋全部門長　**投影**：経営ダッシュボード

1. KPIレビュー（15指標。北極星＝粗利/営業工数のトレンド）
2. ポートフォリオ全体の変化（案件区分の分布・S/A顧客への工数配分）
3. 顧客ランクの見直し（年1回は全面、四半期は例外変更のみ）
4. プロセス改革の進捗（監修・契約リードタイム）
5. 翌四半期の重点方針（重点顧客・重点領域・トップ外交計画）
6. 改革運営自体の点検（現場の入力負荷・ルールの形骸化チェック）

---

## 4. 決定ログ記入ルール

- 1決定=1行。「検討する」は決定ではない（誰が・いつまでに・何をするか、まで書けて初めて決定）
- 状態が期限超過のまま2回続いた項目は、月次会議の冒頭で必ず取り上げる
- 撤退決定には「顧客への伝え方」と「再配分先」の記載を必須とする
