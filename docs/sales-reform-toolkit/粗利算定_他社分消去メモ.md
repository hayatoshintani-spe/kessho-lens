# 粗利算定メモ：ライセンス収入と「他社分消去」

**作成：営業改革事務局用の内部整理（社外秘）**
**元情報：財務・青山さんからの説明＋「TPC 他社分消去 概要」資料（国内ライセンス限定の話。柳沼さんの確認待ち）**

---

## 1. 構造の理解

国内ライセンス収入は、厳密には**製作委員会の収入**であり、円谷プロの純粋な稼ぎではない。円谷プロ以外の委員会出資者への**配分金**が実質的な「原価」に相当し、会計上は**「他社分消去」**という名称で処理される。

### 配分の流れ（資料の例：収入総額1,000万円）

| 項目 | 率 | 金額 | 円谷の取り分 |
|---|---|---|---|
| 委員会収入 | — | 10,000,000 | |
| 窓口手数料 | 10% | 1,000,000 | ✔ ①（窓口として） |
| 原著作権料 | 10% | 1,000,000 | ✔ ②（原著作権者として） |
| その他経費 | — | 0 | |
| 特別配分金 | 24% | 2,400,000 | （例では他社） |
| 配分原資 | — | 5,600,000 | |
| うち円谷プロ配分 | 30% | 1,680,000 | ✔ ③（出資者として） |
| うち他社配分 | 70% | 3,920,000 | |
| **円谷プロ収入総額** | | **3,680,000** | **＝①＋②＋③（この例では総額の36.8%）** |

### 円谷プロ側の会計処理（2パターンのいずれか）
- **パターンA（純額型）**：売上10,000,000に他社分消去▲6,320,000を当て、売上3,680,000・原価0・粗利3,680,000
- **パターンB（総額型）**：売上10,000,000・原価6,320,000を計上し、消去処理を経て粗利3,680,000

いずれも着地は同じ：**円谷の実質粗利＝収入総額×円谷の実効取り分率**。

## 2. 営業改革にとっての意味

### 朗報：案件別の原価計算は「不要」かもしれない
個別案件単位で原価を算出していないのは事実だが、**配分構造（窓口手数料率・原著作権料率・特別配分・出資比率）は作品＝委員会ごとに固定**のはず。つまり：

> **案件別粗利 ≒ 案件のグロス収入 × 「作品別の円谷実効取り分率」**

「作品別 実効率テーブル」さえ財務からもらえれば、NXのグロス請求データと掛け合わせて**案件別粗利を機械的に推計できる**。個別案件の原価積み上げは要らない。

### 帰結：同じ売上でも「作品」によって粗利が大きく違う
同じ1,000万円のライセンス収入でも、円谷単独作品（実効率100%に近い）と委員会作品（例では36.8%）では粗利が3倍近く違う。**スコアリングの「粗利」軸と「粗利/工数」は、グロス売上ではなく実効取り分ベースで見ないと判断を誤る**。案件・顧客の評価において「どの作品のライセンスか」が粗利ドライバーになる。

### KPI・棚卸しへの反映
- 案件マスタに「対象作品」項目を持たせ、作品別実効率テーブルと紐づける設計にする
- 顧客ランクの「取引実績」も、グロスと実効粗利の両方で見られるようにする
- 粗利算定ルールの統一（Day 60目標）は「作品別実効率テーブルの整備」が実体になる

## 3. 財務チームへの確認事項（柳沼さん確認と併せて）

1. **作品別（委員会別）の配分構造・実効率の一覧**は存在するか。ない場合、契約書等から一覧化するとしたらどの程度の作業か
2. 円谷単独（委員会なし）作品の範囲——旧作／新作でどう分かれるか
3. パターンA／Bの**使い分けの基準**（作品による？時期による？）——データ抽出時に売上のグロス/ネットが混在しないための確認
4. 「その他経費」「特別配分金」の中身と変動性（率固定か案件により変わるか）
5. 海外ライセンス・商品化以外（イベント・広告等）の収入にも同様の配分構造があるか
6. NXの請求データ（グロス）と会計上の他社分消去の突合キー（作品コード等）があるか
