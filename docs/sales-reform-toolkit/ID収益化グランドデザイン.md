# ID収益化グランドデザイン — IDをどう利益につなげるか

**作成：新谷（STO・社外秘）**
**位置づけ：接点づくり分科会（黒澤さん）の背骨となる設計書。中計打ち手8（デジタルマーケの強化：常時接点型基盤）の円谷プロ側の実行設計。KGIは営業利益（2026-08-03 STO決定）**

---

## 1. 結論（3行）

円谷IDを「ファンとの接点の記録」から「利益を生む装置」に変える。
装置の式は単純で、**営業利益への寄与 ＝ アクティブID数 × 1IDあたり年間価値 − 獲得・運営コスト**。これに、ファンデータがライセンス営業の武器になる間接価値が乗る。
90日で換算式の第1版を作り、1年で装置を実証し、中計期間（FY2026-2028）で基盤投資を回収する。

## 2. IDが利益になる5つのルート

| ルート | 中身 | 効く先 |
|---|---|---|
| A. 直接販売 | ID→EC・ウルトラマート・自社MD・カード・イマジネーション課金。送客と購買の実測 | 商品＋5億（アップサイド） |
| B. リピート・LTV | 接点間の送客（ライブ→EC、EXPO→カード）で1人の年間購買を増やす | 商品＋5億 |
| C. 企画の的中率 | ファンデータで高付加価値商品・ターゲット拡張（Teen・大人女子）の外れを減らす | 粗利率の改善 |
| D. ライセンス価値の証明 | 「アクティブファン◯万人に直接届く」がパートナー企業への提案材料になる（顧客評価のCRM/D2C軸と接続）。料率・条件交渉、コラボ・広告の単価に効く | ライセンス＋5億 |
| E. 販促費の効率 | 広告を買わずにファンへ直接リーチできる分、獲得・販促コストが下がる | コスト構造 |

直接測れるのはA・B。C・D・Eは間接だが、Dは中計の「IP価値の強化」の中核であり、金額換算を諦めない（提案採用率・条件改定の実績で追う）。

## 3. 指標の階層（会員数をKGIにしない）

```
KGI   営業利益への寄与額
  ↑
第2層 ID経由売上（EC・カード・課金の合算）／ライセンス提案での採用実績
  ↑
第3層 アクティブID数 × 転換率 × 客単価 × 粗利率
  ↑
第4層 ID獲得数・獲得コスト/ID・アクティブ率（接点別）
```

- 報告は必ず上の層とセットで行う。「IDが増えました」単体の報告は禁止
- アクティブの定義（例：90日以内にログイン・購買・来場のいずれか）を分科会で確定し、以後変えない

## 4. 現状と空白（2026-08時点）

- **ある**：円谷ID（ワンID基盤）。カード会員・イマジネーション会員はタグで連結済み
- **空白（取ろうとしていないだけで取れる）**：ウルトラマート来店、ライブ動員、ウルトラマンEXPO先行チケット。QR・簡易登録（LINE・アプリ）→本登録の段階設計で取得可能
- **数字の空白**：アクティブ定義が未確定、ID経由売上の定点計測なし、1IDあたり価値が誰も言えない

## 5. 3段階ロードマップ

### Phase 1：実証（〜9月末・分科会の90日ゴール）

1. **定点計測の確立**（Day30）：ID総数・アクティブID数・ID経由売上の月次定点とベースライン
2. **ID獲得の実験2本**（Day60）：空白接点から2つ（ウルトラマートQR登録／EXPOチケットID連携／ライブ1公演から選択）。獲得数・獲得率・獲得コスト/IDを実測
3. **収益転換の実証と換算式v1**（Day90）：獲得IDへの送客施策1本で1IDあたり売上・転換率を実測。「ID1万人増＝営業利益＋◯円」の換算式第1版と、データ統合投資の論点1枚を戦略会議へ

### Phase 2：拡張（〜FY2026末）

- 主要接点すべてにID獲得の標準動線（入場・購入・来店時の登録フロー）を実装
- 送客プログラムの定常化（新規ID向けの初回導線、休眠IDの再活性）
- 換算式v2（セグメント別：ファン層・購買層・ライト層）
- 換算式に基づくデータ統合基盤の投資判断（実験→実証→投資のゲートを通す）
- ライセンス営業での活用開始：上位20社のアカウント面談でファンデータを提案材料に載せる

### Phase 3：装置化（FY2027-2028・中計後半）

- 常時接点型基盤（中計打ち手8）の本格稼働。タッチポイント70万人→700万人の流れの中で、ID転換率を装置のKPIに
- 新商品・新企画はファンデータ起点が標準に（Cルートの定常化）
- ファンデータがライセンス提案の標準装備になり、条件交渉の武器になる（Dルートの定常化）

## 6. 投資判断の型（実験→実証→投資）

| 段階 | 使う金 | 進むための基準（ゲート） |
|---|---|---|
| 実験 | 最小（既存ツール・手作業可） | 獲得コスト/IDが実測できること |
| 実証 | 小（施策費のみ） | 1IDあたり年間価値 ＞ 獲得コスト/ID × ◯倍（倍率は分科会で設定） |
| 投資 | 基盤投資（データ統合等） | 換算式で回収年数が言えること。承認は点検会議 |

ゲートを通らない限り次の金は使わない。これが「金があるからやる・痛手がないからやめる」をなくす仕組み。

## 7. 体制と役割

- **接点づくり分科会（黒澤さん）**：装置の設計者。指標体系・実験の選定・換算式のオーナー
- **接点オーナー各部**（EC・イベント・カード・イマジネーション・店舗）：獲得動線の実装
- **商品開発側（永山さん・山田さん）**：自社MDとの接続（Bルートの受け皿）
- **STO**：投資ゲートの関所・点検会議への上程・ライセンス側（Dルート）への橋渡し
- 数字の検証：ID経由売上の計測設計は財務（柳沼さん）と整合を取る

## 8. やらないこと

1. 会員数・獲得数をKGIにしない（必ず利益への換算とセット）
2. 実証前の大規模システム投資はしない
3. 全接点の一斉ID化はしない（実験2本→標準動線の順）
4. データ統合を目的化しない（統合は換算式が投資を正当化してから）
