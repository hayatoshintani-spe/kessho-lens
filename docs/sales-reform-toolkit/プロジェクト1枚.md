# 営業改革 — プロジェクト1枚（2026-07-16版）

## これは何のプロジェクトか（3行）

**営業のデータと財務のデータをつないで、どの顧客・どの案件に力を注ぐかを「数字で選べる会社」になるプロジェクトです。**
売上が伸びても利益につながらない構造（65期：売上▲21%・粗利率▲19pt、今期も売上超過なのに利益未達見込み）を、90日で変え始めます。
山本会長・ホールディングスがコミットし、円谷プロ全体（制作〜商品〜流通〜プロモ〜ライブ〜営業）を対象にします。

## 目標

**営業利益を予算に対して＋5億円**（66期予算40.2億 → 45.2億）※社外秘・取り扱い注意

## いま動いている3本（この順で進む）

1. **確認会** — 顧客746社・案件299件の「主担当」を各部長と確定する
2. **財務ひも付け** — 財務チーム（柳沼さん）のデータで、顧客・案件に金額を付ける
3. **採点→力の入れ直し** — ランクを決め、力の注ぎ先を変え始める（1・2の完了後）

## 90日の約束（3行）

- 30日：営業と財務の数字がつながる
- 60日：顧客・案件のランクが決まる
- 90日：力の入れ直しを実行する

2. いま決めるのは**主担当だけ**（役割メモは書ける範囲で）
3. 迷ったら**24時間以内に新谷へ**（抱えるより上げる）
