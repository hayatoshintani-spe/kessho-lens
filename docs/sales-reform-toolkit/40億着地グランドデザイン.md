# 営業利益40億 着地グランドデザイン

**作成：新谷（STO・社外秘・取扱注意）**
**位置づけ：今期（27.03期）営業利益40億円の着地までの全体作戦図。個別の設計（ブリッジ・確度管理・コスト削減・工数×粗利・ID収益化・EC戦略）はすべて本書の部品として位置づける。数字の展開は経営限り**

---

## 1. 結論（3行）

40億は「ベース25億の防衛」「アップサイド15億の積み上げ」「コスト削減」の**三正面作戦**で獲る。
社内はアップサイド＋20億（ライセンス7・商品6・中国7）をミニマムに運転し、各部の凸凹を吸収する。
毎月の点検会議で**「40億まであといくら」を利益ベースで1つの数字**にして確認する。これが唯一の計器。

## 2. 目標の構造

| | 対外（公式） | 社内（運転用） | 実行部隊 |
|---|---|---|---|
| ベース | 25億 | 25億 | 全社 |
| ライセンス | ＋5億 | ＋7億 | 営業事業本部 |
| 商品 | ＋5億 | ＋6億 | 商品開発事業本部 |
| 中国 | ＋5億 | ＋7億 | 中国事業（孫氏・SCLA連携） |
| **合計** | **40億** | **45億** | |

- 対外40億はミニマムライン。社内45億との差5億が凸凹の吸収バッファ
- 会長方針：各＋5億は**利益の積み上げ＋コスト削減の合成で達成してよい**（例：利益3億＋コスト削減2億）
- 二段構造（対外／社内）は経営限り。現場には自部門の社内目標のみを降ろす

## 3. 三つの戦線

### 戦線A：ベース25億の防衛（守り）

上積みの前にベースが毀損したら意味がない。監視対象は4つ。

1. **アジア・その他海外（4-7月▲1.4億）**：時期差か実力減かの切り分けと挽回プラン（次回点検会議で提出）
2. **中国の実効取り分率**：座組変更の早期検知（過去に原価率1.42%→6.04%の実例）。毎月監視
3. **ライブの計上後ズレ**：どのQに入るかを言い切らせる（時期ズレと失注を混ぜない）
4. **構造縮小領域（書籍・フィジカル）**：下げ止めの基準と撤退判断

### 戦線B：アップサイド15億（社内20億）の積み上げ（攻め）

中身は**黒（確定）・青（根拠あり）・赤（構想）の確度パイプライン**で管理し、毎月「赤が青に、青が黒に変わったか」だけを問う。

- **ライセンス＋7億**：大型広告の新規・継続契約化／上位22社（売上の3分の2）のアップセルと四半期戦略MTG／トップ外交（会長・社長登板）
- **商品＋6億**：カード9弾（8/17受注確定・コンビニ拡大で100万パック視野）＋特別弾（11月）／ウルトラマート日販100万円ライン（フワヌイ9月投入）／EC受注前年比2倍の維持／mofusand型の60周年横展開
- **中国＋7億**：MG改定・Blokees／越境EC（月商1,000万→3,000万の段階）／Q1上振れの通期化

### 戦線C：コスト削減（第3のレバー）

- 販管費25億（前期42億→▲17億計画）の**内訳100%見える化**と月次推移の常設報告（9月から点検会議）
- コスト削減チーム（リーダー高橋・部門横断）が削減目標額と第1弾施策を9/11に提示
- 予算外の大型支出は**事前稟議を必須**（2.5億AI事案の再発防止）。聖域なし（スタジオ・施設・外注・広告宣伝含む）

## 4. 月次の運転（マネジメントシステム）

```
分科会（週1）→ 戦略会議（隔週・社長）→ 点検会議（月次・会長）
```

- **計器は1つ**：「40億まであといくら」（利益ベース。柳沼×STOが8月中に計測を整備。請求ベース売上では代替しない）
- 点検会議の業績報告は3点セット：①40億ブリッジと確度パイプラインの更新 ②販管費25億の内訳・推移 ③各部の「今月のアクション」の答え合わせ
- 点検会議に出るものはすべて戦略会議を通過させる（数字の検証・承認事項の選別・リハーサル）。資料は3営業日前にSTO関門
- 承認事項を毎回3件以内で必ず上げる。点検会議は「HDから投資を引き出す場」
- 決定は24時間以内に決定ログへ。翌月冒頭で消し込み

## 5. 改革の道具と40億の接続（何がどこに効くか）

| 道具 | 効く戦線 | 効き方 |
|---|---|---|
| 工数×粗利の4象限 | B・C | 低粗利×高工数の条件改定・整理→浮いた工数を上位22社へ再投下 |
| 顧客ランク（5軸統合） | B | S/A集中で単価と継続率を上げる。500万円未満の新規は原則受けない |
| 監修改革 | B | リードタイム短縮→成約前倒し・回転数増（営業時間の監修比率を工数で計測中） |
| ID収益化（LTV） | B | EC・UM・イベントの送客と客単価。装置の換算式v1を9月に |
| EC全体戦略 | B | チャネル別目標と投資判断（9/11承認事項） |
| 予実基盤（ログラス） | A・C | 数字の正本一本化。10月稼働で「あといくら」の精度が上がる |

## 7. リスクと引き金（先に決めておく）

| 引き金 | 発動する対応 |
|---|---|
| カード9弾受注が90万パック未満 | 商品の社内目標を見直し、他レバー（UM・EC・横展開）へ再割付 |
| 中国の座組・取り分率に変更の兆候 | 即時に戦略会議へ報告（月次を待たない） |
| ベース毀損が累計1億超 | 当該部門が挽回プランを2週間以内に提出 |
| 「あといくら」が計画比2億超の悪化 | 戦略会議で緊急対策を決議（コスト第2弾・条件改定前倒し） |
| 販管費が月次計画を超過 | 事前稟議に遡って原因特定。翌月の点検会議で報告 |

## 8. 役割

- **山本会長**：月次の点検と承認。トップ外交の登板
- **永竹社長**：業績報告のオーナー。戦略会議の議長。ウルトラマート等の投資承認
- **新谷**：全体設計と障害除去。EC戦略。割付の確定。経営との数字の握り
- **小沢**：運転席（宿題・決定ログ・確度パイプラインの更新・関門レビュー）
- **分科会リーダー3名**：90日定量ゴールと「今月のアクション」の実行
- **コスト削減チーム（高橋）**：戦線Cの実行

## 9. やらないこと

1. 人単位で数字を詰めない（追うのはレバー・案件・領域の単位。工数の個人集計は出さない）
2. 数字だけを現場に降ろさない（伝え方は新谷が管理）
3. 精度を理由に報告を遅らせない（7割精度の仮数字で置き、翌月直す）
4. 承認を通らない投資はしない（実験→実証→投資のゲート、事前稟議）
5. 請求ベースの売上好調を「40億に効いている」と言わない（利益ベースの計器だけを信じる）
