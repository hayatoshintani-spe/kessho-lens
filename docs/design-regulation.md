# PROJECT HIKARI 資料 デザインレギュレーション

PROJECT HIKARI ディスカッション資料（en × TSUBURAYA）のデッキから抽出・整備したデザインレギュレーション。
v07_2 → v07_3 の再編集はすべて本レギュレーションに基づく。

## 基本仕様

| 項目 | 規定 |
|---|---|
| スライドサイズ | A4横（841.5 × 595.5 pt） |
| 和文フォント | Yu Gothic |
| 欧文フォント | Arial（ナビ・フッター・ラベル類） |
| 本文色 | `#171717` |
| 補助テキスト | `#666666` / `#929292` |
| 罫線・下線 | `#D5D5D5`（0.75pt） |
| 背景カード | `#F5F5F5` |

## セクションカラー

各章はアクセントカラーを持ち、「ナビのアクティブタブ」「タイトル左の縦バー」「章内の装飾」に一貫して使用する。

| 章 | 色 | 該当スライド |
|---|---|---|
| THESIS | `#E6005A`（ピンク） | 2–5 |
| DESIGN | `#7A164E`（プラム） | 6–15 |
| EVIDENCE | `#F25A2B`（オレンジ） | 16–24 |
| EXECUTION | `#E60012`（レッド） | 25–32 |
| DECISION | `#171717`（ダーク） | 33–42 |
| APPENDIX | 内容に応じた章色を再利用 | 43–51 |

## 共通レイアウト

- **ヘッダーナビ**（表紙以外）: THESIS / DESIGN / EVIDENCE / EXECUTION / DECISION の5タブ。
  非アクティブ = `#929292` + 下線 `#D5D5D5`（高さ 9,525 EMU）。
  アクティブ = 章色・太字 + 下線 章色（高さ 38,100 EMU）。**必ず1タブがアクティブであること。**
- **タイトル**: 26.25pt 太字 `#171717`、左に章色の縦バー。**1行に収める**（収まらない場合は 25pt に縮小）。
- **サブタイトル**: タイトル直下にグレー1行。
- **フッター**: 左 = TSUBURAYA FIELDS HOLDINGS、中央 = CONFIDENTIAL | DISCUSSION DRAFT、右 = スライド番号（2桁）。
- テキストはボックス・カード・帯の境界からはみ出さないこと。

## v07_2 → v07_3 の修正内容

1. **スライド33–40**: ナビのアクティブタブが全グレー（欠落）→ DECISION をアクティブ化（`#171717` 太字 + 太下線）。
2. **スライド3・14・25・33・51**: タイトルが1行に収まらず折返し → 25pt に縮小し1行化。
3. **スライド17**: 「示唆」帯のテキストがピンク帯の右端を超過 → 12.75pt（スライド21の帯と同サイズ）に統一。
4. **スライド29**: JOINT PMO の体制1行がボックスからはみ出し → 11.63pt に縮小。
5. **スライド34**: 黒帯右端「＝ 税別上限 4,400万円」が折返し・見切れ → テキストボックスを帯右端まで拡幅。
6. **スライド36**: 「映像」「IP」行の太字数量ラインが下段グレー行に重なり → ボックスをカード内余白まで拡幅。
7. **スライド40**: 「BAFO・選定」ラベルのボックス幅不足 → 拡幅 + 11pt。
8. **スライド50**: GATE 1 カードの「IDI 12 ＋ N=1,000」と下段3行の溢れ → 14.25pt / 8.75pt に調整。
9. **スライド33**: G3 カード「当該 1,400万円」が枠幅ぎりぎり → 11.25pt + 左右インセット0（中央揃えのためズレなし）。
10. **スライド1**: 「DISCUSSION WITH  en Inc.」の二重スペースを修正。

本文・数値・注記のコンテンツは一切変更していない（テキスト完全一致を検証済み）。
