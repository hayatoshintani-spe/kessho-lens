# 【極秘】TOPIX継続基準対応に関する論点整理

作成: 経営企画 新谷 ｜ 2026年7月11日 ｜ 宛先: 経営会議
出所: J.P.モルガン ディスカッション資料（2026/7/8受領）、公開資料
関連ナレッジ: `docs/knowledge/jpm-ir-proposal-2026-07.md`、`docs/knowledge/bandai-contracts-and-litigation.md`

## 0. サマリー（1分で読む）

**浮動株時価総額が次期TOPIX継続基準に約[60]億円不足しており、基準日2026/8/31まで残り7週間。**
執行系の打ち手（創業家売却）は8月上旬が意思決定リミットであり、**7月中に「今年残留を狙うか否か」の一次判断が必要。**
判断すべき論点は5つ。①Go/No-Go ②引くレバー ③執行手法 ④開示・IRナラティブ ⑤中期リレーティング戦略。
新谷の推奨: **論点①は「条件付きGo」＝創業家の売却許容が確認でき、かつディスカウント許容範囲なら執行。確認できなければ今年は静観し2027年入替に照準。** いずれの場合も④⑤は直ちに着手。

## 1. 前提事実（争いのない数字）

| 項目 | 数値 | 備考 |
|---|---|---|
| 浮動株時価総額 | [363.3]億円 | 2026/6/30終値ベース |
| 残留に必要な水準 | [423.0]億円 | 上位97%ライン（閾値は市場全体で変動する推定値） |
| 不足額 | **約[60]億円** | 株価換算では約+16.5%に相当 |
| 累積比率 | [97.35]% | 基準97.00%との差は0.35pt＝**僅差** |
| 基準日 / 入替日 | 2026/8/31 / 10/30 | 以降毎年（8月末基準・10月末入替） |
| 再算入の基準 | 上位96%以内 | **継続基準（97%）より厳しい。一度落ちると戻りにくい** |
| 浮動株比率 | 40% | 固定株＝創業家・関連会社等が約6割 |
| 足許の業績環境 | 3Q25で中国ライセンス収入減、4Q赤字見込み | 2026 YTD株価[▲22.1]% |

- 自己株取得: ⓑ↑だがⓐ↓で**ネット相殺**（効果はシグナリングのみ）
- 創業家・関連会社売却: **ⓐ↑（唯一の直接策）**
- 還元方針明確化・M&A・リレーティング: ⓒ↑（効くまで時間差）

## 2. 論点①【Go/No-Go】今年（8/31基準日）の残留を狙いにいくか

**問い**: 60億円ギャップを7週間で埋める執行を行うか、今年は静観して2027年に備えるか。

| | A案: 今年残留を狙う（執行） | B案: 静観し2027年に照準 |
|---|---|---|
| 根拠 | 除外時はパッシブの機械的売りが発生。再算入基準（96%）は継続基準より厳しく、**復帰のハードルが上がる** | 97.35%は僅差であり、8月末までの株価・閾値次第で**無施策でも残留の可能性**。4Q赤字見込み直後のディスカウント売出は高くつく |
| リスク | 決算悪材料直後の売出→需給悪化・「創業家の売り逃げ」と誤読される | 除外確定時の株価インパクトと、毎年恒常化する定期入替への後手対応 |

**判断に必要な材料（今週中に揃える）**:
1. 除外時インパクト試算: TOPIX連動パッシブの当社保有額・想定売り圧力（経営企画＋IR、証券会社に照会）
2. 感応度分析: 8/31株価±10%・閾値変動シナリオでの残留確率（JPMの[363.3]億/[423.0]億を独自検証）
3. 創業家・フィールズ関連会社の売却許容度（→論点②の前提。**非公式打診を最優先**）

**推奨**: 条件付きGo。1〜3が揃う7月下旬に最終判断。**「何もしない」も意思決定として記録に残す**（毎年基準日が来るため、静観の場合も論点④⑤は即時着手）。

## 3. 論点②【レバー選択】何で60億円を埋めるか

**問い**: 誰が・いくら・誰に売るか。自己株取得を併用するか。

- **主レバーは創業家・関連会社の株式売却一択**（浮動株数を直接増やせるのはこれのみ）。必要規模の目安: 不足[60]億円＋バッファ[2〜3]割 → **売出規模[70〜80]億円（時価総額の約8%）**。売出後の浮動株比率は40%→[47〜48]%程度
- 売却先の選択が中期戦略を規定する:
  - 機関投資家（幅広分売）= 純粋な浮動株化
  - **ストラテジック** = IP企業転換への提携カードになり得るが、新たな安定株主は浮動株にカウントされないリスクあり（**要確認: 売却先次第で目的を達成しない可能性**）
  - エンゲージメント・ファンド = M&A施策への圧力とセット
- **自己株取得の併用は慎重に**: 浮動株数を減らすため今回の目的とは逆方向。使うなら「売出時の需給下支え・シグナリング」として小規模に、目的（高ROE維持）を明記
- **留意（バンダイ関連）**: 売却対象はHD株であり円谷プロ株ではないため、フィールズ×バンダイ株主間協定（51:49、株主である限り有効）には直接抵触しない。ただしストラテジックへの売却がバンダイとの関係に与える示唆は事前に整理要

**推奨**: 機関投資家向けを軸に[70〜80]億円。ストラテジック案は中期論点として切り離す。

## 4. 論点③【執行手法・タイミング】8/31に間に合う手段は限られる

**問い**: どの売出方式で、いつ執行するか。

- オファリング系（グローバル/旧臨報/国内）は準備2〜3ヶ月 → **今回は物理的に間に合わない**
- 間に合うのは **海外機関向けデスク・ブロック（1〜2週間、対外公表なし）** と **ABB（オーバーナイト〜3週間）** のみ
- 逆算タイムライン:
  - 7月中旬〜: 創業家意向確認・FA決定・インサイダー管理体制
  - 7月末: 経営会議で執行判断
  - 8月上旬〜中旬: 執行ウィンドウ（1Q決算発表日程との整合・沈黙期間に注意）
  - 8/31: 基準日
- **FA選定**: JPM提案は「売出ありき」に寄る構造。少なくとも1社からセカンドオピニオンを取得し、手数料・ディスカウント水準を競わせる

**推奨**: 執行するならABB（貴社関与あり3-way、配分先に意向反映可）。1Q決算発表後の8月中旬をメインウィンドウに設定。

## 5. 論点④【開示・IRナラティブ】売出を「前向きな話」として成立させられるか

**問い**: 創業家売却をネガティブシグナルにしないための開示設計。

- 必須セット: **「TOPIX残留・流動性向上・投資家層拡大が目的」であることの明示**＋株主還元方針の明確化（高ROE維持・配当性向目標・EPS成長へのコミット）を同時公表
- 留意: 中計発表直後の資本政策変更には一定の抵抗感（JPM指摘）→「中計の実現可能性を高める流動性施策」として位置づける
- **中国リスクの説明力が株価回復の前提**: 株価下落の起点は中国ライセンス収入減。係争の現在地（東京三次訴訟一審勝訴 2026/5/14、北京二審敗訴→抗訴準備中、旧キャラのTPC/UMC利用可否整理）を投資家向けに翻訳した説明資料を整備し、「守られている権利／係争中の範囲」を能動開示する

**推奨**: 売出の有無に関わらず、還元方針明確化＋中国リスク説明資料は7〜8月中に実施（静観シナリオでもⓒP/E押し上げに寄与）。

## 6. 論点⑤【中期】パチンコ並み評価からIP企業への再評価（リレーティング）

**問い**: ROE 22.8%・P/E 6.5xの「高資本効率・低評価」から抜け出す道筋。

- JPM試算: 全社回帰線並みの評価なら想定時価総額[2,884]億円（現状比約3.2倍）。**リレーティングが実現すれば浮動株問題は恒久的に解消**（株価+17%で今回のギャップも消える）
- 施策候補: コンテンツ&デジタル事業のKPI開示強化（地域別ライセンス収入等）／EPS accretiveなM&A／IP企業としてのセグメント開示・比較対象の載せ替え
- **制約条件（要事前整理）**: 円谷プロレベルの資産・事業に踏み込む施策（重要資産の処分、M&A対象次第）は、バンダイとの株主間協定上「重要事項の両者合意」が必要。商品化権はバンダイ独占（国内玩具等）であり、MD施策の自由度に制約
- 毎年8月末が基準日となるため、**浮動株時価総額・累積比率の月次モニタリング**を経営ダッシュボード（kessho-lens）に組み込む

**推奨**: 9月までにリレーティング施策のロードマップを策定し、2027年入替を「守り」ではなく「攻め」の期限として設定。
