# 企画書:「ウルトラマン大好き芸人」

トークバラエティ番組の1企画(「○○大好き芸人」フォーマット)として、ウルトラマンシリーズを愛してやまない芸人たちが、その魅力を全力で語り倒す回の企画案。

---

## 1. 企画概要

| 項目 | 内容 |
| --- | --- |
| 企画名 | ウルトラマン大好き芸人 |
| 尺 | 60分(拡大時 90分) |
| 形式 | ひな壇トーク+VTR+実演コーナー |
| ターゲット | 30〜50代の特撮世代を中心に、子どもと一緒に観るファミリー層まで |
| 狙い | 「昭和・平成・令和」3世代にまたがるシリーズの厚みを活かし、世代間トークの化学反応を起こす。ニチアサ・特撮好き層のSNS拡散も見込む |

### 企画の勝ち筋
- ウルトラマンシリーズは1966年の初代から現在まで続いており、**出演者の世代によって「自分のウルトラマン」が違う**。この世代ギャップ自体が笑いとエモさの燃料になる。
- 怪獣・光線技・変身アイテムなど「語れる小ネタ」の物量が圧倒的で、トークが枯れない。
- 「子どもの頃の記憶」×「大人になって気づく深さ(特撮技術・脚本の社会性)」の二段構えで語れる。

---

## 2. 出演者構成(キャスティング方針)

実名キャスティングは制作サイドで調整するとして、役割ベースで6〜7名を想定。

1. **昭和第1期ガチ勢**(初代マン〜セブン推し):モノクロ時代の怪獣デザインや成田亨美術を熱く語れる最年長枠。
2. **昭和第2期育ち**(帰ってきたウルトラマン〜レオ推し):「レオのスパルタ特訓」など苦い記憶を笑いに変換できる枠。
3. **平成三部作の申し子**(ティガ・ダイナ・ガイア推し):「ティガは大人になって見返すと刺さる」を担当するプレゼン職人。
4. **ニュージェネ担当**(ギンガ以降):現行シリーズと映画・配信事情に強い若手。子どもと一緒に観ている「パパ・ママ目線」も兼務可。
5. **怪獣専門枠**:ヒーローよりも怪獣・宇宙人(バルタン星人、ゼットン、ジャミラ等)への愛が重い偏愛枠。
6. **にわか代表(MC側)**:視聴者目線の質問役。「ゾフィーって誰?」を聞ける空気を作る。

## 3. コーナー構成案

### オープニング:「俺のウルトラマン」自己紹介
各自が「人生で一番好きな1体」をフリップで発表。世代がバラけるほど良い。ここで各人のキャラ(推し世代・偏愛ポイント)を視聴者に提示する。

### コーナー1:あるある&トラウマトーク
- 「カラータイマーが鳴ると子どもながらに本気で焦る」
- 「ジャミラ回・ノンマルト回など、子ども番組とは思えない重い回に打ちのめされた話」
- 「変身アイテムを親に買ってもらえなかった/買ってもらった格差」
- スタジオには歴代変身アイテムの玩具を展示し、実演しながら語る。

### コーナー2:名場面プレゼン「この回だけは観てくれ」
各自が1話を選び、VTR+フリップで全力プレゼン。「実相寺昭雄回の映像美」「セブン最終回の音楽」など、笑いだけでなく本気の批評が混ざるのがこのフォーマットの美味しいところ。放送素材の使用許諾は円谷プロと要調整(後述)。

### コーナー3:ガチ勢クイズ「君はウルトラ検定何級?」
- 初級:「シュワッチ」と言うのは誰?/スペシウム光線のポーズは?
- 中級:ゼットンが初代マンに勝った時の技の名前は?
- 上級:科学特捜隊の本部はどこの国にある設定?
- にわかMCが脱落していく様子と、ガチ勢の即答っぷりの対比で笑いを取る。

### コーナー4:実演「光線技・変身ポーズ選手権」
全員でスペシウム光線・エメリウム光線・ワイドショットなどを実演し、「誰が一番それっぽいか」を競う。BGMと照明を本気で寄せると画になる。SNS切り抜きで最も拡散が狙えるコーナー。

### エンディング:「ウルトラマンから学んだこと」
最後は少しエモく締める。「3分しか戦えないからこそ全力を出す」「怪獣にも事情がある(ジャミラ、シーボーズ)」など、シリーズが子ども番組の枠を超えて伝えてきたメッセージを各自一言ずつ。

## 4. 美術・演出メモ

- ひな壇背景は科特隊/ウルトラ警備隊の基地風セット。テーブルには流星マークをあしらう。
- トーク中の効果音に変身音・カラータイマー音を使用(要許諾)。
- テロップは劇中フォント風にすると特撮ファンの好感度が上がる。
- ゲスト降臨サプライズ枠:スーツアクターや主題歌歌手、歴代主演俳優のVTRコメントが取れれば大きな山場になる。

## 5. 権利・考証まわりの注意

- ウルトラマンシリーズの映像・音源・キャラクター使用は**円谷プロダクションの許諾が必須**。VTR素材、玩具展示、効果音、フォント風テロップまで含めて事前確認する。
- 考証ミスは特撮ファンの信頼を一気に失うため、放送前に監修(円谷プロ側または特撮ライター)を入れる。
- 「どの作品を扱うか」は許諾範囲と連動するため、コーナー2のプレゼン作品は早めに確定させる。
