## 2. 環境認識 — なぜ今、HR業界に「動くためのインテリジェンス」が必要か

エン・ジャパン様の事業環境は、複数の構造変化が同時進行しています。

1. **生成AIによる採用プロセスの再定義**
   AI面接・スカウト自動生成・職務経歴書のAI作成が急速に普及。求人メディア・人材紹介のバリューチェーンそのものが問い直されている。
2. **スポットワーク市場の急拡大**
   タイミー、メルカリ ハロ等の台頭により「雇用の前段階」の労働市場が生まれ、従来の求人広告・派遣モデルと交差し始めている。
3. **規制の多発**
   職業安定法の的確表示義務、フリーランス新法、育成就労制度への移行、EU AI Act における採用AIのハイリスク分類など、事業に直結する法改正が国内外で相次ぐ。
4. **構造的な人手不足と労働移動の活発化**
   賃上げ・リスキリング・ジョブ型雇用・外国人材の受け入れ拡大が、中途採用市場・ハイクラス市場の地図を塗り替えつつある。

これらは毎日大量のニュースとして流れてきますが、**「エン・ジャパンの事業機会・リスク・経営論点」への翻訳**は、現状では各部門の属人的な情報収集に依存しがちです。ここを AI で仕組み化するのが本提案です。

## 3. 提案概要 — en Intelligence Brief とは

AI が HR業界の 7 カテゴリを監視・要約・解釈し、経営層・事業部長・経営企画に **Daily Intelligence Brief** として届けます。

```
外部情報（ニュース / 規制 / 技術 / 競合）
        │
        ▼  AI が毎日収集・選別
┌─────────────────────────────┐
│ IntelCard                                            │
│  事実 → 解釈 → エン・ジャパンへの示唆 → 次アクション │
│  重要度 A〜D で自動分類                              │
└─────────────────────────────┘
        │
        ▼  重要トピックは
┌─────────────────────────────┐
│ AI Council Session                                   │
│  6つの社内視点を持つ AI エキスパートが議論し、       │
│  採用 / 保留 / 要調査 の結論を出す                   │
└─────────────────────────────┘
        │
        ▼  毎朝 7:00 JST
  Daily Brief をメール自動配信 + ダッシュボード + Notion 同期
```

### 主要機能（既存基盤で実装済み）

- **Daily Brief** — 経営層向け要約 + 重要トピックス + 次アクション + 識別リスク
- **IntelCard DB** — 重要度 A〜D（経営アジェンダ / 事業部検討 / 共有 / 参考）で分類された記事カード
- **AI Council Session** — 6 エキスパートによる戦略議論と編集者の結論
- **Watchlist** — カテゴリ別の監視キーワード・対象企業
- **Notion 連携** — IntelCard を社内 Notion DB に自動同期
- **Daily Brief 自動配信** — 毎朝 7:00 JST に経営層へ自動メール配信

## 4. エン・ジャパン様向けカスタマイズ — 監視7カテゴリ

円谷プロダクション向けに実運用している 7 カテゴリ構造を、そのまま HR業界仕様に差し替えます。

| # | カテゴリ | 監視対象（例） | 主な観点 |
|---|---|---|---|
| 1 | **採用・転職市場** | 有効求人倍率、賃金動向、中途採用トレンド、新卒市場、リスキリング | どの職種・年齢層・地域で人材流動が起きているか。エン転職・AMBI・ミドルの転職の商機はどこか |
| 2 | **HRテック・AI** | AI面接、スカウトAI、ATS、適性検査、タレントマネジメント、生成AI各社 | 採用プロセスのどこがAIに置き換わるか。engage・3Eテスト・HR OnBoard に何を実装すべきか。脅威と提携機会の見極め |
| 3 | **競合・プラットフォーム** | リクルート（Indeed含む）、パーソル（doda）、マイナビ、ビズリーチ/Visional、LinkedIn、Wantedly、ディップ | 各社がどの領域・価格帯・体験で伸びているか。エン・ジャパンの差別化ポイント「入社後活躍」への影響 |
| 4 | **働き方の構造変化** | スポットワーク（タイミー、メルカリ ハロ）、副業・兼業、フリーランス、ジョブ型雇用、リモートワーク | 「雇用の形」の変化はどの事業に機会/脅威か。スポットワークと求人広告・派遣の交差点はどこか |
| 5 | **規制・労働法制** | 職業安定法、労働者派遣法、フリーランス新法、育成就労制度、労働基準法改正、個人情報保護、AI採用規制（EU AI Act 等） | 求人メディア・人材紹介・派遣の事業運営に影響する改正は何か。海外のAI採用規制は日本に波及するか |
| 6 | **グローバル人材・海外市場** | 外国人材（特定技能・育成就労）、海外HR市場、越境採用、en world 領域のエグゼクティブ市場 | 外国人材の受け入れ拡大はどの事業機会につながるか。海外HRサービスの成功モデルから何を学べるか |
| 7 | **資本市場・M&A** | HR業界のM&A・資金調達、競合決算、HR SaaS の評価額、株式市場のHRセクター評価 | 市場はどの事業モデル（メディア/紹介/SaaS/スポット）を評価しているか。エン・ジャパンの企業価値向上に何が必要か |

> カテゴリ・監視対象・観点はすべて設定ファイル（`categories.py` / Watchlist）で定義されており、運用開始後もエン・ジャパン様側の関心に合わせて随時調整できます。

## 5. AI Council — エン・ジャパン様仕様の6エキスパート

重要トピックについて、6 つの社内視点を持つ AI エキスパートが議論し、「採用 / 保留 / 要調査」の結論と論点を残します。

| エキスパート | 視点 | 主なキー・クエスチョン |
|---|---|---|
| 🧭 **求人メディア戦略** | エン転職・engage の中長期価値 | この動きで求人メディアの価値は上がるか下がるか。「入社後活躍」の思想を強める打ち手か |
| 🤝 **人材紹介・ハイクラス** | ミドルの転職・AMBI・en world | ハイクラス/ミドル市場のどこに商機があるか。紹介ビジネスのフィー構造への影響は |
| 🤖 **HRテック/AI** | プロダクトへの技術実装 | 今すぐ試せる技術はどれか。自社実装・提携・静観のどれが正解か |
| 🌏 **グローバル・新領域** | 外国人材・海外市場・スポットワーク | どの新領域に優先投資すべきか。組むべきパートナーは誰か |
| 💰 **CFO視点** | 収益性・投資対効果・資本配分 | 投資額に対して何年で回収できるか。既存事業のリソースを食わないか |
| ⚠️ **リスク管理** | 労働法制・個人情報・レピュテーション | 職安法・派遣法・個情法上のリスクはないか。求職者保護の観点で炎上リスクはないか |

> エキスパートの人格・専門性・キー・クエスチョンも設定ファイル（`experts.py`）で定義。貴社の実際の会議体（経営会議・事業戦略会議）の論点構造に合わせてチューニングします。

### 重要度分類（A〜D）

| 重要度 | ラベル | 意味 |
|---|---|---|
| **A** | 経営アジェンダ化 | 役員会・経営会議で議論すべき。投資・提携・重要リスクに関わる |
| **B** | 事業部で検討 | メディア・紹介・HRテック・海外など特定部署で企画・検証すべき |
| **C** | 情報共有 | 即時対応不要だが関連部署が知っておくべき |
| **D** | 参考情報 | 背景情報として蓄積 |

## 6. アウトプットイメージ

### IntelCard（例）

> **【HRテック・AI / 重要度 A】大手ATSベンダー、生成AIによる一次面接自動化を国内展開へ**
>
> - **事実**: 〇〇社が AI 面接官による一次選考の国内提供を発表。導入企業は選考工数を約6割削減と主張。
> - **解釈**: 「面接の前工程」が商品化されると、求人広告の後段にあった人材評価の付加価値がプラットフォーム側に移る。
> - **エン・ジャパンへの示唆**: 3Eテスト・動画面接資産と「入社後活躍」データを組み合わせた独自の評価レイヤーは差別化余地。一方、engage への競合機能搭載は時間の問題。
> - **次アクション**: HRテック部門で競合機能のギャップ分析。提携/自社開発の初期判断を4週間以内に。

### Daily Brief（毎朝 7:00 配信・例）

> **今日の要点（3行）**
> 1. AI一次面接の国内展開が本格化 — 評価レイヤーの主導権争いが始まった（重要度A・Council済み）
> 2. スポットワーク大手が正社員求人へ参入検討報道 — メディア事業と初の直接競合の可能性
> 3. フリーランス新法の運用指針改定案 — 紹介事業への影響は限定的、法務確認のみ
>
> **識別リスク** / **次アクション** / **本日のカード一覧（A: 2件, B: 5件, C: 8件）** …

## 7. システム構成・セキュリティ

```
frontend/   Next.js 14（Vercel）      … ダッシュボード・カードDB・Council閲覧
backend/    FastAPI + Claude API（Render） … 収集・要約・解釈・Brief生成
連携        Notion（社内ナレッジDB同期）、Resend（メール配信）
```

- **実績ある構成をそのまま利用**: 円谷プロダクション向けに日次運用中の基盤と同一アーキテクチャ
- **データ主権**: IntelCard・Brief は貴社専用環境の JSON / Notion に保存。将来的な Supabase / PostgreSQL 移行もストレージ層の差し替えのみで対応可能な設計
- **コスト暴走ガード**: 手動更新時の API 呼び出し上限ガードを実装済み
- **認証**: 配信・クロンエンドポイントはシークレットトークンで保護。社内限定公開（IP制限・Basic認証等）にも対応可能

## 10. 本提案のまとめ

1. **HR業界の構造変化（AI・スポットワーク・規制・人手不足）を、毎朝「エン・ジャパンの経営論点」に翻訳して届ける**
2. **円谷プロダクションで日次運用中の実績基盤を流用するため、低リスク・短期間（約4週間）で PoC 開始可能**
3. **カテゴリ・エキスパート・ウォッチリストは設定差し替えで貴社仕様化。「入社後活躍」の思想を判断軸に組み込んだ AI Council が意思決定を支援**

まずは Step 1 の要件ワークショップ（1〜2時間 × 2回）からのスタートをご提案します。
