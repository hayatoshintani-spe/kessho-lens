# 円谷フィールズホールディングス（2767）企業分析レポート

**作成日:** 2026年8月14日
**対象企業:** 円谷フィールズホールディングス株式会社（東証プライム / 証券コード 2767）
**作成方法:** Anthropic「Agents for financial services」で示された金融サービス向けエージェントのワークフロー（企業調査 → 決算分析 → バリュエーション・リスク検証 → レポート化）に沿って作成

---

## 1. エグゼクティブサマリー

- **2026年3月期は大幅な増収増益。** 売上高1,741億円（前期比+23.9%）、営業利益174億円(+14.1%)、純利益130億円(+17.0%)と過去最高水準の業績を達成。牽引役はアミューズメント機器事業（パチンコ・パチスロ関連）の市場シェア拡大。
- **2027年3月期は期初予想を早くも上方修正。** 第1四半期(2026年4-6月)は減収減益となったものの、通期予想を売上高1,870億円→2,053億円、営業利益190億円→225億円へ引き上げ。
- **株主還元を強化。** 2026年3月期の期末配当を50円→70円に増額。2027年3月期は年間140円配当(前期比+70円)を予定。
- **一方でコンテンツ事業には課題。** 中国におけるウルトラマンIPライセンス収入が規制強化・競合IP増加により10年ぶりに減少(前期比▲51.6%)。ウルトラマン生誕60周年(2026年)を契機とした中国市場の立て直しが焦点。

## 3. 業績分析

|---|---|---|

**ポイント**

## 5. コンテンツ＆デジタル事業（ウルトラマンIP）の論点

### 5.1 中国市場の減速

- 2026年3月期の中国向けウルトラマンIPライセンス収入は**25億57百万円(前期比▲51.6%)と10年ぶりの減少**。
- 要因は ①トレーディングカード市場への規制強化による調整 ②競合IPの増加による市場再編 ③日中関係の影響によるリアルイベントの延期・縮小。
- 中国はファン層1億人ともいわれる最重要海外市場であり、依存度の高さが露呈した形。

### 5.2 ポジティブ材料

- **ウルトラマン生誕60周年(2026年)**: 中国独占代理店の新創華文化発展(SCLA)と記念イベントを始動済み。中国市場立て直しの起爆剤として期待。
- **海外権利訴訟の決着**: 2026年5月14日、東京地裁がウルトラマンシリーズの日本国外利用権について円谷プロ側の主張を全面的に認める判決。約30年に及ぶ権利紛争に区切りがつき、海外展開の法的基盤が強固に。
- 東南アジアなど中国以外の海外市場への展開余地。

---

## 6. リスク要因

1. **遊技機市場への依存**: 収益の大半をアミューズメント機器事業が占め、パチンコ・パチスロ市場の規制動向やヒットタイトルの有無で業績が大きく振れる。
2. **中国市場・地政学リスク**: ライセンス収入の中国依存度が高く、規制強化や日中関係の悪化が直撃する構造。
3. **四半期業績の振れ**: 遊技機の販売スケジュールにより四半期ごとの業績変動が大きい(Q1の▲21.3%減収が典型)。
4. **IP競争の激化**: 中国国内外での競合キャラクターIPの台頭。

## 7. 総合評価

| 観点 | 評価 |
|---|---|
| 業績モメンタム | ◎ 通期上方修正、営業利益225億円(前期比+28.9%)見込み |
| 株主還元 | ◎ 年間140円配当(利回り約5.6%)、増配継続 |
| 成長ストーリー | ○ ウルトラマン60周年・権利紛争決着は追い風だが、中国回復は要確認 |
| リスク | △ 遊技機依存と中国依存の二重の集中リスク |

**結論:** アミューズメント機器事業の好調により短期の業績・還元面は非常に強い。中期的な企業価値の鍵は、コンテンツ＆デジタル事業が中国市場の落ち込みから回復し、「ウルトラマンIPのグローバル収益化」という第二の柱を再構築できるかにある。60周年施策の成果と中国ライセンス収入の底打ちを確認できれば、評価の切り上がり余地がある。
