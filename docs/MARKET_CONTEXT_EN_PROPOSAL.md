出典: [矢野経済研究所「人材ビジネス市場に関する調査(2025年)」](https://www.yano.co.jp/press/press.php/003942)

### 構造変化の読み方(提案の立脚点)

- 生産年齢人口の減少により、企業の採用難は景気循環ではなく**構造**になった
- 希少資源は「求人」ではなく「求職者」— 企業課金モデルの勝敗は**求職者への想起・好意**で決まる
- 単価の高い人材紹介(=「入社決定」ビジネス)が業界の利益成長を牽引 → 「入社決定数」がKPIとして重みを増す

## 2. 業界のプロモーション戦略(先例ファクト)

### ビズリーチ(同業界・最重要先例)

- TVCM放映前の人事担当者認知率 **9% → 放映後 60〜70%**
- 関東圏の人事における認知度: 2015年 10% → 2018年4月 **79%**
- CM出稿以前と比べ導入企業数 **約2倍**、事業売上 **3.4倍**、営業1人あたり売上3.2倍、受注リードタイム約半分
- 勝因: 「ビズリーーーチ!」という**一つの音と決めポーズ(=広告記号)** への集中投資

出典: [ダイヤモンド・オンライン](https://diamond.jp/articles/-/276371) / [SELECK](https://seleck.cc/1193) / [ビデオリサーチ VR Digest plus](https://www.videor.co.jp/digestplus/article/180823nakajima1.html)

### 通信業界(隣接業界の先例)

- ソフトバンク「白戸家」、au「三太郎」— 機能均質化した業界でキャラクター物語広告に年間数十億円規模を投資し、10年以上ブランド想起の上位を独占
- 示唆: **機能で差がつかない業界ほど「物語・キャラクター」が効く**

### 提案への翻訳

エンの選択肢は2つ:
1. ゼロから広告記号を育てる(ビズリーチは数年+巨額のGRPを要した)
2. **完成済みの国民的記号(ウルトラマン)を借りて業界で独占する(本提案)** — 「記号を作る時間」を金で買う

## 3. エン(旧エン・ジャパン)の中計・直近業績ファクト

### 中期経営計画(FY2023–2027、2022年5月策定)

- 基本方針: **「投資事業を既存事業と並ぶ規模にする5年間」** — engage・AMBIを投資事業と位置づけ次の柱に
- 最終年度(2027年3月期)目標: **売上高1,200億円・営業利益240億円**(2022年3月期の2倍強)

出典: [中期経営計画資料(2022/5/12)](https://s3-ap-northeast-1.amazonaws.com/enjapanhp/wp-content/uploads/20220713165427/MMP_2023-2027.pdf) / [エンIR資料室](https://corp.en-japan.com/IR/library.html)

### 直近業績(2025年3月期)— 提案タイミングの根拠

- エン転職の**広告宣伝費・販促費を前年比約▲20.2%**(投資効率化)→ 増益を確保
- 一方、国内求人サイト売上は**250億円(前期比▲15.0%)** — 「広告を絞れば利益は出るが成長も止まる」ことが数字で顕在化
- **FY2026(2026年3月期)方針: エン転職を中心に再強化、「入社決定数の増加」、マネタイズ多様化** → 広告再投資フェーズに入った

出典: [HRog決算解説(2025年3月期通期)](https://hrog.net/ir/129602/) / [ブリッジレポート 2025年3月期決算](https://www.bridge-salon.jp/report_bridge/archives/2025/07/250702_4849.html)

### 経営体制・会社概要

- **2025年4月、創業者・越智通勝氏が社長復帰**。背景は成長の停滞と企業価値の低下(時価総額はコロナ前2019年末の約2,400億円から800億円強まで減少、との報道)。会社発表は「変化の激しい事業環境において更なる企業価値向上を目指し、新たな体制による改革が必要と判断」
- **2025年10月1日、商号を「エン・ジャパン株式会社」から「エン株式会社(en Inc.)」に変更**。由来は創業以来大切にしてきた「縁」
- 越智社長は「おちめし」(週5日の社員ランチ会)など、人と対話を重視する経営スタイル

出典: [日本経済新聞(社員還元・おちめし記事)](https://www.nikkei.com/article/DGXZQOUC062JV0W5A500C2000000/) / [商号変更ニュースリリース](https://corp.en-japan.com/newsrelease/2025/43070.html)

## 4. 「越智さんに刺さるか」の検証と資料への反映

| 越智社長の関心(推定) | 根拠 | 資料での対応 |
|---|---|---|
| 企業価値の回復・改革の見える成果 | 社長復帰の公式理由が「企業価値向上への改革」 | スライド15「接続3: 企業価値・話題性」— 業界初の独占IP提携はIR/PRニュースになる |
| エン転職の再強化と入社決定数 | FY2026方針(通期決算説明) | 効果測定KPIを「入社決定数」に直結(スライド9・10・12) |
| 広告費の効率(前期に▲20%効率化した直後) | FY2025決算 | 「消える広告 vs 資産になる物語」の対比(スライド4・5)。段階投資(まず8,000万で実証)の設計 |
| 中計の柱 = 投資事業(engage・AMBI) | 中計基本方針 | PKG B「まちを守る仕事」をengage掲載企業獲得エンジンに、AMBIに「変身」文脈(スライド15) |
| 「入社後活躍」の思想 | 長年の同社の差別化軸 | コンセプト「変身して終わりじゃない=入社して終わりじゃない」(スライド7) |
| 「縁」への思い(社名変更の由来) | 商号変更リリース | むすび「縁と光」(スライド16) |

### 留意点(商談での言い回し)

- **時価総額の減少(▲66%)は資料に載せない** — 本人が最も痛感している数字。資料では「企業価値向上への改革」という本人の言葉に乗る形で前向きに扱う
- 広告費▲20%→売上▲15%の指摘は「学び」として敬意をもって提示(批判ではなく、再投資フェーズの根拠として)
- 金額(8,000万/2億)・独占条項は円谷プロダクションとの最終協議前提であることを必ず添える
