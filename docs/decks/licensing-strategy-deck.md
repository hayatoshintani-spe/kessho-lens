## スライド 4：現状認識（Market | 市場環境と機会）

**メッセージ:** ウルトラマンIPの顧客接点は、子ども・ファミリーから大人ファン・ライト層・海外へと広がっている。

- キャラクターMD市場の動向（子ども向け中心 → 大人向け・ライト層向けの高成長）
- 顧客層の広がり: 幼児・小学生・親子・女性ライト層・大人ファン・コレクター・プレミアム層
- 売場の多様化: 量販店・専門店・EC・公式店舗・ポップアップ

## スライド 5：基本方針（Policy | 「素材提供型」から「提案型」へ）

**メッセージ:** 素材を渡して終わるのではなく、パートナーが売りやすい形まで円谷が伴走する。

| 素材提供型（従来） | | 提案型（今後） |
|---|---|---|
| 依頼を受けて既存素材を提供 | → | 顧客・売場・価格帯から逆算した最適な提案 |
| 商品化の工夫はパートナー任せ | → | 商品化しやすい部品と販促プランをセットで提供 |
| 発売したら関与終了 | → | 発売前後のマーケティングまで一緒に実行 |

## スライド 6：営業戦略とクリエイティブ（Strategy | 営業戦略があるから、必要なクリエイティブが決まる）

**メッセージ:** クリエイティブは「あるものを渡す」のではなく、営業戦略から逆算して「必要なものを決める」。

- **従来型（素材起点）:**
  営業先が決まる → 「何か素材が欲しい」と依頼 → 既存素材を提供 → 相手側が商品化
- **今後型（戦略起点）:**
  顧客・市場分析 → ターゲット設定 → 商品・価格・売場設計 → 必要なアートを選定・開発 → 販促・デジタルまで一体提案
- ビジュアル: 上下2段のフロー図。従来型は途切れる矢印（円谷の関与が素材提供で終了）、今後型は最後まで続く矢印（一体提案）で対比

## スライド 7：スタイルガイド戦略 全体像（Style Guide | 「商品化部品庫」という考え方）

**メッセージ:** スタイルガイドは完成されたキービジュアル集ではなく、顧客・商品・ターゲットに応じた最適な提案を組み立てるための「商品化部品庫」。

- 3階層の部品を組み合わせて、案件ごとに最適解を構成する:
  1. **ターゲット**（誰に売るか）
  2. **商品カテゴリー・利用シーン**（何をどこで使うか）
  3. **ルック＆フィール**（どんな表現で見せるか）
- メインコピー: **「同じウルトラマンでも、相手の顧客・売場・価格帯によって、最適な提案は変わる。」**
- ビジュアル: 3層の引き出し棚（部品庫）から部品を取り出して1つの商品提案に組み上がるイメージ図

## スライド 8：階層①ターゲット（Layer 1 | ターゲット）

**メッセージ:** ターゲットが変われば、選ぶキャラクター・色・言葉のすべてが変わる。

| ターゲット | 特徴・狙い |
|---|---|
| 幼児 | 親が購入決定者。安心感・かわいさ・わかりやすさ |
| 小学生 | 本人が選ぶ。ヒーローのかっこよさ・番組連動 |
| 親子 | 一緒に楽しむ。共有体験・思い出づくり |
| 女性ライト層 | キャラクターを「デザイン」として楽しむ。ファンシー・雑貨性 |
| 大人ファン | 作品愛・世代の記憶。シリーズ・怪獣への深い理解 |
| コレクター | 希少性・網羅性。限定・シリアル・仕様へのこだわり |
| プレミアム層 | 上質・ミニマル。日常で使える大人のデザイン |

## スライド 9：階層②商品カテゴリー・利用シーン（Layer 2 | 商品カテゴリー・利用シーン）

**メッセージ:** 同じ表現でも、商品カテゴリーと利用シーンによって最適なアートの形は異なる。

- 商品カテゴリー: **玩具 / 文具 / 食品 / 水筒・ランチ用品 / アパレル / 雑貨 / ホビー**
- 販促・コミュニケーション: **店頭販促 / 広告 / デジタル**
- 各カテゴリーごとに、必要なアート仕様（展開図対応・小面積対応・パッケージ用・動画用など）を部品として整備

## スライド 10：階層③ルック＆フィール（Layer 3 | ルック＆フィール）

**メッセージ:** ウルトラマンは1つの顔ではない。10のルックで、あらゆる顧客・売場に対応する。

| ルック | 表現の方向性 |
|---|---|
| 王道ヒーロー | 番組そのままのかっこよさ。戦闘ポーズ・必殺技 |
| クール | シルエット・ラインアート・モノトーン |
| かわいい | デフォルメ・2頭身・にこにこ表情 |
| ファンシー | パステル・手描き風・雑貨向け |
| レトロ | 昭和シリーズのアートワーク・ノスタルジー |
| ストリート | グラフィティ・ビッグロゴ・アパレル向け |
| 怪獣・ヴィラン | 怪獣を主役に。個性・ユーモア |
| プレミアム | 上質素材前提のミニマルデザイン |
| メカ・防衛隊 | 科特隊・メカニック・エンブレム |
| 映画連動 | 最新映画のキーアート・期間限定展開 |

## スライド 11：3階層の組み合わせ方（Combination | 組み合わせで最適解を作る）

**メッセージ:** 同じ商品カテゴリーでも、ターゲットが変われば最適な部品の組み合わせは変わる。

- 組み合わせマトリクスの例:

| ターゲット × 商品 | 選ぶルック | 想定売場・価格帯 |
|---|---|---|
| 幼児 × 玩具 | かわいい | 量販店・低〜中価格 |
| 小学生 × 文具 | 王道ヒーロー | 量販店・文具店・低価格 |
| 女性ライト層 × 雑貨 | ファンシー / レトロ | 雑貨店・バラエティショップ・中価格 |
| 大人ファン × ホビー | 王道ヒーロー / 怪獣・ヴィラン | 専門店・EC・中〜高価格 |
| プレミアム層 × アパレル | クール / プレミアム | セレクトショップ・高価格 |

- メインコピー再掲: **「同じウルトラマンでも、相手の顧客・売場・価格帯によって、最適な提案は変わる。」**

## スライド 12：ケーススタディ：水筒・ボトル3種比較（Case Study | 同じ「水筒」でもここまで変わる）

**メッセージ:** 同じ水筒というカテゴリーでも、ターゲットによって使用キャラクター・カラー・アート・ロゴ・表現のすべてが変わる。

- ビジュアル: 3本の水筒・ボトルを横並びで比較（左から幼児向け→小学生向け→大人向け）

| | 幼児向け水筒 | 小学生向け水筒 | 大人向けボトル |
|---|---|---|---|
| 使用キャラクター | デフォルメしたウルトラマン＋人気かいじゅう | 最新シリーズのヒーロー＋怪獣（戦闘シーン） | 初代ウルトラマンのシルエット／科特隊エンブレム |
| カラー | 明るいパステル・ビビッド | ヒーローカラー（赤×シルバー×ブルー） | モノトーン＋ワンポイントの赤 |
| アート | 2頭身・にこにこ表情・総柄 | 戦闘ポーズ・必殺技エフェクト・大胆な構図 | ミニマルなラインアート・ロゴグラフィック |
| ロゴ | ひらがな・丸ゴシック・大きく | 番組ロゴをそのまま・目立つ配置 | 英字「ULTRAMAN」小さく控えめに |
| 表現（ルック） | かわいい／ファンシー | 王道ヒーロー | クール／プレミアム |
| 売場・価格帯 | 量販店・ベビー用品店 | 量販店・スーパー | 雑貨店・セレクトショップ・EC |

## スライド 13：提供形態と運用（Delivery | 商品化しやすい形で届ける）

**メッセージ:** 素材を渡すだけでなく、商品化しやすい形にする。

- 提供物: 商品カテゴリー別テンプレート（展開図対応データ）、カラーパレット、ロゴバリエーション、使用ルール、売場・販促イメージ
- 運用: 案件ヒアリング → 3階層から部品を選定 → 商品化提案パッケージとして提供 → 商品化後の販促まで接続（スライド14へ）
- メインコピー: **「素材を渡すだけでなく、商品化しやすい形にする。」**

## スライド 14：デジタルマーケティング戦略 全体像（Digital | 商品化した後も、円谷が一緒に市場へ届ける）

**メッセージ:** デジタルマーケティングは特定カテゴリーの施策ではなく、全ライセンシーに対する円谷の支援機能。

- タイトル: **「商品化した後も、円谷が一緒に市場へ届ける」**
- 対象: ゲーム・プラットフォーム向け提案に限定せず、**全ライセンシー・全商品カテゴリー**が対象
- 商品発売を3段階で支援:
  1. **発売前** — 期待を作る
  2. **発売時** — 話題を最大化する
  3. **発売後** — 拡散と購買を伸ばす
- メインコピー: **「商品を発売するだけでなく、"売れる瞬間"を一緒に作る。」**
- ビジュアル: 発売日を中心とした時間軸の山型グラフ（期待の醸成→ピーク→ロングテール）

## スライド 15：発売前：期待を作る（Phase 1 | Before Launch）

**メッセージ:** 発売日を「知らせる」のではなく、発売日までに「待ち望まれる」状態を作る。

| 施策 | 内容 |
|---|---|
| ティザー投稿 | 円谷公式SNSでのシルエット・チラ見せ投稿 |
| 商品開発ストーリー | 開発者・デザイナーの想いを発信し、商品に物語を持たせる |
| インフルエンサー先行体験 | 発売前サンプル提供・先行レビュー |
| 予約・抽選告知 | 予約開始・抽選販売の告知で初速を確保 |
| ファン投票 | カラー・デザインをファン参加で決定し、当事者化する |

## スライド 16：発売時：話題を最大化する（Phase 2 | Launch）

**メッセージ:** 発売日を「イベント」に変え、オンラインとリアルの両方で話題の瞬間風速を最大化する。

| 施策 | 内容 |
|---|---|
| 円谷公式SNS | 公式アカウントからの発売告知・拡散 |
| ULTRA MART | 旗艦拠点での展開・限定企画（スライド18参照） |
| インフルエンサー投稿 | 発売日に合わせた一斉投稿 |
| ライブ配信 | 発売記念配信・開封実演 |
| 店頭イベント | 発売記念イベント・体験企画 |
| ヒーロー登場 | キャラクター登場イベントで店頭を目的地化 |
| 限定・先行販売 | 「ここでしか買えない」「今しか買えない」を設計 |

## スライド 17：発売後：拡散と購買を伸ばす（Phase 3 | After Launch）

**メッセージ:** 買った人の声を次の購買につなげ、発売の熱をロングテールの売上に変える。

| 施策 | 内容 |
|---|---|
| 購入者投稿 | ハッシュタグ企画で購入報告を促進 |
| UGC活用 | ファンの投稿を公式が紹介し、二次拡散を生む |
| EC誘導 | 話題からECへの導線を整備し、機会損失を防ぐ |
| 再入荷告知 | 品切れ・再入荷情報で購買意欲を維持 |
| 利用シーン投稿 | 「使っている風景」の発信で日常需要を喚起 |

## スライド 18：ULTRA MARTの役割（Flagship | 原宿で話題を作り、全国の売場へ広げる）

**メッセージ:** ULTRA MARTは全商品を売る総合店舗ではなく、新規層と話題を生み出す「発信・実験拠点」。

| 役割 | 内容 |
|---|---|
| ① 新規層の開拓 | 女性・若年層・ライト層など、従来接点の薄かった層との出会いの場 |
| ② 話題化 | 限定販売・先行販売・インフルエンサー施策で話題の起点を作る |
| ③ 全国への波及 | ここで生まれた話題・実績を既存の量販店・専門店・EC・公式店舗へ広げる |
| ④ テストマーケティング | 新しい商品・デザインを小ロットで試し、反応をデータで検証する |

- メインコピー: **「原宿で話題を作り、全国の売場へ広げる。」**
- ビジュアル: ULTRA MARTを中心に、話題・実績が全国チャネルへ波及する同心円マップ

## スライド 19：流通戦略：3軸のチャネル設計（Channel | 3軸で顧客に届ける）

**メッセージ:** チャネルごとに役割を分け、3軸で市場全体をカバーする。

| チャネル軸 | 役割 | 主な売場 | 主なターゲット |
|---|---|---|---|
| ① 公式・専門店チャネル | 深いファンへの確実なリーチ。高付加価値・限定商品 | 公式店舗・公式EC・ホビー専門店 | 大人ファン・コレクター |
| ② 一般流通チャネル | 量とリーチの最大化。定番商品の安定供給 | 量販店・スーパー・文具店・雑貨店 | 幼児・小学生・親子 |
| ③ ULTRA MART中心の新規層開拓チャネル | 新規層との接点創出・話題化・テストマーケティング | ULTRA MART・ポップアップ・コラボショップ | 女性ライト層・若年層 |

- 3軸は独立ではなく連動: ③で生まれた話題・検証結果を①②の売場提案に還流する

## スライド 20：監修・ナレッジ活用（Support | パートナー支援としての監修）

**メッセージ:** 監修を「通過すべき関門」から「商品の質を上げる支援」へ。知見を仕組み化してパートナーに還元する。

| 取り組み | 内容 |
|---|---|
| 過去監修事例の蓄積 | 過去の監修判断・修正事例をデータベース化 |
| 判断基準のデータ化 | 表現ルール・判断基準を明文化し、ブレのない監修を実現 |
| 素材検索性の向上 | 部品庫（スタイルガイド）と連動した素材検索基盤 |
| AIを活用した一次確認・検索支援 | 類似事例検索・ガイドライン照合をAIが支援し、確認を高速化 |
| 最終判断は専門担当者が実施 | AIは支援に徹し、品質責任は専門担当者が担保 |
| 営業・監修・制作間の情報共有 | 案件情報を三者で共有し、手戻りなく提案から監修まで接続 |

- メインコピー: **「知見を人に閉じず、仕組みとしてパートナー支援に活かす。」**
- 効果: 監修スピード向上 → パートナーの商品化リードタイム短縮 → 提案型ビジネスの回転数向上

## スライド 21：推進体制（Team | 推進体制）

- プロジェクトリーダーの下に3機能:
  - **クリエイティブ・スタイルガイドチーム**（部品庫の整備・案件別提案パッケージ作成）
  - **デジタルマーケティングチーム**（発売前後の3段階支援・ULTRA MART連動企画）
  - **監修・ナレッジチーム**（監修DB・AI支援基盤・情報共有の運用）
- 営業（ライセンス営業）が3チームのハブとなり、パートナーへの一体提案を実行
- 注記: 制作・システム開発の一部は外部パートナーと連携

## スライド 22：ロードマップ（Roadmap | 段階的に立ち上げる）

| フェーズ | 期間 | 主な取り組み |
|---|---|---|
| Phase 1: 基盤整備 | 〜3ヶ月 | 部品庫の骨格設計（3階層の分類確定）／監修事例のデータ化着手／重点カテゴリー（水筒・ランチ用品等）でパイロット提案 |
| Phase 2: 実装・検証 | 4〜9ヶ月 | 部品庫を主要カテゴリーへ拡充／発売3段階支援を主要案件で実施／ULTRA MARTでテストマーケティング開始 |
| Phase 3: 全面展開 | 10ヶ月〜 | 全ライセンシーへの標準サービス化／AI監修支援の本格運用／チャネル3軸の連動運用 |

## スライド 23：期待効果・KPI（Impact | 期待効果）

| 領域 | KPI例 | 狙い |
|---|---|---|
| 営業 | 提案型案件比率／案件あたり提案リードタイム | 素材提供型からの転換度合いを測る |

| ULTRA MART | 新規層来店比率／テスト商品の全国展開転換率 | 発信・実験拠点としての機能 |
| 監修 | 監修リードタイム／手戻り率 | パートナー支援スピード |

## スライド 24：サマリー再掲・クロージング

- 4つの柱を1枚で再掲:
  1. **営業戦略起点のクリエイティブ** — 営業戦略があるから、必要なクリエイティブが決まる
  2. **商品化部品庫としてのスタイルガイド** — 「同じウルトラマンでも、相手の顧客・売場・価格帯によって、最適な提案は変わる。」
  3. **全ライセンシーへのデジタルマーケティング支援** — 「商品を発売するだけでなく、"売れる瞬間"を一緒に作る。」
  4. **仕組み化された監修・ナレッジ** — 「知見を人に閉じず、仕組みとしてパートナー支援に活かす。」
- クロージングメッセージ: **「商品化した後も、円谷が一緒に市場へ届ける。」**
- ネクストステップ: パイロットカテゴリーの選定／部品庫3階層の詳細設計キックオフ
