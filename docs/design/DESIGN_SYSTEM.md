# デザインシステム「HENSHIN」— 円谷 シネマティック・ダーク

スライド・レポート・HTML アーティファクトなど、このプロジェクトから出す
**すべてのビジュアルアウトプットの標準デザイン**。
基準実装は `docs/proposals/rokid-ultraman-pitch.pptx`（ソース: `tools/design-kit/decks/rokid-ultraman-pitch.js`）。

## コンセプト

特撮映画のティザーのような、漆黒×発光のシネマティックトーン。
モチーフは**カラータイマー**（赤く発光するリング＋青いコア）。

## カラーパレット

| 役割 | 色 | Hex |
|---|---|---|
| プライマリ（ウルトラレッド） | 赤 | `C8102E` |
| 強調赤（発光・見出し強調） | 明るい赤 | `E8354F` |
| アクセント（カラータイマー青） | シアンブルー | `2EA8E0` |
| 背景ベース | 漆黒 | `0A0C11` |
| カード面（ガラス） | 濃紺黒・透過14% | `141926` |
| カード輪郭線 | 暗グレー | `2A3140` |
| 本文（主） | 白 | `FFFFFF` |
| 本文（副） | シルバー | `AEB6C4` |
| 弱テキスト・キャプション | グレー | `78808F` |
| ゴースト文字 | 沈み紺 | `181E2B` |
| 推奨カード枠 | 赤枠 `C8102E` 1.5pt + 赤グロー | — |

配分の目安: 漆黒背景が支配（60-70%）、白/シルバーのテキスト、赤は強調にのみ。青はカラータイマーのドットと最終ノードなど「点」でのみ使う。

## タイポグラフィ

| 用途 | フォント | サイズ |
|---|---|---|
| 和文タイトル | Yu Gothic Bold | スライドタイトル 28pt / 表紙 60pt |
| 和文本文 | Yu Gothic | 11–13.5pt、lineSpacing 15.5–23 |
| 英字キッカー | Arial Bold, charSpacing 4 | 10.5–11pt |
| 英字ディスプレイ（ゴースト・数字） | Arial Black | ゴースト 100–130pt / カード数字 44pt |

## 反復モチーフ（全ページ共通）

1. **キッカー**: 左上に青の発光ドット（0.1in, glow）＋ `NN / LABEL` 形式の英字（例 `05 / PROMOTION`）
2. **ゴーストタイポ**: 背景右上に超大型英字（`181E2B`、右寄せ）で奥行きを出す（例 1967 / WHY / 2026 / PLAN）
3. **ガラスカード**: 角丸 0.1、透過フィル＋1pt輪郭線。推奨・強調カードは赤枠＋赤グロー
4. **発光**: キーコピー・価格・大数字に赤グロー `{size:9, opacity:0.45, color:C8102E}`。アイコン円・タイムラインのドットにも同系の外側シャドウ
5. **アイコン**: 白抜きアイコン（react-icons/fa）を赤い正円＋赤グローの上に載せる
6. **ビーム**: 表紙とクロージングに、中心が白く光る水平ビーム画像
7. **ページ番号**: 右下 `02` 形式、グレー10pt

## 背景

単色塗りではなく、SVG からレンダリングしたグロー背景画像を全面に敷く:
- `bg_hero.png` — 表紙・クロージング用（右に強い赤グロー）
- `bg_dark.png` — 本文ページ用（右上に弱い赤グロー＋ビネット）
- `ring.png` — カラータイマーリング（透過、表紙・カード内で使用）
- `beam.png` — 光線ビーム（透過）

アセットと再生成スクリプトは `tools/design-kit/` にある。

## レイアウト規則

- 13.33 × 7.5in（LAYOUT_WIDE）、余白 0.7in
- 本文は左揃え。中央揃えはタイトル・スタット数字のみ
- カード間ギャップ 0.18–0.21in で統一
- 統計は「箱」ではなく細い区切り線＋大数字（白）＋単位（赤）のマガジンスタイル
- タイムラインは発光ドット（赤、最終ノードのみ青）＋上下ラベル

## 使い方

新しいスライドを作る場合:

```bash
cd tools/design-kit
npm install pptxgenjs react-icons react react-dom sharp   # 初回のみ
node gen_art.js    # art/*.png を再生成（コミット済みならスキップ可）
node gen_icons.js  # icons/*.png を再生成（同上）
node decks/rokid-ultraman-pitch.js   # 基準実装。新デッキはこれを複製して作る
```

HTML アーティファクト・レポートに適用する場合も同じパレット・タイポ階層・
ガラスカード・グロー表現を踏襲する（ダークテーマを既定とする）。
