# 📸 AI投資ファンド スクリーンショット

実機で動作させた状態のスクリーンショットです。ローカルでバックエンド (FastAPI) とフロントエンド (Next.js) を起動し、各ページを Playwright で撮影しました。

各ページにつき **デスクトップ版 (1440×900)** と **モバイル版 (390×844 @2x)** を用意しています。
