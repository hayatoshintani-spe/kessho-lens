## 冒頭30秒（つかみ）

> 「本日お願いしたいのは、ウルトラマンを使うことではありません。御社とウルトラマンの相性を、私たちの思い込みではなく**生活者データ**で確かめてきました。今日はその結果からお話しさせてください。」

## 進行の山場（3つ）

1. **P.4 最初の発見** — 「ロッテの強い購買文脈と、ウルトラマンの強い文脈が、データ上重なっていた」。ここで身を乗り出してもらう。スコアの意味を聞かれたら「競合との相対差です。詳細はAppendixに」で流す
2. **P.6 本命はコアラのマーチでした** — 結論先出し。4軸のカードはBEST FITだけ説明。**P.9「+9.57」と「食べるウルトラ図鑑」**で企画の骨格を一言で伝える
3. **P.13 「3分間を、たべよう。」** — ここまでULTRA 3MIN.を我慢するのが今回の設計。P.12「では、次の習慣は何か。」で一拍置いてから開く。「実現できます」とは言わず「**御社の研究部門と検証したい仮説**」で通す

## 想定問答（口頭用の短い返し）

- **「このスコアはどう出した？」「6.19ってどういう意味？」** → 「0を基準とした競合比の相対値で、正の値が大きいほどそのきっかけを競合より強く独占していることを示します。偏差値に近い相対指標で、絶対値そのものに単位はありません。算出手法はAppendix P.20に」※詳細ロジックはアライド社に確認中。深掘りされたら「分析パートナーと共に正確な定義をお持ちします」で持ち帰る
- **「YoYの+80%とかは何が伸びている？」** → 「ウルトラマン関連の発話の中で、その文脈の発話数が2024年→2025年の1年間で伸びた割合です。IP自体がいま熱を持っている証拠です」
- **「コアラのマーチでなぜウルトラマン？」** → 「『絵柄を楽しみながら食べたい』が+9.57と突出した独占文脈で、そこに60年×約2,500種の絵柄資産がそのまま刺さるからです。データが選んだ組み合わせです」
- **「変身なら仮面ライダーでは？」** → 「データでもライダーはコラボ文脈で強い。ただ『周年記念』はウルトラマンが+7.46で独占（ライダーは-0.26）。60周年起点の本提案はウルトラマンの土俵です（Appendix P.23）」
- **「ULTRA 3MIN.は本当に作れるのか？」** → 「技術検証したい仮説です。だからこそ、いきなり作らず、コアラのマーチで実証してから判断いただく設計にしています」
- **3分の語り方（重要）** → 主軸は「**3分で気分が変わる**」（キリッとする／やるぞのスイッチ／すっと落ち着く）。味や色の変化は「検証仮説の一つ」として添える程度に。**形態はグミ第一候補**——ロッテはガム縮小を受けてグミへ生産・投資をシフトしており、この文脈に乗せて語る
- **「アライドアーキテクツの役割は？」** → 「生活者データで仮説と成果を検証する分析パートナーです。企画の主役は御社と円谷です」
- **「今日決めることは？」** → 「方向性の合意と、コアラのマーチを題材にしたワークショップの設定だけです。商品化の判断は実証データを見てからで構いません」

## 本日の実質ゴール（社内認識）

玉塚社長からの**商品化の即決は狙わない**。狙いは「面白い、現場で検討させる」と言わせること——つまり**コアラのマーチ担当・マーケティング・研究部門への接続指示**を引き出せれば勝ち。ワークショップ設定（お願い②）はその受け皿。
