## 提案の骨子（1分で思い出す用）

- **コラボではなくカテゴリー創造**。ビックリマン（収集の習慣）・おーいお茶（購買の習慣）に続く「変身菓子」カテゴリーを両社で発明する
- **本命『ULTRA 3MIN.』**：噛んで3分、味と色が変身するガム＆グミ。カラータイマーの3分間を口の中に再現。キャッチコピーは「3分間を、たべよう。」（変身はライダーと競合するため、3分に重心）
- **なぜ今**：2026年はシリーズ60周年、『ウルトラマンテオ』世界同時放送中。ロッテ側はガム縮小・グミ逆転で旗艦カテゴリーが必要な局面
- **道筋**：2026年度内ウルトラマンマンチョコ（先行弾）→ 2027年ULTRA 3MIN.全国発売 → 2028年〜アジア展開＋ULTRA CHARGE（大人市場）
- **本日のゴール**：方向性合意とNDA・共同ワークショップの設定
