## A. ロッテ自身がカテゴリークリエイターの常連である（最重要・冒頭で使う）

「カテゴリー創造はロッテのDNAそのもの」と示せる事例群。提案の説得軸を「外部の成功例に学ぶ」から「御社の勝ちパターンを最新IPで再現する」に転換できる。

| 商品 | 年 | 発明したカテゴリー | ポイント |
|---|---|---|---|
| **ビックリマンチョコ** | 1977（悪魔VS天使は1985） | シール食玩・収集型菓子 | オリジナルキャラのシールで「集める文化」を発明。最盛期年間4億個、「お一人様3個まで」が社会現象に |
| **ホカロン** | 1978 | 使い捨てカイロ市場 | 先行技術は旭化成(1975)だが、全国流通と商品名で市場を定義したのはロッテ電子工業。「発明者より、カテゴリーを定義した者が勝つ」の教科書 |
| **雪見だいふく** | 1981 | 冬アイス・餅アイス | 「冬はアイスが売れない」という業界常識の逆転から誕生。和菓子×アイスの新形態 |
| **キシリトールガム** | 1997 | 機能性ガム（オーラルケア菓子） | 「ガムは歯に悪い」の常識を「歯にいいガム」に反転。歯科界を巻き込んだエビデンス戦略で、現在もガム市場シェア6割の源泉 |
| **クーリッシュ** | 2003 | 飲むアイス | ゼリー飲料用チアパック容器の転用で「歩きながら飲めるアイス」を発明。2004年SIAL世界ヒット商品コンクールでアジア食品初の最高賞 |
| **乳酸菌ショコラ** | 2015 | 機能性チョコレート | 「乳酸菌はチョコで摂る時代へ」。チョコで乳酸菌を胃酸から守る技術で発売半年20億円。※広告表現は後に当局の指摘を受けており、機能訴求のエビデンス管理が肝要という内部教訓も |

→ **玉塚社長への刺し方**:「ビックリマン、ホカロン、雪見だいふく、キシリトール、クーリッシュ、乳酸菌ショコラ。御社は約10年ごとにカテゴリーを発明してきました。次の一手を、ウルトラマン60周年と一緒に打ちませんか」

## B. 「IP×収集×食品」の直系事例（本提案の家系図）

『ULTRA 3MIN.』の収集エンジン設計に直結する系譜。**成功例と失敗例の両方**から設計原則を抽出できる。

- **仮面ライダースナック（カルビー、1971）** — カード付きスナックの元祖にして「変身ブーム」の申し子。発売直後から品切れ続出、1972年2月時点で1日100万袋、**15ヶ月で6億2000万袋・約87億円**。一方で「カード目当てでスナックを捨てる」社会問題も発生 → **教訓: おまけが主役化しすぎると炎上する。菓子体験そのものが本体であるべき**（ULTRA 3MIN.が「食べる体験＝変身」を中核に置く理由）
- **プロ野球チップス（カルビー、1973〜現在）** — 仮面ライダースナックの仕組みを「終わらないコンテンツ（プロ野球）」に接続し、50年超の長寿カテゴリー化に成功
- **ビックリマン（ロッテ、1985）** — 借り物IPではなくオリジナルキャラで頂点へ。キャラ・世界観を自社資産化したことが長寿の鍵
- **キンダーサプライズ（フェレロ、1974・グローバル）** — 玩具入り卵型チョコの世界標準。世界数十カ国で50年継続する「開封のドキドキ」の国際実証
- **たまごっち（バンダイ、1996）** — 「育成を持ち歩く」カテゴリーの発明。1年足らずで1000万個。ただしブーム急落で約60億円の特別損失 → **教訓: ブームの熱狂は資産でなく負債になり得る。供給管理と「ブーム後の日常需要」の設計が必須**
- **ポケモンパン デコキャラシール（第一パン、1998〜現在）** — シール付きパンで25年以上・195弾継続。派手なブームではなく「毎月の定番」として親子二世代を回し続ける**長寿設計のお手本**
- **チョコエッグ（フルタ製菓、1999）** — 海洋堂の造形力で「大人が集める食玩」を発明。キャラものでなく動物フィギュアで社会現象化 → 造形クオリティが大人を動かす証明
- **妖怪ウォッチ×妖怪メダル（バンダイ、2014）** — 玩具×ゲーム×映像連動の「フィジタル」先行例。ピーク年度売上522億円、店頭は連日行列。しかしIP人気の減速とともに売上はピークの9分の1へ → **教訓: フィジタル連動は爆発力があるが、単一タイトルの寿命に運命を預けると急落する。60年続くウルトラマンの「シリーズ構造」（毎年新ヒーロー×歴代資産）はこのリスクへの構造的な答えになる**
- **ポケモンカードゲーム（1996〜現在）** — 収集×対戦で30年継続、近年は大人の投資的収集も巻き込む。「子ども向け収集物は大人市場に育つ」実例

## C. 食品・飲料のカテゴリークリエイター（古典）

### 常識の反転型
- **おーいお茶（伊藤園、缶1985→改名1989）** — 「お茶は家で淹れるもの」を「緑茶は買うもの」に反転。無糖飲料市場そのものを開拓
- **キリンフリー（キリン、2009）** — 世界初アルコール0.00%。「ビールもどき」を「運転者が堂々と飲むもの」に反転し、ノンアル市場を創出
- **ハーゲンダッツジャパン（1984）** — 「アイスは子どものおやつ」を「大人のご褒美」に再定義し、プレミアムアイス市場を創出

### 容器・形態の発明型
- **チキンラーメン（日清、1958）／カップヌードル（1971）** — 即席麺、そして「カップ＝食器」の発明。世界の食習慣を変えた日本発カテゴリー創造の頂点
- **inゼリー（森永製菓、1994）** — 缶飲料の失敗（ウイダーinドリンク）を経て、スパウト付きパウチで「10秒チャージ」のゼリー飲料カテゴリーを確立
- **午後の紅茶（キリン、1986）** — 紅茶液の変色を防ぐ技術でペットボトル紅茶カテゴリーを確立
- **サトウのごはん等 無菌パックごはん（1988〜）** — 「ごはんは炊くもの」を「ごはんは常備するもの」へ

### 機能の物語化型
- **ヤクルト（1935）** — 乳酸菌飲料という習慣を戸別配達網込みで発明した最古級の事例
- **リポビタンD（大正製薬、1962）／レッドブル（1987・グローバル）** — 栄養ドリンク／エナジードリンクのカテゴリー創造。レッドブルは「翼をさずける」で機能を物語に昇華
- **ポカリスエット（大塚製薬、1980）** — 「飲む点滴」の思想でイオン飲料カテゴリーを創出
- **カロリーメイト（大塚製薬、1983）** — 「バランス栄養食」という言葉ごと発明
- **明治コーラアップ（1980、日本初のグミ）→果汁グミ（1988）** — グミというカテゴリーを国産化・市場化。2021年にはグミがガム市場を逆転。「カテゴリーは静的でなく、世代交代する」実例

## D. 2010年代以降の新カテゴリー（「いまも起きている」ことの証明）

カテゴリー創造は過去の神話ではなく、現在進行形の勝ち筋であることを示す事例群。

- **明治 R-1（2009→ブレイクは2010年代）** — 「風邪予防のヨーグルト」という機能カテゴリー。ヨーグルトを味でなく効能で選ぶ習慣を定着させた
- **サラダチキン（セブン×プリマハム、2013）** — コンビニ発の「高たんぱく即食」カテゴリー。RIZAP等の糖質制限ブームと同期して品切れ続出、全社追随で棚が恒久化
- **いきなり！ステーキ（2013）** — 「立ち食い×量り売り」でステーキを日常化。急拡大後の失速は**「体験の希少性が薄まるとカテゴリーごと衰える」教訓**として使える
- **メルカリ（2013）** — フリマアプリという行動カテゴリー。「捨てる→売る」の習慣転換
- **乳酸菌ショコラ（ロッテ、2015）** — 前掲。チョコの「嗜好品→セルフケア」転換
- **BASE FOOD（2017）** — 「完全栄養食」カテゴリーをD2Cサブスクで立ち上げ、コンビニ1.4万店へ拡大、シリーズ累計1億袋。**ニッチなカテゴリー名を自ら定義→定期購買で習慣化→マス流通**という現代の教科書
- **ワークマンプラス（2018）** — 作業服の機能をそのまま「低価格アウトドアウェア」カテゴリーに転用。既存資産の再定義でカテゴリーを創った点がホカロン的
- **ヤクルト1000（2019→全国2021）** — 「睡眠の質×乳酸菌」で飲料に睡眠カテゴリーを発明。SNS発の口コミ→品薄→品薄自体がニュース化という現代型ブーム構造。**「品薄の物語」が最大の広告になる実例**（ビックリマンの「お一人様3個まで」と同型）
- **チョコザップ（RIZAP、2022）** — 「コンビニジム」。月2,980円・24時間・ながら運動で、ジムに行かない人をジム市場に取り込んだ行動カテゴリー創造

## E. 食品以外（メカニズムの普遍性）

- **ヒートテック（ユニクロ×東レ、2003）** — 「防寒は着込むもの」を「インナーが発熱するもの」に反転し、機能性インナー市場を創造。累計15億枚。**玉塚社長がファーストリテイリング社長を務めた企業の代表的カテゴリー創造であり、最も共感を得やすい事例**。素材メーカーとの長期共同開発体制は円谷×ロッテの共創スキームの雛形
- **宅急便（ヤマト運輸、1976）** — 「個人の荷物は運べない」の反転。翌日配達という習慣の発明
- **ウォークマン（ソニー、1979）** — 「音楽を持ち歩く」習慣の発明
- **QBハウス（1996）** — 理容から洗髪・髭剃りを引き算し、10分1000円カットという時間価値カテゴリーを発明
- **ファブリーズ（P&G、日本1999）** — 「洗えない布は我慢する」を「布は消臭するもの」に反転
- **RIZAP（2012）** — 「結果にコミット」でパーソナルジムを日本に定着

### グローバル
- **キンダーサプライズ（フェレロ、1974）** — 前掲。玩具入りチョコの世界標準
- **ネスプレッソ（ネスレ、1986→2000年代に開花）** — カプセルコーヒーで「家庭のエスプレッソ」カテゴリーを創造。**本体×消耗品の継続購買モデル**はフィジタル菓子の収益設計の参考
- **スターバックス（日本1996）** — 「サードプレイス」という場所カテゴリー
- **GoPro（2004）** — アクションカメラ。「撮る人＝主人公」の反転
- **Lululemon（1998〜）** — アスレジャー。「運動着は運動のためだけ」の反転
- **Oatly（2010年代グローバル展開）** — オーツミルク。「牛乳の代替」でなく「バリスタのための植物ミルク」と定義してカフェ経由で文化化。**流通チャネル自体をメディアにする**手法
- **Beyond Meat / Impossible Foods（2010年代）** — 植物肉。「ベジタリアン食品」を「肉好きのための代替肉」に再定義
- **ダイソン（1993〜）** — 「吸引力の変わらないただひとつの掃除機」。技術の物語化で高価格カテゴリーを創出

## F. 横断分析 — カテゴリークリエイターの10法則

1. **商品ではなく習慣を発明する** — おーいお茶・ヤクルト・宅急便。売るのはスペックでなく「新しい日常の行動」
2. **業界の常識・弱点を反転する** — キシリトール（歯に悪い→歯にいい）、雪見だいふく（冬に売れない→冬に食べる）、ワークマン（作業服→アウトドア）
3. **容器・形態のイノベーションが体験を変える** — カップヌードル、inゼリー、クーリッシュ。中身より「食べ方・飲み方」の発明
4. **ランダム性と収集が継続購買を生む** — 仮面ライダースナック、ビックリマン、チョコエッグ。「開封の3秒」に感情のピークを設計する
5. **機能はエビデンスと物語で語る** — キシリトール（歯科界）、ポカリ（点滴思想）、ヤクルト1000（乳酸菌1000億個）、ダイソン
6. **カテゴリー名を自ら命名し、定義を握る** — 「バランス栄養食」「完全栄養食」「サードプレイス」「飲むアイス」。名前を握った者が棚を握る
7. **発明者ではなく、市場を定義した者が勝つ** — カイロは旭化成が先でもホカロンが勝ち、グミはコーラアップが発明しても果汁グミが市場化した
8. **ブームとカテゴリーは別物。長寿は「終わらないコンテンツ」への接続で決まる** — たまごっち・妖怪メダル・いきなり！ステーキは熱狂の後に急落。プロ野球チップス（プロ野球）・ポケモンパン（ポケモン）は毎年更新されるコンテンツに接続して長寿化。**毎年新ヒーローが生まれ歴代資産が積み上がるウルトラマンのシリーズ構造は、後者の条件を満たす**
9. **品薄と行列は最大の広告になる（ただし設計せよ）** — ビックリマン「お一人様3個まで」、ヤクルト1000、たまごっち。初速の需給ギャップは物語になるが、たまごっちの60億円損失が示す通り、無計画な増産・品薄は自滅する
10. **おまけを主役にしすぎない** — 仮面ライダースナックの投棄問題。食べる体験そのものが価値の中核にないと、カテゴリーでなくキャンペーンで終わり、社会の反発も招く

## G. 本提案『ULTRA 3MIN.』への適用マップ（更新）

| 法則 | 本提案での実装 |
|---|---|
| 習慣の発明 | 「1日3分のヒーロータイム」（集中スイッチの儀式） |
| 常識の反転 | 「ガムは衰退カテゴリー」→「3分噛むことに意味がある菓子」へ反転 |
| 形態の発明 | 時限フレーバー＆色変化（噛んで3分で変身する菓子構造） |
| 収集・ランダム性 | 変身ホロシール全60種＋シークレット（ビックリマンエンジン） |
| エビデンス×物語 | ロッテ噛むこと研究 × カラータイマー（世界一有名な3分） |
| カテゴリー命名 | 「変身菓子」を両社共同で宣言し、定義を握る |
| 定義を握る速度 | 60周年の2026年度内に先行弾（ウルトラマンマンチョコ）で着手 |
| ブームでなく長寿設計 | 毎年の新TVシリーズ＋歴代60年資産に接続（プロ野球チップス型）。妖怪メダル型の単一タイトル依存を構造的に回避 |
| 品薄の設計 | 初速はシークレット封入率と地域限定で需給を制御し「物語としての品薄」を演出、増産計画は段階制に（たまごっちの教訓） |
| 菓子体験が主役 | シールはあくまで従。「3分の味変身」という食体験がなければ成立しない設計にする（仮面ライダースナックの教訓） |
