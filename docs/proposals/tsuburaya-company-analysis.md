# 円谷プロ分析 — 強み・成功・失敗と本提案への含意

**用途**: ロッテ玉塚社長打ち合わせの自社理解・想定問答資料(社内準備用)
**関連**: `lotte-company-analysis.md`(ロッテ側分析)、`lotte-ultraman-category-proposal.md`(提案本体)

---

## 1. 現在地(2026年時点)

- 円谷フィールズHD傘下で財務・資本が安定。中期経営計画では2024〜25年度をブランディング期間、**2026年3月期から「攻めの成長フェーズ」**と位置づけ — 60周年と提案タイミングが完全に一致
- 直近業績はコンテンツ&デジタル事業の上半期売上約57億円(前年比+16.3%)。**海外MDライセンスは前年比+35%の31.7億円で国内(8億円)の3倍超**。トイ&ホビーに加え「ライフスタイル」「食品」分野が成長中
- 2026年はシリーズ放送開始60周年。記念作『ウルトラマンテオ』が世界同時放送・配信中、記念映画・記念本・60周年プロジェクトが進行

## 2. 強み(ロッテに提示すべき資産)

1. **「終わらないコンテンツ」の構造** — 『ウルトラマン』は**「最も派生テレビシリーズが作られたTV番組」としてギネス世界記録認定**(2013年時点で27作品、以後も毎年更新中)。毎年新ヒーローが生まれ、歴代資産が積み上がる年次モデルは、プロ野球チップス型の長寿商品設計の前提条件そのもの
2. **数百体のキャラクター資産と「怪獣文化」** — 敵役の怪獣まで愛され、大人が名前を言える(ゼットン、バルタン星人…)。善悪の宇宙観を最初から持つ点はビックリマン「悪魔VS天使」と同型
3. **三世代に届く認知** — 祖父母・親・子が同じヒーローを知っている稀有なIP。親子二世代購買(ビックリマン型)を三世代に拡張できる
4. **中国・アジアの爆発的熱量** — 中国トレカ最大手・卡游(Kayou)は2018年にウルトラマンライセンス取得後に急成長し香港上場申請、2020年時点でウルトラマンカードだけで年約7.4億円売上・レアカード1枚20万円の二次市場。2024年からは円谷公式「ウルトラマンカードゲーム」を日本・北米・中国・東南アジアで世界同時展開。**「IP×収集×アジア」は既に実証済み**
5. **発明的フォーマットの保有** — 「変身」「3分間の活動限界」「カラータイマー」という、体で覚えられた世界共通言語。食体験への翻訳素材として唯一無二
6. **海外権利が完全にクリーン** — 約30年続いたチャイヨー社との海外版権紛争が2019年の米控訴審で完全決着。**いまが史上最も安心して海外展開できる時期**
7. **映像・イベント・デジタルの連動力** — TVシリーズ、劇場、配信、カードゲーム、ゲーム(2025年〜グローバル展開)を自社グループで同期できる

## 3. 成功の系譜

| 成功 | 年 | 意味 |
|---|---|---|
| 初代ウルトラマン | 1966 | 怪獣ブームの社会現象。「変身ヒーロー」フォーマットの発明 |
| 平成三部作(ティガ〜) | 1996〜 | 16年ぶりTVシリーズ復活を成功させ、世代を超えるIPであることを証明 |
| ニュージェネレーション(ギンガ以降) | 2013〜 | 毎年新作の年次モデルを確立。玩具・カード連動の現行エコシステムの基盤 |
| 中国でのカードブーム | 2018〜 | 卡游との提携で子ども市場を席巻。IP×収集の海外実証 |
| シン・ウルトラマン | 2022 | 興行収入40億円超、2022年邦画実写トップ級。大人・ライト層への再接続 |
| 海外ライセンス急成長 | 2020年代 | MDライセンス海外が国内の3倍超に。食品分野も成長開始 |
| 60周年プロジェクト/テオ | 2026 | 世界同時放送・配信。グローバル展開の号砲 |

**共通パターン**: ①フォーマット(変身・3分)は不変のまま、毎年器を新しくする ②収集と物語を接続する ③子ども市場で燃えた熱が大人のノスタルジー市場に還流する。

## 4. 失敗・挫折の系譜(教訓と、商談での使い方)

### ① 映像単体の構造赤字(1960年代〜)
- 初代は1話の制作費に対し局からの受取額が半分程度で、「作るほど赤字」。円谷英二の完璧主義と特撮のコスト構造ゆえ、シリーズごとに億単位の赤字も
- **教訓**: 映像は投資、回収はライセンスとマーチャンダイズ — という現在のIPビジネスモデルの原点。**だからこそ商品パートナーの質がIPの命運を決める**

### ② チャイヨー海外版権紛争(1976年〜2019年)
- 1976年付とされる権利譲渡文書(後に真正でないと確定)を巡り、タイ・中国・米国で約30年係争。2019年米控訴審勝訴で完全決着
- **教訓**: 契約・権利管理の甘さは数十年の海外機会損失になる。**アジア展開が本格化できるのは実質ここ数年のことであり、「手つかずの伸びしろ」こそ商談の売り物**

### ③ 経営危機と創業家の退場(2007〜2010年)
- 放漫経営と赤字体質で経営危機に陥り、2007年TYO傘下入りで同族経営に終止符。2010年フィールズ(現・円谷フィールズHD)傘下へ
- **教訓**: 現在の円谷はこの反省の上に立つガバナンス体制。**「プロ経営で再生した会社」という点は玉塚体制のロッテと相似形**であり、共感の接点になる

### ④ 作品・編成の挫折(2000年代)
- コスモス放送中断(2001年・主演俳優の誤認逮捕。後に再開)、ネクサス視聴率低迷で37話に短縮(2004-05年)、メビウス(2006年)以後は地上波TVシリーズが長期休止し、2013年ギンガまで空白
- **教訓**: 単発タイトルの浮沈はある。それでもIPが死ななかったのは「歴代資産×新作」のシリーズ構造ゆえ。**妖怪メダル型の単一タイトル依存リスクへの、歴史で実証された答え**

### ⑤ 食品・日用品の「毎日の棚」を持っていない(現在の弱み)
- MDライセンスはトイ&ホビー中心。食品分野は伸び始めたが、**ビックリマンやポケモンパンのような「毎週買う定番」をウルトラマンは一度も持ったことがない**
- **含意**: これは弱みであると同時に、ロッテにとって「未開拓の一等地」。菓子売場の日常頻度×ウルトラマンの熱量はどちらか一方では作れない

## 5. 商談での語り方 — 「傷を含めて語る」戦略

1. **ブーム崩壊の痛みを共有する** — ロッテにはビックリマンの公取委勧告と急落、円谷には2000年代の低迷とシリーズ休止。**両社ともブームの怖さを骨身に染みて知っている**からこそ、「ブームではなくカテゴリー(習慣)を作る」という本提案の思想に説得力が出る
2. **権利クリアを明言する** — 過去の紛争と決着を自ら開示し、「現在は全世界で権利関係がクリーン。御社に法務リスクを持ち込まない」と先回りする
3. **再生企業同士の共鳴** — 同族経営の危機からプロ経営で再生した円谷と、お家騒動からプロ経営者体制に移行したロッテHD。「新しい体制の旗艦プロジェクト」という物語は双方の社内を動かす
4. **数字で語る** — 海外MD+35%、卡游の実証、シン・ウルトラマン40億円、ギネス記録。情緒でなく実績で「いま買うべきIP」であることを示す

## 6. 両社相補マトリクス(クロージング用)

| 領域 | 円谷が持つもの | ロッテが持つもの |
|---|---|---|
| コンテンツ | 60年のIP・毎年更新されるシリーズ・ギネス級の派生構造 | ビックリマン等の商品IP運営経験 |
| 体験の素材 | 変身・3分・カラータイマーという世界共通言語 | 咀嚼・時限フレーバー・色変化の食品技術 |
| エビデンス | — (機能訴求の科学は持たない) | 噛むこと研究・キシリトールの実績 |
| 収集の仕掛け | カードゲーム世界展開・デジタル図鑑基盤 | シール食玩の発明者としての売場ノウハウ |
| 売場 | — (毎日の棚を持たない) | 国内全域の菓子棚+アジア流通網 |
| 海外 | 中国・東南アジアのファン熱量(権利クリア済) | アジア製造拠点(インドネシア等)・海外比率3割目標 |
| 顧客接点 | 子ども+三世代ノスタルジー | 日常の購買頻度(コンビニ・スーパー) |

→ **7領域すべてで欠けが噛み合う。「どちらか一方では『変身菓子』カテゴリーは作れない」ことが、この提案の最大の防御力(他社に真似されない理由)になる。**
