# ロッテ分析 — 強み・成功・失敗と本提案への含意

**用途**: ロッテ玉塚社長打ち合わせの相手理解資料（社内準備用・持ち出し不可）
**関連**: `lotte-ultraman-category-proposal.md`（提案本体）、`category-creator-case-studies.md`（事例集）

---

## 1. 現在地（2026年時点）

- 1948年、重光武雄氏がチューインガム製造で創業。「お口の恋人」を掲げる国内菓子最大手級
- 現体制は**玉塚元一社長CEO（2021年就任）**。元ファーストリテイリング社長・元ローソン社長のプロ経営者
- グループ成長戦略は**「食品」「ライフサイエンス＆デジタル」「ライフスタイル＆エンターテインメント」の3本柱**。※エンタメが公式に事業柱に入っている＝IP共創提案の受け皿が既にある
- 海外売上比率は約2割で、**3割への引き上げが公式目標**。チョコパイのインドネシア生産倍増（2025年工場新棟）などアジア軸
- 2026年7月にはヤオコーを核店舗とする商業施設を開業（ライフスタイル事業）。玉塚社長が自ら登壇

## 2. 強み（本提案が乗るべき資産）

1. **総合菓子フルライン** — ガム・チョコ・キャンディ・ビスケット・アイスをすべて自社で持つ国内でも稀な布陣。『ULTRA 3MIN.』のガム/グミ/チョコ横断展開が1社で完結する
2. **「噛むこと」研究のエビデンス資産** — 中央研究所を核に「噛むこと健康研究会」を運営、東大高齢社会総合研究機構とも連携。ガム口腔健康プログラムで**年間最大約1.2兆円の介護費抑制可能性**を発表するなど、咀嚼×健康の科学的裏付けは他社が持ち得ない。「3分噛む」ことへの価値付けはこの資産の上に立てる
3. **収集型商品の運営ノウハウ** — ビックリマンで培ったシール文化・封入率設計・コラボ枠運用（ミャクミャクマンチョコ等）。日本で最も「開封のドキドキ」を運営してきた会社
4. **マーケティングの実行力** — ガーナ（後発から定番化）、Fit's（発売2ヶ月で2,000万個、フィッツダンス×YouTubeの参加型設計）、雪見だいふく、乳酸菌ショコラ。話題化→定番化の型を持つ
5. **アジアの製造・流通網** — インドネシア等の生産拠点、グループのアジア販路。ウルトラマンの東南アジア人気と地理的に重なる
6. **非上場ゆえの長期投資余地** — 短期の四半期圧力が相対的に小さく、カテゴリー育成のような長期戦に向く
7. **改革を断行できる経営** — 玉塚体制でロッテリア売却（2023年、ゼンショーへ）など選択と集中を実行済み。新規カテゴリーへの投資判断が速い可能性

## 3. 成功の系譜（パターン抽出）

| 成功 | 年 | 勝ちパターン |
|---|---|---|
| グリーンガム | 1957 | 戦後の粗悪品市場に品質で参入、ガム＝ロッテを確立 |
| ガーナミルクチョコ | 1964 | 半世紀遅れの圧倒的後発から、カカオ輸入自由化の機を捉えスイス人技師の技術導入で定番化。**「後発でも定義で勝つ」の原体験** |
| ビックリマン | 1977/1985 | 収集文化の発明。年間4億個 |
| ホカロン | 1978 | カイロ市場の定義 |
| 雪見だいふく | 1981 | 冬アイスの発明 |
| キシリトールガム | 1997 | エビデンス×歯科界巻き込みで機能性ガム創造。ガムシェア6割の源泉 |
| クーリッシュ | 2003 | 飲むアイスの発明 |
| Fit's | 2009 | 若年ガム離れに参加型マーケ（ダンス×YouTube）で対抗、発売2ヶ月2,000万個 |
| 乳酸菌ショコラ | 2015 | 機能性チョコ創造、半年で20億円 |

**共通パターン**: ①後発・逆風を「定義の転換」でひっくり返す ②研究所のエビデンスを物語化する ③参加型の仕掛け（集める・踊る・共有する）で消費者を巻き込む — いずれも本提案の設計思想と一致。

## 4. 失敗・挫折の系譜（教訓と、本提案での応え方）

### ① ビックリマンブームの崩壊（1988→1990年代）
- 1988年、**公正取引委員会がロッテに勧告**（シールの価値差を煽らない・種類毎の混入率均一化・特定シールに価値が出る広告の自粛）。ブームに冷や水を浴びせ、90年代はポケモンカード等に子どもの関心が移り、**1998年に生産一時終了**まで落ちた
- **教訓**: レア封入と射幸性の設計は規制と表裏一体。ブームは設計しないと崩壊する
- **本提案での応え**: レア設計は「射幸性」でなく「物語性」（60周年の歴代60種＝コンプリートに意味がある構造）に置く。封入率の透明性・デジタル図鑑での重複救済など、令和の健全設計を初期から組み込む

### ② 主力ガム市場の長期縮小（2004年ピーク→4割超減）
- スマホ（手持ち無沙汰の代替）、ミント菓子・グミへの移行で構造縮小。Fit'sで若年を一時喚起したが、**グミ市場の拡大（2021年にガム逆転）は明治系に主導権を取られた**
- **教訓**: 首位カテゴリーの防衛だけでは、隣で生まれる新カテゴリーを取り逃す
- **本提案での応え**: 『ULTRA 3MIN.』はガム・グミ両形態で「噛む時間の価値」を再発明し、縮小するガムの技術資産と成長するグミの勢いを一つのカテゴリーに束ねる出口になる

### ③ ロッテリアの売却（2023年）
- 外食は「最適なパートナーのもとでの成長がベスト」としてゼンショーへ売却。玉塚社長による選択と集中
- **教訓/含意**: 玉塚体制は「ブランドが付いていても、勝ち筋がなければ手放す」。**情緒でなく事業構造で判断する相手**であり、提案はKPI・収益構造・棚の獲得ロジックまで詰めて持ち込むべき

### ④ 乳酸菌ショコラの広告表現問題
- 「乳酸菌が100倍届く」等の表現に当局の指摘。ヒット商品でも機能訴求のエビデンス管理を誤ると足をすくわれる
- **本提案での応え**: 「集中」「リフレッシュ」等の効能表現は噛むこと健康研究会の知見と表示規制に沿って設計。IP側（円谷）は世界観表現に徹し、機能表現はロッテの科学に委ねる役割分担を明確化

### ⑤ 創業家のお家騒動（2015年〜）とガバナンス
- 兄弟間の経営権争いが長期化し、株主総会で4度の対決。この収拾過程で外部プロ経営者（玉塚氏）体制へ移行
- **含意**: 玉塚体制の正統性は「ガバナンス改革と新しい成長物語」にある。**「新しいロッテ」を象徴する旗艦プロジェクト**という文脈で提案すると、社長自身のアジェンダと重なる。※騒動自体には打ち合わせで触れない

### ⑥ （グループ）中国事業のTHAAD打撃（2017年〜）
- 韓国ロッテグループはTHAAD用地提供への中国の報復でロッテマート99店舗中87店舗閉鎖、約1兆円投資からの撤退に追い込まれた
- **教訓/含意**: グループの海外軸足は中国から東南アジアへ移行済み。**ウルトラマンが強い東南アジア（＋日本発IPとして安全に展開できる市場）との重なり**は、地政学的にも合理的な提案になる。※これも先方から出ない限り深入りしない

## 5. 玉塚社長個人への刺さり方（想定）

- **ユニクロ時代** — ヒートテック（東レとの共同開発によるカテゴリー創造）を知る人。「素材×小売の共創でカテゴリーを創る」文法が通じる → 円谷×ロッテを「IP×菓子のヒートテック型共創」として語れる
- **ローソン時代** — コンビニの棚とデイリー購買の力学を熟知 → 「週替わり」「定番棚の獲得」の設計は解像度高く見られる。数字を持って行く
- **プロ経営者として** — 情緒的なIP愛でなく、「なぜロッテが勝てるのか」「なぜ今か」「出口はどこか」の構造で聞く。事例集の10法則と適用マップはそのまま武器になる
- 提案の座組は「御社の失敗も含めた歴史に、私たちのIPが構造的に応える」形が最も敬意ある形

## 6. まとめ — 提案ストーリーへの組み込み

1. **冒頭**: ロッテのカテゴリー創造史（成功の系譜）に敬意 → 「次の10年の一手」として位置づけ
2. **中盤**: ガム縮小・グミ逆転という構造課題に、『ULTRA 3MIN.』が「噛む価値の再発明」として応えることを明示
3. **収集設計**: ビックリマンの公取委の記憶に対し、令和の健全設計（物語性・透明性・デジタル救済）を先回りで提示
4. **海外**: 海外比率3割目標×東南アジア軸と、ウルトラマンのアジア人気の重なりを地図で見せる
5. **クロージング**: 「新しいロッテ」の旗艦プロジェクトとして、エンタメ事業柱に正面から乗せる
