# SB週20ライン要望への対応整理と確保作戦【社内限定・持出厳禁】

2026/10/8 作成:新谷/情報源:菅野さん提案資料「ウルトラソフトバンクフェス 全国本格実走計画」+エリア別稼働スケジュール別紙+菅野さんコメント

## 1. 菅野さん提案の要点整理

**計画の骨格**

- 運用期間:2027年1月〜2028年3月(15ヶ月)・土日開催130日
- 稼働規模:**全国15ライン基準**・総実走1,950回(ライン×日)・延べ約26万組(78万人)動員想定
- エリア配分:関東785回(40.3%)/関西270/東海249/九州236/地方5エリア410
- **パッケージ単価:50万円/日(税別)=土日2日間で100万円** → SBに提示済みの「ライブ費100万円/開催」と完全整合
- 総額:**9億7,500万円(税別・15ヶ月)**+交通運搬費・スーツ送料・宿泊・JASRAC(主催者負担)別途
- **粗利:売上の50%**(菅野さん明言)→ 従来仮置きの「ライブ粗利20%」を上方修正。15ライン計画の粗利は約4.9億円

**体制(トライアルからの改善)**

- 5名→**7名体制**:D1・アクター1・専任MC1(新規)・キャラ補助2・運営スタッフ2(1名増員)。スタッフ2名追加はこの単価に内包
- 撮影会は「30分×3回(150組)」または「20分×4回(160組)」に最適化(5回→午後の集客分散に対応、スーツメンテ時間確保)
- キット・ノベルティは**SB側で事前作成・運用**(=キットなし見積と整合)
- 現地準備:控室(施錠可)・関係車両駐車場

**菅野さんからの条件(=保守性の中身)**

1. SB様窓口の一本化(告知フォーマット一括確認・監修時間削減)
2. イベント内容の全店共通フォーマット化(店舗個別仕様の廃止)
3. 円谷側専任スタッフ1名常駐+申請フロー厳守(専用フォーム申請→**前月1日に可否確定**→確認書→実施)
4. 既存FIX施設のバッティング回避(アリオ橋本・八尾ほか全国リスト提示済み→SB会場選定から除外要請)

**ライン数の制約要因(別紙スケジュールより)**

- 2027年2-3月:テオ劇場版CP(6ライン持っていかれる)
- 2027年8-9月:ゼロ映画劇場CP/9-12月:E1バンダイCP/10月:ツブコン/4月:福岡EXPO/6-7月・12-1月:東京・大阪EXPO/2028年2月:E1劇場CP
- 基準15ラインに対し、**1月・4月・6月・11月・12月は+2ライン程度の追加バッファあり**

2. 15ヶ月計画(FY27末まで)とSB見積の2年(2028年12月まで)の期間ズレ → 見積は2年、供給計画はFY28分を追補する必要

## 3. 20ライン確保の作戦(供給5レバー)

**経済性の前提(菅野さん説得の核)**:1ライン追加の価値=130日×50万円=**売上6,500万円・粗利3,250万円(15ヶ月)**。5ライン追加なら**売上+3.25億円・粗利+1.6億円**。SB専属班の新設コスト(採用・育成・スーツ)が1班500万円規模なら、**回収は稼働2ヶ月以内**。

| # | レバー | 増分 | 内容・条件 |
| --- | --- | --- | --- |
| 1 | 休眠スロットの充当 | +2 | 別紙の空き行(キャップス東京No.11・シーズ大阪No.15・森次No.18-19・シーズ九州No.22-23等)にスーツ複製+アクター充当。既存代理店なので立ち上げが最速 |
| 2 | SB専属班の新設 | +3 | 東名阪に専属班を新設(採用・育成3ヶ月リード)。**SBのMG(年間最低開催数保証)を投資根拠に充てる**。これが従来の「スーツ増産・採用500万」のスケール版 |
| 3 | キャラポートフォリオ分離 | 衝突回避 | 劇場CP・バンダイCPが取るキャラ(テオ/ゼロ/E1)とSBラインのキャラ(マン/タロウ/ティガ/ダイナ/ゼット/ジード/オメガ)を月次で分離。SBには「月別キャラシフト表」を当社から提示し、キャラ被り=ライン減を構造的に防ぐ |
| 4 | 月別変動ライン設計 | 実質+α | 「全月20固定」をやめ、**年間総量ベースのMG**で合意する。繁忙月(2-3月・8-10月)は15-17、閑散月(1・4・6・11・12月)は20-22で、年平均で週18-20相当を担保。SBの本音が「総開催数の確保」なら総量合意で満たせる |
| 5 | 平日・連休の活用 | 実質+α | 土日130日に加え、連休・学休期の金曜/祝日をSB商戦に合わせて追加提供(3日間オプション+50万円/日の既提示単価で収益化) |

レバー1+2で**物理20ラインを2027年夏までに整備**、それまでの立ち上がり期はレバー4の月別変動でブリッジする2段ロケットが現実的。

## 4. 菅野さん説得プラン(保守の根っこを外す)

菅野さんの保守性の根源は「①既存IP行事(劇場CP・ツブコン)との衝突 ②空振り稼働のリスク ③監修・個別対応の工数爆発」の3つ。それぞれに答えを当てる:

1. **交換条件として菅野さんの3大重点方針を丸呑みでSBに通す**:窓口一本化・全店共通フォーマット・前月1日確定フロー・既存FIX施設除外は、すべて当方からSBに「契約条件」として通す(※SB側はすでにEDI・販促企画2課ラインで一本化が進んでおり通る公算大)。「あなたの要望を全部通す。その代わり基準を15→20に」という取引にする
2. **空振りリスクはMGで消す**:SB契約に年間最低開催数保証(8割)+キャンセル料30/50/100%+前月1日確定が入る設計。**稼働が空く月は請求が立つ**構造を示し、「増員しても仕事がない」懸念を外す
3. **劇場CPは侵食しないことを契約で担保**:繁忙月のSBラインに月別キャップ(15-17)を明記し、自社IP行事の優先権を菅野さん側に残す。SBとの合意は総量ベースなので両立する
4. **数字で締める**:+5ライン=粗利+1.6億円/15ヶ月、投資500万円規模・回収2ヶ月。粗利50%は菅野さん自身の数字なので、この計算に反論の余地がない
5. 段取り:まず新谷→菅野で1on1(上記1〜4)→合意後に部長会で投資承認(すでに「MG裏付け投資の承認」として議題化済み)→SBへは月別ライン表つきで回答

- 条件セット:①窓口一本化②全店共通フォーマット③前月1日確定フロー④会場は当社バッティングリストとの事前照合⑤年間MG——をパッケージで

## 6. アクター採用要件と育成パイプライン(菅野さん 10/9 チャットより)

**採用要件(スペック)**

- 体格:ヒーロースーツに入れる170〜180cm・標準体型(身長は高い方が望ましい)
- スキル:練習・経験のある方/キャラクターのポージングができる方(写真・SNSに残るため)/ある程度の芝居ができる方
- 適性:閉所恐怖症でないこと(スーツは自力で脱げないため、パニックにならない方)
- ウルトラマンのスーツは特殊なため、一定の経験が必須

**育成の標準ルート(即戦力にはならない)**

ステージショーの怪獣 → 複数ヒーローの撮影会 → 1体の撮影会 → ステージショーのヒーロー

**20ライン計画への含意(重要)**

- SB案件の中心である「1体の撮影会」は育成ラダーの3段目。**新規採用者をいきなり充てられない**ため、増強の実リードタイムは「採用3ヶ月」より長く見る必要がある
- 対策①:専属班の新設は**経験者の中途採用・既存12社代理店ネットワークからの引き抜き/出向を優先**(未経験採用は怪獣・キャラ補助枠で入れて育成)
- 対策②:**SBライン自体を育成の場に使う**——複数ヒーロー撮影会(キャラ補助2名体制)で新人を回し、既存アクターをSB専属へ振り替える玉突き方式なら、ラダーを崩さず実質増員できる
- 対策③:増強スケジュール(第1弾6月・第2弾11月)は「経験者確保が前提」と1on1で正直に握る。確保が遅れた場合のバッファとして代理店スポット稼働(既存FIX施設運用チームの土日融通)を菅野さんに相談
- 瓜生さん(キャスティング窓口)への見積内訳・宿泊交通費概算は本日中に菅野さんから届く予定 → 受領後、SB見積の実費欄(交通運搬・宿泊)の精緻化に反映
