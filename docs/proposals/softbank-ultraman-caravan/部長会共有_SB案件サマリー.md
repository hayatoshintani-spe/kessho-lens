# 【部長会共有】ソフトバンク×ウルトラマンIP 店頭イベント案件(2026/9/9時点)

社内限定・持出厳禁/作成:新谷

## 1. 案件概要

- ソフトバンク株式会社(コンシューマ事業統括)との、ウルトラマンIPを活用した店頭イベントの年間ライセンス化を目指す商談。7/23に提案書(0723_v02)を提出済み
- 進め方は2段階。**今週末からのスポットテスト(9〜10月・神奈川7会場)で実績を作り、その結果をもとにSB側が来期(FY27)年間契約を判断**する構図
- SB側の判断時期が確定:**「テストの営業反響・集客状況を見た上で、9月中〜遅くとも10月内に年間契約を判断する」**(9/8 コミュニケーション本部プロモーション部 髙田様よりメールで明言)。開催数(L数)等の詳細条件も同時並行で協議に入る

## 2. スポットテストの実施内容(今週末開始)

- 期間・エリア:2026年9月12日〜10月18日の週末4回・神奈川県内7会場(契約主体:ソフトバンク株式会社)
- 9/12-13 イトーヨーカドー古淵:ステージショー型(テオ&オメガ/ゼット&ジード)※初回・今週末
- 9/19-20 イトーヨーカドー川崎+ビックカメラ ラゾーナ川崎:写真撮影会型×2(同日2会場・キャラ重複回避で調整中)
- 9/26-27 イトーヨーカドー上永谷:写真撮影会型(ゼロ/ティガ)+ヤマダデンキ横浜本店:ステージショー型(テオ&オメガ/ゼット&ジード)
- 10/17-18 港南台バーズ+ヨドバシカメラ横浜:写真撮影会型×2(ゼロ/ティガ)
- 運営スキーム:契約書は締結せず、**当社見積書(キャンセル料・IP利用範囲等の条件を備考記載)+SBのEDIシステム発注書+会場ごとの実施確認書**で個別契約を構成(SB側と合意済みの方式)

## 3. テストの受注規模(SB提示済み単価ベース)

- **確定ベース合計 1,110万円(税別)**
- 内訳:写真撮影会型 100万円/開催×5会場=500万円、ステージショー型 200万円/開催×2会場=400万円、イベントキット利用料 30万円/開催×7会場=210万円
- 上記に加え、ノベルティ(SB側が当社商品を卸値で購入)と交通・運搬等の実費が別途加算
- 正式見積書は日程・内容の最終確定後に発行し、SBのEDIシステムで発注書を受領するフロー(現在発行準備中)

## 4. 来期(FY27)年間契約の提案内容(提示済み)

- 基本条件(すべて税別):**①IP使用料 年間2,000万円(初年度特別価格・通常2,400万円) ②キャラクター出演 20万円/開催 ③店頭訴求ツールのロイヤリティ20%**
- 規模別の年間総額シミュレーション:全量展開(最大720開催)約2億500万円/半分 約1億1,200万円/3分の1 約8,200万円
- 交渉方針(社内確認済み):守り順は「配分・MG > IP使用料 > 単価 ≧ 料率」。2,000万円は初年度特別表記でアンカー維持、単価20万円は公式レギュレーション定価として死守、ロイヤリティ15%への譲歩は最低開催数・最低作成数量の保証(MG)との交換条件に限る

## 5. 今後のスケジュール

- 9月:テスト4週末を実施。各開催の集客実績を都度SBへ共有し、判断材料を当社主導で提供
- 9月中〜10月内:SB側が年間契約を判断(L数協議並行)。当社は基本合意(LOI)ドラフトと開催数別試算を準備して臨む
- 10月〜:条件合意→契約手続き→FY27年4月稼働に向けた準備(監修体制・キャラバン班増強)

## 6. 部長会でご確認・ご判断いただきたい事項

- **ドコモとの既存契約の扱い**:今期のテスト実施は許容の確認取得済み(スポットの法務前提はクリア)。FY27にSBへ切り替える場合の非更新判断・解約費用(社内想定200万円)の意思決定タイミングを、SBの判断時期(10月)に合わせて設定したい
- **MGの裏付けとなる先行投資の承認**:年間720開催体制に向けたスーツ増産・アクター採用(想定500万円規模)。SBにMG(最低保証)を求める根拠として必要
- **キャパシティ**:現行は同時最大15開催/週。全量展開受注時は3ヶ月前リードタイムでの増強が前提となる点の共有
- **グループ協業の位置づけ**:SB側からホールディングス単位の協業・60周年連携への言及あり。単年ライセンス案件ではなくグループ協業の入口として扱う場合の全社方針
- 補足:キャラクターは権利調整の関係で今期テストはウルトラセブンを除く8ヒーローで運用中(来期は応相談)
