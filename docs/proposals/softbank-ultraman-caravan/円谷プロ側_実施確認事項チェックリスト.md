## 1. 契約・権利関係(法務・ライセンス)【期限:契約締結前】

- [ ] ★ **ドコモ契約との整理(経営判断)**:競合制限は2027年3月31日まで。SBと年間契約するならドコモは更新しない前提で確定させる(実質二者択一)。ドコモ側への仁義(関信越支社との関係維持)をどう切るかも含めて経営レベルで決定
- [ ] ★ **FY26中テストの可否判断**:SBが希望した場合、ドコモ契約第3条2項(事前書面通知+協議)を踏むか、商業施設主催建付けで逃がすか、断るか。法務見解を先に取る
- [ ] ★ **税込/税別の確定**:SB提示「1,650万」が税込(=税別1,500万)か税別か。見積の前提が変わる
- [ ] ★ **使用範囲の定義**:業種(携帯通信・BB・でんき、コンシューマ限定)/媒体(イベント・店頭・LP/Web・SNS・メール)/法人向け・グループ他社サービスの除外を契約書に明記
- [ ] ★ **ワイモバイル・LINEMOの扱い**:SB資料の作成イメージにはY!mobileロゴ併記ツールが含まれる。ブランドの範囲(SoftBank単独か、Y!mobile・LINEMO込みか)で価値が変わる——込みなら価格の上積み根拠になる
- [ ] ★ **ロイヤリティ算定基礎の定義**:「作成費用(税別)」とは何か——外注費ベースか、値引き後実費か、内製時の扱いは。**SBからの月次作成レポート提出義務と帳簿確認権(監査権)**を契約に入れる
- [ ] ★ MG採用時:未消化MGの精算方法(返金なし・翌期繰越なし)、ミニマムロイヤリティの精算タイミングを明文化
- [ ] ★ 競合制限条項:円谷側から見た排他はどこまで与えるか(ドコモ型3項構造=同種事業者主催でないイベントは除外、を維持し自社イベントの自由を守る)
- [ ] ☆ 成果物の著作権帰属(ドコモ契約4条5号型:円谷帰属+著作者人格権不行使)、©表示(「©円谷プロ」)の位置・サイズ規定
- [ ] ☆ 使用キャラクターの範囲:どのヒーロー・怪獣を許諾するか。**既存商品化権者(玩具・カードゲーム等)とのバッティング確認**(ノベルティが既存商品と競合する場合の優先購入ルール=ドコモ別紙2型を踏襲するか)
- [ ] ☆ 60周年ロゴ・「with U」等の記念素材の使用条件(60周年プロジェクトの権利処理・使用期限)
- [ ] ☆ 放送・映画連動キャラの解禁時期(新ヒーローの店頭解禁はTV放送スケジュールと連動)
- [ ] ☆ 契約解除・中途終了時の措置(店頭ツール撤去期限、素材返還=ドコモ7条型)、反社条項、守秘条項

## 2. 供給体制:着ぐるみ・アクター(制作・イベント部門)【期限:契約締結〜2026年12月】

- [ ] ★ **スーツ増産の費用とリードタイム**:1着あたりの製作費・納期を確定し、2027年4月に間に合う発注時期を逆算。**この先行投資額がMG要求の根拠**になる
- [ ] ★ **指定アクター制の設計**:自社アクターだけでは600開催は不可能。外部イベント会社との提携・認定研修制度(演技・ポージング品質基準、NG動作)・認定料の有無を設計
- [ ] ★ ディレクター人材の確保(各開催1名帯同。ポケモン方式と同じ2名体制)
- [ ] ☆ 地方対応:拠点配置か巡回か。交通・宿泊実費の見積り方法と請求フロー(SB側との精算ルール)
- [ ] ☆ **自社イベントとの稼働バッティング**:ウルサマ・60周年イベント・映画舞台挨拶と、SBの繁忙期(GW・夏休み・年末年始・春商戦)が重なる。年間稼働カレンダーの優先順位ルールを決める
- [ ] ☆ スーツのメンテナンスサイクル・洗浄・輸送体制(キャリーバッグ規格、配送業者)
- [ ] ☆ 実施ルールブックの整備(1回30分×1日最大5回、控室要件、写真撮影ルール、キャラクターの声・発話の扱い、他キャラ共存不可)——ポケモン運用ルールと同等の文書をSB・代理店へ配布
