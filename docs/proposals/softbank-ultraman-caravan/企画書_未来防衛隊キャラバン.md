## 1. 提案の結論

本企画は、ウルトラマンを単なるキャラクター露出として使う企画ではありません。

**ウルトラマンを"商業施設に顧客を呼び込む店頭イベントの核"として活用し、来館した親子・ファミリー層をSoftBankショップ、BB、でんき、モバイル相談へ送客する企画**です。

現在のポケモン契約では、FY26の契約費用が7,000万円であり、イベント・BB・でんき領域でのコンテンツ活用が可能です。一方で、FY27以降はポケモンコンテンツの利用は継続予定であるものの、**着ぐるみ利用は不可**となる前提です。

このため、FY27以降のSoftBank店頭イベントには、親子・ファミリーを商業施設へ呼び込める**リアル集客コンテンツ**が必要になります。

そこで、ウルトラマンを以下の役割で提案します。

> ポケモンを置き換えるのではなく、ポケモンでFY27以降担いにくくなる"リアルイベント集客機能"をウルトラマンで補完する。

**本命プランは、FY27年度の年間活用を前提とした1億5,000万円プラン(B案)です。**

## 2. 高島副社長向けの提案ポジション

高島謙一氏は、2026年4月1日付で**副社長執行役員 兼 COO コンシューマ事業統括**に就任しています。したがって、本企画は「IPコラボ」ではなく、**コンシューマ事業のリアル接点拡張施策**として提案します。

ソフトバンクのコンシューマ事業は、付加価値サービスを備えた料金プランの浸透、グループ経済圏の活用、長期利用が期待できるユーザー層の獲得・定着を通じて、モバイルサービス売上とセグメント利益の継続成長を目指しています。また、SoftBank、ワイモバイル、LINEMOのマルチブランド展開も競争優位として示されています。

この文脈で、高島副社長向けの主語は以下です。

> ウルトラマン60周年を活用し、商業施設に親子・ファミリーを呼び込み、SoftBankショップ、BB、でんき、モバイル相談へ送客する、コンシューマ事業成長施策。

## 4. 企画コンセプト

本企画は、ウルトラマンを店頭イベントの核として活用し、商業施設に親子・ファミリー層を呼び込む**送客型キャンペーン**です。

ウルトラヒーローの登場、親子撮影会、館内ミッションラリー、デジタル隊員証、SoftBankショップでのスマホ・BB・でんき相談を一体化し、商業施設全体の来館動機を創出します。

- **商業施設にとって**:週末・祝日のファミリー集客、館内回遊、滞在時間向上に貢献するイベントパッケージ
- **SoftBankにとって**:店舗前通行量の増加、相談件数の創出、家族契約・機種変更・BB・でんきへの送客につながる施策
- **KGIとの接続**:最終KGIは新規契約(モバイル・BB・でんき)の獲得。来場・ラリー参加・送客・相談・見積のKPIは、すべてKGIの先行指標として設計する

## 5. なぜ今ウルトラマンなのか

ウルトラマンシリーズは2026年7月10日に60周年を迎え、公式60周年プロジェクトでは「with U」をコアメッセージとして展開しています。この「with U」という文脈は、SoftBankのコンシューマ事業と相性があります。

| ウルトラマンの文脈 | SoftBank側の接続 |
| --- | --- |
| 守る | 家族のスマホ安全、通信の安心、暮らしの電気 |
| つながる | モバイル、BB、Wi-Fi、家族契約 |
| 未来 | 5G、AI、デジタルサービス、次世代の生活 |
| 親子二世代 | 商業施設のファミリー集客 |
| ヒーロー登場 | 目的来館・撮影会・イベント集客 |

重要なのは、ウルトラマンを「懐かしいIP」として使うのではなく、**通信・家族・暮らし・未来をわかりやすく伝える"体験装置"として使うこと**です。

## 6. ポケモン契約を踏まえた企画の必然性

### 現行ポケモン契約の整理

| 項目 | 現状 |
| --- | --- |
| 契約期間 | 4月〜3月の年度単位 |
| FY26契約費用 | 7,000万円 |
| 利用可能領域 | イベント、BB、でんき |
| ノベルティ | 作成数制限なし。ただし数量に応じた許諾対価が別途必要 |
| 他コンテンツ制限 | なし |
| 着ぐるみ利用 | FY26 3月まで |
| FY27以降 | 契約継続予定。ただし着ぐるみ利用不可 |
| 他IP検討 | ちいかわ、すみっコ、サンリオにアプローチ中 |

### 導かれる論点

1. **ポケモンは継続すべき** — BB・でんき・既存コンテンツ活用において引き続き強力。ファミリー向けIPとしての認知も高い。
2. **ただし、FY27以降はリアル集客機能に空白が生まれる** — 着ぐるみ利用ができなくなることで、商業施設イベントにおける「会いに行く理由」「写真を撮る理由」「親子で参加する理由」が弱まる。
3. **ウルトラマンは、その空白を補完できる** — ヒーロー登場、撮影会、ステージ、館内ミッションラリーと相性が高く、商業施設に人を呼ぶイベントの核になれる。

### IPポートフォリオ上の役割分担

| IP | 役割 |
| --- | --- |
| ポケモン | BB・でんき・既存コンテンツで継続活用 |
| ちいかわ/すみっコ/サンリオ | かわいい系、SNS拡散、女性・低年齢層向け |
| ウルトラマン | 商業施設イベント、親子撮影会、ヒーロー登場、通信・未来・防衛文脈 |

## 7. 企画の中核戦略

**旧来型の店頭施策**:SoftBankショップに来た人へ販促する(=すでに来店意思のある人への施策)

**本企画の店頭イベント戦略**:

```
ウルトラマンを目的に商業施設へ来てもらう
  ↓
館内イベントに参加してもらう
  ↓
SoftBankショップへ送客する
  ↓
スマホ・BB・でんき相談へつなげる
  ↓
見積・予約・申込・後日フォローへ展開する
```

つまり、**店頭で待つ施策ではなく、商業施設に顧客を呼び込む施策**です。ここが高島副社長向けの最重要メッセージです。

## 8. 商業施設との相性

| 商業施設側の課題 | ウルトラマン施策での解決 |
| --- | --- |
| 週末・祝日の集客を増やしたい | ウルトラマン撮影会で目的来館を作る |
| 親子・ファミリー層を呼びたい | 親子二世代に認知がある |
| 館内回遊を増やしたい | ミッションラリーで複数フロアを回遊 |
| 滞在時間を伸ばしたい | ステージ、撮影会、ラリー、相談を組み合わせる |
| テナント全体を盛り上げたい | 館内参加型イベントとして展開できる |
| 天候に左右されたくない | 屋内商業施設イベントと相性が高い |

SoftBankショップ単体でイベントを行うより、商業施設全体を巻き込むことで、**来館動機・館内回遊・店舗送客**を同時に作れます。

### 場所代削減による「実質ゼロ円」ロジック(商談の決め球)

- 商業施設のイベントスペース利用料は**1日50万〜100万円**が標準的な水準。ソフトバンク側の負担は代理店との折半で**1日25万〜50万円**
- 施設側は「来館者が喜ぶ集客企画」に対して場所代を減額する交渉余地を持つ。ファミリー集客企画は最強の交渉材料
- **① 直接効果**:本企画実施施設(10〜20施設×年間80〜160日)の場所代負担が減額対象に(数千万円規模)
- **② 波及効果**:全国数百か所の店頭イベントの場所代交渉の標準材料に → **年間数億円規模**のコスト構造に波及
- **商談での使い方**:「場所代の削減効果がB案1.5億円を上回れば、実質負担ゼロでこの企画ができる」と参考値として提示する。場所代・減額幅は施設との個別交渉によるため、断定はせず"考え方"として見せる

## 10. ユーザー体験設計(生活者導線)

```
① SNS・商業施設告知・SoftBank告知でイベントを知る
② 週末に親子で商業施設へ来館
③ ウルトラマン撮影会・ステージを見る
④ 館内ミッションラリーに参加
⑤ デジタル隊員証を発行
⑥ SoftBankショップで特典・相談導線に接触
⑦ スマホ料金診断、家族契約、BB、でんき相談
⑧ 見積、来店予約、オンライン申込、後日フォロー
```

この導線で重要なのは、**いきなり契約を狙いすぎないこと**です。商業施設イベントでは、まず「来館・参加・相談・見積・予約」を作り、その後、店舗またはオンラインで申込につなげます。

## 12. ミッションラリー設計

企画名:**未来防衛隊ミッションラリー**

**「基本ミッション(SoftBank・固定)」+「拡張ミッション(施設側で追加自由)」の2層設計**とする。根幹はSoftBank相談ミッション(ここをやらないと意味がない)。館内テナントを回遊する拡張ミッションは施設側で自由に追加でき、テナントからの送客協賛も設計可能。施設全体の回遊・売上に貢献するため、場所代交渉の材料にもなる。

### 基本ミッション(SoftBank・固定)

| ミッション | 目的 |
| --- | --- |
| 家族スマホ安全ミッション | 子どもスマホ・見守り・セキュリティ相談 |
| おうちWi-Fi防衛ミッション | SoftBank 光/Air相談 |
| でんき防衛ミッション | でんき契約・電気料金見直し |
| 料金見直しミッション | 家族通信費の診断 |
| ショップ基地ミッション | SoftBankショップへの送客 |
| フォトミッション | ウルトラマン撮影会参加 |
| デジタル隊員証ミッション | 顧客接点の取得 |

### ラリー完了特典

- ウルトラマン未来防衛隊ステッカー
- デジタル壁紙
- 隊員証カード
- クリアファイル
- 店舗相談者限定ノベルティ
- 抽選応募権

ノベルティは、ポケモン契約と同様に、**作成数に上限を設けず、数量に応じた許諾対価を別途支払う設計**にするのが自然です。

### デジタル隊員証の設計(社内MTGで具体化)

| 設計ポイント | 内容 |
| --- | --- |
| 発行フロー | QRからアンケート回答 → その場でオリジナル隊員証**画像**を発行。アプリ開発はしない(画像ダウンロードのみの軽い設計) |
| デザインの出し分け | アンケート結果に応じて隊員証デザインを出し分け → **スタッフが隊員証を見た瞬間に獲得ターゲットか判別できる**(例:他キャリアユーザーは一目で分かるデザイン)。既存SBユーザーにスマホ相談を勧めるムダを排除し、その人に見合ったミッションを割当 |
| ランクアップ演出 | 来場・ミッション達成で隊員ランクが上がる → 再来館動機 |
| 体験への配慮 | アンケートは遊びの中で自然に答えられる設計とし、営業感を出さない(ドコモ施策の反省点:アンケートが営業っぽくなり嫌がられる) |
| 将来拡張 | ポイント連携・アプリ連携・LINE連携は将来オプション(初期スコープ外)。本気で経済圏連携までいけば超大型化の可能性あり |

ソフトバンクはSoftBank、ワイモバイル、LINEMOを複数ブランドとして展開しているため、来館者のニーズに応じて最適な受け皿を用意できます。

## 16. 見積もり3パターン

すべて**税別・概算**です。円谷プロ側の正式なIP使用料、監修条件、ヒーロー稼働条件、使用媒体、使用期間によって変動します。

| プラン | 金額 | 位置づけ | 推奨度 |
| --- | --- | --- | --- |
| A案:短期検証プラン | 3,500万円 | 商業施設イベントの小規模検証 | ○ |
| B案:FY27標準プラン | 1億5,000万円 | 年間展開の本命 | ◎ |
| C案:60周年大型展開プラン | 2億5,000万円 | 全国大型キャンペーン | ○ |

**本命は、B案:1億5,000万円です。**

### 見積の前提と積算の考え方(蓋然性の担保)

| 項目 | 積算の考え方 |

## 24. 高島副社長向けの冒頭説明トーク

> 本日ご提案したいのは、ウルトラマンを広告に起用する企画ではありません。
>
> FY27以降、現在のポケモン契約は継続予定である一方、着ぐるみ活用ができなくなるため、商業施設イベントにおけるリアル集客装置に空白が生まれます。
>
> そこでウルトラマンを、ポケモンの代替ではなく、商業施設に親子・ファミリーを呼び込む店頭イベントの核として位置づけます。
>
> ウルトラヒーローの撮影会、館内ミッションラリー、デジタル隊員証を通じて商業施設へ来館していただき、その来館者をSoftBankショップでのスマホ相談、BB相談、でんき相談へ自然に送客します。
>
> 商業施設にとっては週末集客と館内回遊の施策になり、SoftBankにとっては店舗送客、相談件数、見積、申込につながる。ここが本企画の最大の価値です。
>
> 推奨は、FY27年度の年間活用を前提とした1億5,000万円の標準プランです。

## 25. 決め台詞集

**一番重要な一文**

> 本企画は、SoftBankショップに来た人へ販促する施策ではなく、ウルトラマンを目的に商業施設へ来館した親子・ファミリーを、SoftBankショップ、BB、でんき、モバイル相談へ送客する施策です。

**ポケモン契約を踏まえた一文**

> ポケモン契約はFY27以降も継続予定である一方、着ぐるみ活用ができなくなるため、リアルイベントでの目的来館機能は弱まります。ウルトラマンは、その空白を補完する商業施設送客型IPとして活用できます。

**商業施設向けの一文**

> 商業施設にとっては、ウルトラマン撮影会・館内ラリー・ステージを組み合わせた週末ファミリー集客施策となり、館内回遊と滞在時間向上に貢献します。

**SoftBank向けの一文**

> SoftBankにとっては、来店意向のない親子・ファミリー層を商業施設へ呼び込み、スマホ・BB・でんきの相談接点へ転換する新しい店頭イベントモデルです。

## 27. 企画の最終まとめ(勝ち筋)

```
現行ポケモン契約はFY27以降も継続
  ↓ ただし、着ぐるみは利用不可
  ↓ 商業施設イベントでのリアル集客機能に空白
  ↓ ウルトラマンを"店頭イベントの核"として導入
  ↓ 親子・ファミリーを商業施設へ呼び込む
  ↓ 館内ラリー・撮影会・デジタル隊員証で参加接点を作る
  ↓ SoftBankショップへ送客
  ↓ スマホ・BB・でんき相談へ転換
  ↓ 見積・予約・申込・継続フォローへつなげる
```

**最終的な提案主語**

> ウルトラマンでSoftBankを目立たせる企画ではない。
> ウルトラマンを目的来館の核にして、商業施設に顧客を呼び込み、SoftBankの店頭相談・BB・でんき・モバイル獲得へつなげる企画である。

この形であれば、ポケモン契約との整合、FY27以降の課題、商業施設送客、SoftBankコンシューマ事業への貢献が一本につながります。
