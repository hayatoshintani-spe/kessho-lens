# 制作物の仮申請のご案内(イベントキット・ノベルティ・店頭訴求ツール)

ソフトバンク株式会社 御中/株式会社円谷プロダクション/2026年10月

イベントキット、ノベルティなどの制作物は、当社の申請システムで「仮申請」をいただき、制作の可否を回答します。品目ごとに下記の情報をご用意のうえ、お申し込みください。

## 1. 申請の流れ

| 手順 | 内容 | 時期 |
| --- | --- | --- |
| 1 | 貴社ご担当者の事前登録(貴社名、部署、担当者名)。申請の通知は登録した1名に届くため、窓口のご担当者を1名お決めください | 契約締結後 |
| 2 | 品目ごとに仮申請を登録(入力項目は下記) | 品目が決まり次第 |
| 3 | 当社で権利を確認し、制作可否を回答 | 申請から約1週間 |
| 4 | デザインデータのご提出、当社監修、製造 | 監修は5営業日 |

## 2. 仮申請の入力項目

| 項目 | 記入内容 |
| --- | --- |
| 企画商品名 | 販売物でないことが分かるように「ノベルティ ○○」と記載(例:ノベルティ マグカップ)。会場装飾は「店舗備品 バックバナー」など |
| キャラクター | 使用するキャラクター名。キャンペーンビジュアルを使う場合は「集合ビジュアル」など |
| 商品カテゴリー | ノベルティ(配布物)は1〜16の商品カテゴリーから選択(例:7 文具、8 雑貨、9 生活雑貨)。会場装飾(バックバナー、カットアウトなど)は「20 店舗備品等」 |
| 仮売価(税抜) | 販売物ではないため、予定している製造原価の単価を記載(おおよその金額で結構です) |
| SKU | 品目内のバリエーション数(柄違いなど) |
| 初回合計予定数/年間合計予定数 | 製造予定数量 |
| 使用割合 | 「1/1=100%」のまま |
| 発売予定日/生産開始希望月 | 配布開始の予定日と製造開始の希望月 |
| 材質/サイズ・判型 | 分かる範囲で |
| 性別/年齢層 | 配布対象(通常は「不問」) |
| 画像 | 商品イメージ(JPEG、2MBまで)。この画像では監修は行いません。監修用のデータは別途ご提出ください |
| 流通販路 | 「イベント」にチェック。店頭で配布する場合は「量販」「専門店」なども該当すれば選択 |
| 海外展開想定 | 国内のみのためチェック不要 |
| 企画通信欄 | 配布条件、会場、キャンペーン名などの補足 |

## 3. 記入時のお願い

- ノベルティは「配布物」、バックバナーなどの会場装飾は「店舗備品」として分けて申請してください(どちらも作成許諾の対象です)
- 製造原価の単価と予定数量は、作成許諾ロイヤリティ(作成費用の20%)の計算のもとになります。確定後に変わった場合は企画通信欄または再申請でお知らせください
- 制作できない品目があります(お子様向け玩具、菓子類、ランチボックスなど)。タオルは一般的な仕様でお願いします(ループタオル、ミニタオルは除く)
- キャンペーン名称とキービジュアルが決まってから申請いただくと、権利確認が早く進みます
