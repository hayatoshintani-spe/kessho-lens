# 制作物の仮申請のご案内(イベントキット・ノベルティ・店頭訴求ツール)

ソフトバンク株式会社 御中/株式会社円谷プロダクション/2026年10月

イベントキット・ノベルティ等の制作物は、当社の申請システムによる「仮申請」をもって正式回答(制作可否)をいたします。品目ごとに以下の情報をご用意のうえ、ご申請ください。

## 1. 申請の流れ

| ステップ | 内容 | 目安 |
| --- | --- | --- |
| 1 | 貴社ご担当者様の事前登録(貴社名・部署・担当者名を登録。申請通知はご登録の1名に届くため、窓口のご担当者を1名決めてください) | 契約締結後すぐ |
| 2 | 品目ごとに仮申請を登録(下記の入力項目) | 品目確定の都度 |
| 3 | 当社にて権利確認(約1週間)→制作可否のご回答 | 申請から約1週間 |
| 4 | デザインデータのご提出→当社監修→製造 | 監修は別途ご案内のリードタイム |

## 2. 仮申請の入力項目

| 項目 | ご記入内容 |
| --- | --- |
| 企画商品名 | 販売物でないことが分かるよう「ノベルティ ○○」と記載(例:ノベルティ マグカップ)。店舗装飾物は「店舗備品 バックバナー」等 |
| キャラクター | 使用するキャラクター名(キャンペーンビジュアル使用の場合は「集合ビジュアル」等) |
| 商品カテゴリー | ノベルティ(配布物):1〜16の商品カテゴリーから選択(例:7 文具、8 雑貨、9 生活雑貨)/店舗用装飾物(バックバナー・カットアウト等):「20 店舗備品等」を選択 |
| 仮売価(税抜) | 販売物ではないため、予定製造原価の単価を記載(おおよその目安で可) |
| SKU | 品目内のバリエーション数(柄違い等) |
| 初回合計予定数/年間合計予定数 | 製造予定数量 |
| 使用割合 | 「1/1=100%」のまま変更不要 |
| 発売予定日/生産開始希望月 | 配布開始予定日・製造開始の希望月 |
| 材質/サイズ・判型 | 任意入力(分かる範囲で) |
| 性別/年齢層 | 配布対象(通常は「不問」) |
| 画像 | 商品イメージ(JPEG・2MBまで)※この画像では監修は行いません。監修用データは別途ご提出ください |
| 流通販路 | 「イベント」にチェック(店頭配布の場合は「量販」「専門店」等も該当すれば選択) |
| 海外展開想定 | 国内のみのためチェック不要 |
| 企画通信欄 | 配布条件・会場・キャンペーン名等の補足 |

## 3. ご記入時の留意点

- ノベルティは「配布物」、バックバナー等の会場装飾は「店舗備品」として区別してご申請ください(いずれも作成許諾の対象です)
- 製造原価単価と予定数量は、作成許諾ロイヤリティ(作成費用の20%)の算定基礎となります。確定後の変更は企画通信欄または再申請でご連絡ください
- カテゴリー制限:お子様向け玩具(フィギュア・ソフビ等)・菓子類・ランチボックス等は制作できません。タオルは一般仕様(ループタオル・ミニタオルを除く)でお願いします
- キャンペーン名称・キービジュアルの確定後にご申請いただくと、権利確認がスムーズです
