# ソフトバンク×ウルトラマン案件 全体経緯と現在地(社内共有用/2026年7月17日時点・FY25ノベルティ実績反映)

**取扱注意:ドコモ契約・交渉戦略・原価情報を含むため社外持出厳禁**

## 1. 案件の概要

ソフトバンク株式会社(コンシューマ事業)に対し、ウルトラマンIPの年間ライセンス契約を提案中の案件。ソフトバンクは現在ポケモンを店頭イベント・販促に活用しているが、**FY27以降ポケモンの着ぐるみ活用が契約上できなくなる**ため、その後継となる「店頭集客の核」を探しており、当社ウルトラマンが最有力候補。決裁ラインは高島副社長(コンシューマ事業統括COO)、実務は井上氏ほか。

## 2. 経緯(3つのフェーズ)

**フェーズ1:企画提案期(〜7月上旬)「未来防衛隊キャラバン」**

当初は、当社が企画・制作・イベント運営まで一括で担うフルパッケージ型企画(B案:年間1.5億円)を高島副社長向けに提案。商業施設への送客設計、館内ミッションラリー、デジタル隊員証、「場所代削減で実質負担ゼロ」ロジック等を含む36枚の提案書を円谷フォーマットで作成した。企画自体の反応は良かったが、結果的にソフトバンクの「買い方」と合わないことが判明する。

**フェーズ2:モデル転換期(7/16)ポケモン型ライセンスへ**

ソフトバンクから正式フィードバック資料を受領。要求は「**ポケモンと同じ座組**」=①年間IP使用料(固定)+②着ぐるみは撮影会・グリーティング型で従量+③キット・ノベルティ・訴求ツールはソフトバンク側が制作しロイヤリティを支払う、の3階建て構造。先方の希望水準は「IP使用料1,650万円・着ぐるみ15万円/開催・ロイヤリティ10%」。

これに対し当社は、**アンカー価格(IP使用料2,000万円・着ぐるみ20万円/開催・ロイヤリティ20%)**で見積回答を作成。あわせて譲歩の交換条件表(ラダー)、MG(最低保証)設計、プランA/B二者択一スライド、テスト実施3パターン、統合提案資料(15枚)を整備した。

**フェーズ3:実務者MTG(7/17)条件の実像が判明**

ソフトバンク実務チームとの打ち合わせで多数の新事実を獲得(次章)。宿題として**規模別見積3パターンを7/23までに提出**することになった(資料作成済み)。

## 3. 確定している事実・前提(7/17時点)

- **開催数はコミットではない**:着ぐるみ600開催/キットイベント2万開催は「ポケモン実績のなぞり」。実際の規模は今後の交渉で決まる(半分もあり得るし、単価次第で増やす意向もある)
- **600開催の内訳**:週15開催×4週×10か月。**7・8月はポケモン側の意向で着ぐるみ稼働不可**→ウルトラマンは夏稼働可能で、**最大720開催まで拡張できる。ポケモンに構造的に不可能な差別化**
- 週15はポケモン着ぐるみの在庫30体(往復ローテーション)による上限。物流はIP側委託会社が倉庫・配送・アクター派遣を担う方式
- **着ぐるみは非独占**:女子向けにちいかわ・サンリオ系が入る可能性あり。キット・訴求ツールはポケモンが来年も継続=枠を分け合う。**すみっコぐらし/ポケモン/ウルトラマンの3社分割が有力な見立て**
- **並行IPのライセンス利用料:ちいかわ=1,650万円、すみっコぐらし=1,350万円**(いずれも決定済み)。ソフトバンクが言う「1,650万でないと通らない」の出所はちいかわ。かわいい系・並列枠の相場である
- **ブランド範囲**:SoftBank+Y!mobile+光+でんき。LINEMOは除外、法人向けは対象外
- **キットは800式**(週400稼働×往復の倍持ち)。単価15.5万円/式は数量変動制で固定ではない
- **ノベルティFY25実績を受領(SB岡田氏メール)**:年間合計約569万個(ランチBOX15.5万・マグカップ23.3万・ティッシュ116.4万・シールシート414万)、**作成費約1億8,487万円・ロイヤリティ支払額約1,849万円(10%)・平均約2.1万セット/年**。従来想定(4,000セット・約4,000万円)の約4.6倍の規模
- **SB資料ver1.2で追加の実績・内訳を受領**:①店頭訴求ツールの作成数=年間約23.5万部(ポスター・POP・チラシ等。**作成費の金額は未記載→追加確認要**)②ポケモン15万円の内訳=着ぐるみ1.5万+ディレクター3.5万+アクター2万の**2名体制・ほぼ実費パススルー価格**と判明(→当社単価の防衛は人数でなく演技品質・夏季稼働・開催権で行う。15万を切る提示は当社マージンゼロのため不可)③キット155,470円/式=当社仮定と一致④**SBは既にウルトラマン版のキット・Starlink Direct連動ポスター等のモックを作成済み**=実務は導入前提で稼働中。価格が折り合えば決まる状態で、LOIを急ぐ好機
- **MG(最低保証)にはソフトバンク側も前向き**(井上氏「全然あると思います」)
- **IP使用料は「高い」**というフィードバックが宮園ラインで確認済み
- **今期スポットテスト**:高島副社長案件として年間契約と切り離して実施希望。地域自由・回数ベース・ショー型/撮影会型の2形式。コンテンツ代100万円/回でも成立、来期が大きければ今期分はSB負担の可能性も(井上氏発言)

## 4. 現在提示中の条件と見積(7/23提出予定)

**単価体系(アンカー)**:IP使用料2,000万円/着ぐるみ20万円/開催(土日2日・1日のみ10万円・首都圏外は交通宿泊実費別途)/ロイヤリティ 作成費用の20%(実績実額ベース精算)

**規模別3パターン(年間・税別/FY25ノベルティ実績反映後)**

- 最大(実績同等・全量):着ぐるみ600開催・ノベルティ2.1万セット → 合計**約2.05億円**(③ロイヤリティ約6,480万)
- 半分(50%):300開催・1.05万セット → **約1.12億円**(③約3,240万)
- 3IP分割(約1/3配分):200開催・7,000セット → **約8,200万円**(③約2,170万)

**添えた2つの提案**:①年間最低開催数コミットで着ぐるみ単価優遇(例:400開催以上で17万円)②夏季稼働による最大720開催への拡張

**今期スポットテスト**:S1写真撮影会型100万円/開催、S2ステージショー型150万円/開催(ともに土日2日、IP許諾・監修・スーツ・アクター・輸送込み。会場・集客・運営はSB側)。**5施設程度での実施を想定(S1×5施設=総額500万円・IP使用料不要)**。エリア・施設タイプを分散して比較データを取り、年間契約の配分拡大条項の根拠にする

## 5. 経済性の要点

- 収益は①IP料(ほぼ全額粗利)②着ぐるみ稼働(2名体制原価14万/開催で薄利。ただしポケモン実態はアクター1名+SB社員誘導と判明し、1名体制なら原価約9万に改善)③ロイヤリティ(ほぼ全額粗利・成長ドライバー)の3層
- **FY25ノベルティ実績の受領で率の価値が急上昇**:率15%と20%の差は従来試算の年300〜440万円から、**全量で年約1,620万円/1/3配分でも年約540万円**に拡大。「率は安く譲れる弾」ではなくなった
- ただし着ぐるみ配分の振れ幅(全量↔1/3で年1億円超)が依然最大のため、**守る優先順位:①着ぐるみカテゴリの主力地位(配分・MG)>②IP使用料2,000万>③ロイヤリティ率(価値上昇・譲る場合の対価要求を引き上げ)>④着ぐるみ単価(譲る弾)**
- 数量MGのノベルティ基準も実績ベースへ引き上げ:1/3配分なら**年7,000セット**、単位ロイヤリティ下限は実績単価約8,800円×20%=**約1,760円/セット**(higher-of条項維持)
- **社内シミュレーション(0721R・1/3配分=240現場・契約料1,800万前提)**:円谷利益は最悪ケース(RY10%・単価15万)でも**約3,275万=ドコモ現行(約3,030万)を上回り**、目標ケース(単価20万・RY20%)は**約5,489万=ドコモ比+81%**。切替の経済合理性は全シナリオで成立。また**単価15→20万の差(+1,200万)>率10→20%の差(+1,014万)**であり、交渉の守り順は「単価≧率」。専任バイト採用▲500万の先行投資はMG要求の根拠に使う
- **撮影会レギュレーション(0721版)で単価20万の正当性を確保**:20万=公式レギュレーション定価(使用料4万/日〔メンテ込〕+人件費6万/日〔D3.5万+A2.5万〕)。ポケモン15万との差はスーツ使用料と専門アクター単価であり、マージン上乗せではない——と構造で説明可能に

## 6. 交渉戦略(現在の方針)

- **IP料2,000万の防衛ロジック=「役割差の論法」**:「1,650万円は並列的なIP活用(ちいかわ・すみっコ水準)の相場。同じ役割ならば当社も1,650万円で受ける。着ぐるみイベントの主力(年600開催の開催権)を担うなら開催権込み2,000万円」——先方のベンチマークを肯定しながら差額350万を役割差で説明。ちいかわ・すみっコの名は当方からは出さない
- **率の正当化**:「ポケモンの10%は年2万開催・大量作成前提の特別料率。3IP分割で数量が限定されるなら標準料率15〜20%」(数量ディスカウントの逆論法)。15%は通せる見込み
- **推奨の交渉型**:初回20%を維持→率を突かれたら**15%への譲歩と交換で「着ぐるみMG年400開催+カテゴリ主力地位の明文化+作成物の数量下限」を取る**。譲る価値300〜440万に対し取る価値は数千万で、交換レートが圧倒的に有利
- **想定着地**:IP2,000万+着ぐるみ17万×MG400開催+率15%+数量下限 → ウルトラマン分の年間売上約1.05〜1.2億円、保証床約9,300万円
- **クロージングの2点集中**:①8月中の基本合意(LOI:テスト計画+成功基準達成時の年間移行+優先交渉権)②スポットテスト/先行開発の開始日。金額が紛糾したら「まず①②、金額は並行協議」に切り替える

## 7. リスクと留意点

- **ドコモ契約(競合制限:携帯通信事業、2027年3月31日まで)**:当社はドコモと契約中のため、FY26中のSB店頭実働は原則不可。7/17MTGで「円谷からドコモへ『別の場所でやらせてほしい』と相談に行く」方針をSB側も了承。ただし**協議に行った時点でSBとの交渉がドコモに知られる不可逆な一手**のため、法務確認とSB案件の確度向上(LOI取得)を先行させてから動く。SBと年間契約が固まればドコモは更新しない前提(実質二者択一)
- **ドコモ解約費用は約200万円の想定(社内試算)**:SB年間契約の最小ケース(約8,200万)比で誤差レベルであり、スポットテスト5施設(売上500万・粗利約450万)だけでも回収できる。経済面は切替の障害にならず、論点は関係・レピュテーションと手順のみ。なお200万は現時点の想定値のため、法務確認で違約金・精算条件の正確な把握が必要
- **守秘**:ドコモ契約の存在・条件はSBに開示不可。SBに聞かれた場合の統一回答は「個別の契約はお答えできないが、FY27年度に貴社と組む場合、業種独占的なお取り組みをお約束できる状態」
- **発言整合**:7/17に当方から「ドコモは20%」と発言済みだが、実際のドコモ契約は製造単価の15%。以後の対外説明は「当社標準は15〜20%」で統一する
- **供給体制**:年400〜600開催には着ぐるみ約30体規模+指定アクター制(認定研修)の先行投資が必要。ウルトラマンスーツは視界・動作の制約が大きく育成必須。**この投資額の試算がMG要求の根拠になる**ため早急に算出する
- **未確認事項**:見積の税込/税別、**店頭訴求ツールの年間作成費(金額)**(数量約23.5万部はver1.2で受領済み)。ノベルティ年間実績はFY25分を受領済み
- **火曜締め前の社内整合3点**:①社内シミュレーションの契約料1,800万とSB提示2,000万の関係整理(対外アンカーは2,000万を維持)②1/3配分の分母(社内試算240現場=720ベース vs 提出資料200開催=600ベース)の統一③着ぐるみ実費の範囲(レギュレーションは全案件別途 vs SB見積は首都圏外のみ別途→「首都圏内実費込みは特別条件」と明示する案を推奨)
- **エリアバッティングルール(前8日後5日・半径8km)**:年間600開催では都市部でSB店舗同士が自己バッティングするため、契約に「SB案件は当社一括スケジュール管理・相互適用外」の特則が必要。スポット5施設の会場選定も同ルールで事前チェック(ドコモ実働との距離・日程含む)
