# ソフトバンク案件 体制増強・アクター採用要件資料【社内・キャスティング関係者限定】

2026/10/9 作成:新谷/監修:菅野(ライブチーム)/採用窓口:瓜生

## 1. 背景と採用の目的

- ソフトバンク様との全国店頭イベント(2027年1月開始・2年間)に向け、稼働ラインを現行基準15ラインから**20ラインへ段階増強**する
- 1ラインの現場体制は**7名**(運営ディレクター1・アクター1・専任MC1・キャラクター補助2・運営スタッフ2)
- 増強計画:**第1弾 2027年6月稼働(+2ライン)/第2弾 2027年11月稼働(+3ライン)**
- 稼働は土日中心(月8〜10日)・全国(東名阪+各エリア代理店拠点)

## 2. 必要人員(増強5ライン分の目安)

| 職種 | 必要数 | 備考 |
| --- | --- | --- |
| スーツアクター | 5名+控え | 経験者優先(要件は下記)。各ラインの中核 |
| 運営ディレクター | 5名 | 東京/大阪拠点から配置。安全管理・現地連携 |
| 専任MC | 5名 | キャンペーン口頭告知・列整理。イベントMC経験者 |
| キャラクター補助 | 10名 | 未経験者の入口ポジション(育成枠を兼ねる) |
| 運営スタッフ | 10名 | 設営・誘導・物販補助 |

既存12社の代理店ネットワーク(無限・キャップス東京/関西/北海道・シーズ大阪/九州・森次プレーン・FF・Dエモ・アクトレイ・S琉球ライブ ほか)からの出向・紹介を併用する。

## 3. スーツアクターの採用要件(菅野基準)

**必須条件**

- 身長170〜180cm・標準体型(ヒーロースーツに入れること。身長は高い方が望ましい)
- スーツアクトの練習・経験のある方
- キャラクターのポージングができる方(撮影会は写真に残り、SNSにも投稿されるため)
- ある程度のお芝居ができる方
- 閉所恐怖症でない方(スーツは自力で脱げないため、パニックにならないことが必須)

**留意事項**

- ウルトラマンのスーツは特殊なため、一定の経験が必要。未経験者を撮影会ヒーローに直接充てることはできない
- 稼働は1回30分(移動含む)×1日3〜4回が基本。スーツメンテ時間を確保した運用

## 4. 育成ラダー(標準キャリアパス)

ステージショーの怪獣 → 複数ヒーローがいる撮影会 → 1体の撮影会 → ステージショーのヒーロー

- SB案件の中心は3段目「1体の撮影会」。**即戦力=2段目以上の経験者**が採用ターゲット
- 未経験者はキャラクター補助または怪獣役で採用し、複数ヒーロー撮影会をOJTの場として育成
- 育成が進んだ既存アクターをSB専属に振り替え、新人を既存案件に充てる「玉突き方式」で全体を底上げする

## 5. 採用スケジュール(逆算)

| 時期 | マイルストーン |
| --- | --- |
| 2026年11月 | 募集要項確定・代理店へ募集依頼開始(経験者ルート優先) |
| 2026年12月〜2027年2月 | 第1弾採用・契約(経験者+2ライン分) |
| 2027年3月〜5月 | 研修・スーツ合わせ・現場OJT(テスト会場・既存案件で実地) |
| 2027年6月 | 第1弾稼働開始(+2ライン) |
| 2027年5月〜7月 | 第2弾採用(+3ライン分) |
| 2027年8月〜10月 | 第2弾研修・OJT |
| 2027年11月 | 第2弾稼働開始(=20ライン体制完成) |

※採用から稼働まで最低3ヶ月。経験者確保が遅れる場合は代理店スポット稼働でブリッジする。

## 6. 条件・その他

- 報酬・契約形態:別途規定(代理店経由/直接契約で異なる。菅野・瓜生ラインで設計中。宿泊・交通費条件は菅野さんから共有予定の概算条件に準拠)
- 勤務地:首都圏・関西・東海を中心に全国(エリアは代理店拠点に準ずる)
- 本資料の要件は募集要項・代理店依頼文のベースとして使用可。**ソフトバンク様の社名を含む案件情報は採用活動では伏せ、「大手企業の全国店頭イベント」等の表現とすること**(契約前の案件情報につき取扱注意)
