# 視界に、ヒーローを。

## ULTRAMAN × Rokid Glasses 共同プロモーション提案書

- **提案先**: Rokid 社 / フューチャーモデル株式会社（日本総代理店）
- **提案元**: 円谷プロダクション ライセンス事業部
- **作成日**: 2026-07-23
- **ステータス**: 提案先提示用ドラフト（社内承認前）

---

## 0. 最初に、ひとつの事実を

1967年、ウルトラセブンはメガネ型のデバイス「ウルトラアイ」を装着して変身しました。

**「グラスをかけると、世界が変わり、自分が変わる」——
この物語を60年前から持っているIPは、世界でウルトラマンだけです。**

2026年、Rokid Glasses をかけた人の視界で、それが現実になります。
これは単なるキャラクターコラボではなく、**Rokid Glasses という製品体験そのものに
「変身」という物語を与える**提案です。

> 想定キーコピー: **「変身は、現実になった。」**

---

## 1. Rokid の現在地（私たちの理解）

| 獲得済み | これからの課題 |
|---|---|
| Makuake 歴代応援購入額1位という話題性 | 早期採用層の外側に届く「物語」 |
| 全国約75店舗+5都市ポップアップの販路 | 店頭で足を止めさせ、装着させる引力 |
| 翻訳・AIメモ・ナビという機能的説得力 | 「毎日かけたい」と思わせる情動的理由 |
| 109,890円に見合うスペック | 年末商戦、競合スマートグラス攻勢前の差別化 |

機能の戦いはすでに勝ちつつある。次に必要なのは、**かける理由の物語化**です。
そこにウルトラマンほど構造的に噛み合うIPはありません。

---

## 2. なぜ、ウルトラマンなのか

### 理由1: 「装着して変身する」物語を持つ唯一のIP

ウルトラアイ（1967年〜）以来、ウルトラマンにとって「アイウェアの装着」は
変身の起点です。Rokid Glasses の装着動作そのものがブランドストーリーになる。
広告は説明不要で成立します——**「さあ、変身してください」**。

### 理由2: 購買層とファン層の完全一致

Rokid の中核購買層＝ガジェット感度の高い30〜50代。これはウルトラマンを
リアルタイムで浴びて育ち、いま自分の裁量で10万円のガジェットを買える世代です。
さらにウルトラマンは親子2世代・3世代IP。購入者の家族へ体験が波及します。

### 理由3: 製品機能のすべてにIP文脈を与えられる

| Rokid Glasses の機能 | ウルトラマン文脈 |
|---|---|
| 通知・ステータス表示 | **カラータイマー**（残量・通知が点滅と音で分かる） |
| 12MPカメラ撮影 | **光線ポーズ撮影**（スペシウム光線エフェクト合成→SNS共有） |
| ARナビ | **防衛隊HUDモード**（科特隊風UIスキン） |
| 空間ディスプレイ | **巨大ウルトラマン召喚**（都市スケールの空間演出） |

機能デモがそのまま感情体験になる。「翻訳できます」より「変身できます」が、
店頭で人を立ち止まらせます。

### 理由4: Rokid のホーム市場・中国での圧倒的地盤

ウルトラマンは中国で世代を超えた国民的人気を持つIPです。日本コラボの成功は
そのまま Rokid 本国市場・グローバル販路への展開シナリオに接続できます。
日本は「世界展開の第1話」です。

### 理由5: 円谷プロが監修とアセットで本気で組む

キャラクター表現の品質は円谷が公式監修で担保し、既存3Dアセットを供与します。
「本物のウルトラマン」であることが、ファンに対する最大の品質保証です。

---

## 3. なぜ、今なのか

### 理由1: 2026年はウルトラマンシリーズ60周年イヤー

- 60周年プロジェクトが2025年7月から約2年半にわたり進行中
- 記念新シリーズ『ウルトラマンティオ』が2026年7月4日から世界同時展開で放送中
- 「ULTRAMAN EXHIBITION -ウルトラマンシリーズ60周年展-」が2026年4月から
  大阪を皮切りに福岡・神奈川ほか全国巡回中

つまり今年は、**メディア露出とファンの熱量が60年間で最大化している年**です。
この波に乗れる外部パートナー枠は限られており、60周年の公式文脈に
テクノロジーパートナーとして入れるのは今年だけです。

### 理由2: 7月10日という「運命の一致」

Rokid Glasses の日本発売日・7月10日は、**「ウルトラマンの日」**
（1966年7月10日、ウルトラマンが初めてテレビに登場した日）と同日です。
この偶然を必然に変え、**毎年7月10日を「変身の日」として更新し続ける**
記念日マーケティングを設計できます。単発コラボではなく、恒例行事になります。

### 理由3: 「ARグラスの最初のIP体験」を定義できるのは一度だけ

ARグラス市場は機能訴求から体験訴求へ移る直前にあります。
スマートフォンにおけるキラーコンテンツがそうだったように、
**カテゴリ最初の代表的IP体験を作ったブランドが、以後数年の連想を独占します。**
「ARグラスで変身する」をウルトラマン×Rokidが最初に定義すれば、
後発のどの組み合わせも二番手の模倣になります。年末商戦の前、今が最後の窓です。

## 4. 提案プラン

### Plan S 「SPARK」 — 3,000万円（税別）

**デジタル体験と店頭の熱量に集中するプラン**

| 項目 | 内容 |
|---|---|
| AR体験パック「ULTRAMAN MODE」 | 光線ポーズ撮影（SNS共有導線付き）/ カラータイマー通知 / 防衛隊HUDナビスキン。円谷が監修・3Dアセット供与 |
| 店頭・ポップアップ | 全国5都市ポップアップに「変身体験コーナー」併設（等身大ウルトラマンAR+記念撮影） |
| 記念日PR | 7月10日「ウルトラマンの日」共同プレスリリース・SNS相互露出 |
| 許諾範囲 | プロモーション使用+デジタルコンテンツ、日本国内、12ヶ月 |

**期待効果（初年度目安)**: 店頭・イベント体験10万人 / 光線撮影UGC 1万件 /
メディア露出換算 2〜3億円

### Plan U 「ULTRAMAN EDITION」 — 8,000万円（税別）

**ハード限定モデルと60周年公式文脈まで含むフルパッケージ**

Plan S のすべてに加えて:

| 項目 | 内容 |
|---|---|
| 限定コラボモデル | 「Rokid Glasses ULTRAMAN EDITION」3,000台。シルバー×レッド意匠 / カラータイマー型充電ケース / 変身音起動 / シリアルNo. / 60周年記念ロゴ。商品化ライセンス+意匠監修込み |
| 60周年公式連携 | ULTRAMAN EXHIBITION（全国巡回中）への体験ブース出展枠 / 60周年公式サイト・SNSでの告知連携 ※ |
| 巨大召喚デモ | 展示・イベント会場での巨大ウルトラマン召喚体験（管理環境での高負荷演出） |
| 広告使用 | TVCM・店頭販促物へのキャラクター使用許諾 |
| 放送連動 | 新シリーズ『ウルトラマンティオ』放送期間中のタイアップ告知枠 ※ |
| グローバル | 中国・北米・欧州の Rokid 販路への展開優先交渉権 |

**期待効果（初年度目安)**: 限定モデル3,000台完売（小売規模 約3.3億円）/
60周年展来場者への直接装着体験 / メディア露出換算 5億円以上

※ 60周年イベント・番組連動の実施形態は円谷社内の企画枠調整を経て確定します。

### 対価に含まれるもの / 含まれないもの

- **含む**: キャラクター使用許諾（上記範囲）、円谷公式監修、3Dアセット供与、共同PR
- **含まない**: デバイス製造原価、アプリ実装費（Rokid側負担。実装は円谷推薦の制作パートナー紹介可）
- 限定モデル・体験パック課金の売上ロイヤリティは別途協議（MG充当方式も可）

## 6. 結びに

かつてウルトラアイを装着したかった少年たちは、いま、購買決定者になりました。
その手に10万円のARグラスを取らせる最後のひと押しは、スペックの数字ではなく、
**60年間待った「変身」の実現**です。

Rokid には日本で最も勢いのあるデバイスがあり、円谷には視界に宿る60年のヒーローがいる。
この組み合わせが成立するのは、60周年と発売元年が重なった2026年だけです。

**7月10日生まれ同士、一緒に歴史を作りましょう。**
