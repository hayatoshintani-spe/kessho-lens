# 提案書: Rokid（ロキッド）プロモーションにおけるウルトラマンIP活用

- **作成日**: 2026-07-22
- **提案元**: 経営企画（Tsuburaya Intelligence Brief 起案）
- **提案先**: IP戦略・ライセンス事業部 / Rokid 社（日本総代理店: フューチャーモデル株式会社）
- **ステータス**: ドラフト（社内検討用）

---

## 1. エグゼクティブサマリー

AI×ARスマートグラス「Rokid スマートAIグラス」は 2026年7月10日に日本で一般販売が開始され、
先行の Makuake 先行販売では同プラットフォームの歴代応援購入額 1 位を記録した、いま日本市場で
最も勢いのあるスマートグラスである。

本提案は、Rokid の日本市場プロモーションに **ウルトラマンIPをライセンス供与し、
「限定コラボモデル × AR体験コンテンツ × 店頭体験」の三層で展開する**ものである。

- 円谷側の狙い: **「ARグラス時代に最初に体験されるIP」のポジション獲得**と新規ライセンス収入
- Rokid 側の狙い: 認知拡大（特に30〜50代男性のガジェット層＝ウルトラマン世代）と「買う理由」の創出
- 投資規模: 小（監修工数＋既存アセット活用中心）。デバイス開発は Rokid 側負担

社内 Watchlist でも「ARグラス各社＝次世代IP体験の媒体」として監視中であり、
IntelCard の示唆（「価格しきい値の低下により、どのIPがARで体験設計を作るかの競争が始まる。
先行事例づくりは比較的安価で可能」）に対する具体的な打ち手となる。

## 2. 背景・市場環境

### 2.1 Rokid の現状

| 項目 | 内容 |
|---|---|
| 製品 | Rokid スマートAIグラス（約49g、両眼 Micro LED、12MPカメラ） |
| 日本発売 | 2026年7月10日 一般販売開始、価格 109,890円 |
| 先行実績 | Makuake 応援購入額 歴代1位（2026年2月〜先行販売） |
| 販路 | Amazon・楽天 + ビックカメラ・ヨドバシ等 全国約75店舗 |
| プロモーション | 全国5都市で体験ポップアップを展開中 |
| 機能 | リアルタイム翻訳、AI検索、AR ナビ、動画撮影、空間ディスプレイ |

デバイスとしての機能訴求は既に立ち上がっている一方、**「毎日かけたくなる情動的な理由」
「店頭で足を止めさせるコンテンツ」**が次の課題であり、ここがIPの出番である。

### 2.2 円谷側の戦略的文脈

- ARグラスは普及前夜から本格化フェーズへ移行中（IntelCard: device_telecom）。
  IP各社の「AR上の体験設計」競争が始まる前に先行事例を作る価値が大きい。
- ウルトラマンの中核モチーフ（変身、カラータイマー、スペシウム光線、巨大化、防衛隊ガジェット）は
  いずれも「**視界に重なる**」AR表現と極めて相性が良い。
- 主要購買層（30〜50代男性ガジェット層）とウルトラマン世代が重なり、ターゲット効率が高い。

## 3. 提案施策（三層構成）

### 施策A: ウルトラマン限定コラボモデル（ハード）

- 本体カラー/テンプルにウルトラマンモチーフ（シルバー×レッド配色、カラータイマー意匠）
- 充電ケースを「変身アイテム/科特隊ガジェット」風の特別デザインに
- 起動音・起動アニメーションに変身音/カラータイマー音を採用
- 数量限定・シリアルナンバー入りで、コレクターズ需要と話題性を確保

### 施策B: AR体験コンテンツ「ウルトラマンと目が合う」（ソフト）

グラス購入者向け公式アプリ内のコラボ体験パック:

1. **等身大/巨大ウルトラマン召喚** — 街や部屋にウルトラマンが立つ。巨大化スケール切替で「怪獣目線」を体験
2. **カラータイマー通知** — バッテリー残量・通知をカラータイマーの点滅とサウンドで表現する常用機能
3. **変身フィルター/光線撮影** — 12MPカメラで、スペシウム光線ポーズに光線エフェクトを合成して撮影・SNS共有
4. **AR ナビ「防衛隊モード」** — 既存ARナビのスキンとして、防衛隊HUD風UIを提供

※ 3 の撮影・SNS共有機能が UGC を生み、プロモーションの拡散装置になる。

### 施策C: 店頭・ポップアップ体験（場）

- 展開中の全国5都市ポップアップに「ウルトラマン体験コーナー」を併設
- 体験のフィナーレで巨大ウルトラマンが登場する 90 秒デモを標準化（購入転換の山場を設計）
- 家電量販店75店舗の店頭デモ機に施策Bの体験パックをプリインストール
- 7月10日=「ウルトラマンの日」と発売日が同日である点を毎年のコラボ記念日として訴求

## 4. 事業スキーム（案)

| 項目 | 内容 |
|---|---|
| 契約形態 | 商品化ライセンス（施策A）+ デジタルコンテンツライセンス（施策B）+ プロモーション使用許諾（施策C） |
| 対価 | ミニマムギャランティ + 限定モデル販売数・体験パック課金のロイヤリティ |
| 監修 | 円谷側でキャラクター表現・音声・造形を監修（既存3Dアセットの転用で工数圧縮） |
| 地域 | 第一段階は日本国内。成果次第で Rokid のグローバル販路（中国・北米・欧州）へ拡張オプション |
| 期間 | 12ヶ月（限定モデル1回 + 体験パック常設）+ 更新オプション |

## 5. KPI（初年度目標の目安）

- 限定コラボモデル: 完売（想定 3,000〜5,000台規模、Rokid と要協議）
- 体験パックDL率: グラス購入者の 30%以上
- UGC: 光線撮影コンテンツのSNS投稿 1万件
- 店頭体験: ポップアップ+店頭デモで 10万人接触
- 円谷側: ライセンス収入に加え、「ARグラス×IP」の先行事例・体験設計ノウハウの獲得

---

## 6. リスクと対応

| リスク | 対応 |
|---|---|
| キャラクター表現の品質（AR上の造形・動き） | 円谷監修を契約に明記。既存の高品質3Dアセットを支給 |
| 中国本社企業との協業に伴う地政学・データ取り扱い懸念 | 契約主体・データ管理は日本法人/総代理店経由とし、コラボ範囲をコンテンツ・意匠に限定 |
| デバイス販売不振によるブランド毀損 | ミニマムギャランティで下限を確保。限定数量でリスクを限定 |
| 他IPとの競合（先行者優位の喪失） | ARグラスカテゴリでの一定期間の独占条項を検討 |
| 過去コラボ実績の有無（中国市場での既存契約関係） | Rokid 社の既存IP契約状況をデューデリで確認（要調査） |

## 7. 次アクション

1. **ライセンス事業部**: フューチャーモデル株式会社（日本総代理店）経由で Rokid 社へ初回打診（〜8月上旬）
2. **IP戦略**: ARグラスカテゴリにおけるIP独占条項の要否・条件を整理
3. **経営企画**: 中国本社との契約スキームに関する法務・地政学リスクの事前確認
4. **コンテンツ部門**: 既存3Dアセットの AR 転用可否と監修工数の見積り
5. 成立時は年末商戦（11月）での限定モデル発表を逆算したスケジュールを策定
