次のテーマの経営論点を整理せよ: $ARGUMENTS

手順:
1. `advisory/knowledge/my-mandate.md` `company-profile.md` を読み文脈を把握。
2. テーマを「答えを出すべき1つの問い」に言語化する。
3. `advisory/templates/issue-map.md` の型に沿って:
   - 論点をMECEに分解（イシューツリー）
   - 事実 / 仮説 / 未確認 を明確に切り分ける
   - 暫定の結論（筋の良い仮説）と確信度（高/中/低）
   - 次に潰すべき最重要の不確実性 TOP3
4. 領域が特定できる場合は該当参謀（ip-strategist / d2c-crm-strategist / cfo-analyst 等）の視点も取り込む。
5. `advisory/02_issues/YYYY-MM-DD-<テーマ短縮>.md` に保存。

抽象論を避け、次のアクションが決まる粒度まで具体化せよ。
