# 最初の7日間 実装＆立ち上げ計画

参謀本部を「明日から動く」状態にするための7日間。各日60〜90分を想定。
目的は完璧なナレッジではなく、**回るループ**を作ること。走りながら埋める。

---

## Day 1（月）— 環境と自己定義
**ゴール: `/morning-brief` が動き、自分の立ち位置が言語化されている。**
- [ ] Claude Code を kessho-lens リポジトリで起動できることを確認。
- [ ] `advisory/knowledge/my-mandate.md` を埋める（ミッション/KPI/持論/90日計画/最重要論点TOP3）。← **最優先。ここだけは今日必ず。**
- [ ] MCP連携を確認：Google Calendar と Gmail が Claude Code から見えるか（`/morning-brief` を試打ちして予定・メールを拾えるか）。
- [ ] `/morning-brief` を1回実行し、出力を見て違和感を `my-mandate.md` に反映。
- 成果物: 埋まった `my-mandate.md`、初回ブリーフ `01_daily-brief/`。

## Day 2（火）— 会社と数字の地図
**ゴール: 自社の事実ベースができる。**
- [ ] `/finance-check 自社の直近決算とセグメント収益性` を実行。決算短信・有報を一次情報で当てさせ、`company-profile.md` の「要確認」を「確定」に昇格。
- [ ] 証券コード・売上・営業利益・ROE・セグメント構成・中計目標を埋める。
- [ ] 分からない数字は「要確認＋誰に聞くか」を残す（空欄のままにしない）。
- 成果物: 数値が入った `company-profile.md`、`07_finance/` に初回分析。

## Day 3（水）— IPと競合の地図
**ゴール: ウルトラマンIPの資産と、比較相手が定まる。**
- [ ] `advisory/knowledge/ultraman-ip.md` の「要確認リスト」に着手（現行ライセンシー/グローバル権利/既存D2C基盤の有無）。分かる範囲で埋め、残りは宿題化。
- [ ] `/ip-strategy ウルトラマンIPの最大の未活用資産はどこか` を実行し、初期仮説を得る。
- [ ] `/finance-check 競合4社（バンナム/サンリオ/東映アニメ/ポケモン）のROE・利益率比較` で `competitors.md` に比較表。
- 成果物: `03_ip-strategy/` に初期仮説、`competitors.md` の比較表。

## Day 4（木）— キーパーソンと組織
**ゴール: 「誰に・どう」動くかの地図。**
- [ ] `advisory/knowledge/stakeholders.md` を埋める（会長/社長/役員の関心・地雷・効くメモの型。分かる範囲で）。
- [ ] `/org-review 私の担当領域（IP開発/D2C/体験/CRM/B2B/営業開発）を成果に繋げる組織の初期論点` を実行。
- [ ] 「最初の90日で握るべきキーパーソンTOP5」を洗い出し `my-mandate.md` に追記。
- 成果物: 初稿の `stakeholders.md`、`08_org-talent/` に組織論点。

## Day 5（金）— 実戦：論点整理と案件評価
**ゴール: 実際の案件で参謀を使い倒す。**
- [ ] 今抱えている実際のテーマで `/issue-map <テーマ>` を実行。
- [ ] 検討中の案件があれば `/deal-eval <案件>`（red-team込み）を実行。撤退基準まで出させる。
- [ ] 出た判断を `/decision-log` で1件記録してみる（ループの完成）。
- 成果物: `02_issues/` `06_bizdev-deals/` `10_decision-log/` に実データ1件ずつ。

## Day 6（土）— 実戦：提案とメモ
**ゴール: アウトプットが役員/社外に出せる品質か検証。**
- [ ] `/proposal ソフトバンク <狙い>` を試作（相手の最新戦略をWebで拾わせる）。
- [ ] Day5の分析を `/board-memo 社長 <テーマ>` で1枚に清書。stakeholders.md が効くか確認。
- [ ] 出力品質を見て、テンプレ（`templates/`）を自分好みに微修正。
- 成果物: `05_b2b-proposals/` `09_board-memos/` に試作、調整済みテンプレ。

## Day 7（日）— 運用設計と自動化
**ゴール: 明日以降、勝手に回る仕組みにする。**
- [ ] 1週間使って合わなかった参謀プロンプト/コマンドを修正（`.claude/` を編集）。
- [ ] 毎朝ブリーフの運用時間を決める（例：出社前7:30に `/morning-brief`）。
- [ ] （任意）毎朝の自動化：既存の GitHub Actions `daily-brief.yml` の仕組みに倣うか、Claude Code の cron/loop で定時実行を検討。
- [ ] `my-mandate.md` の「最重要論点TOP3」を最新化。来週の重点を決める。
- [ ] ここまでの成果を git にコミット（機密が混じっていないか確認してから）。
- 成果物: 自分仕様に調整された参謀本部、来週の重点。

---

## 7日終了時のチェックリスト
- [ ] `my-mandate.md` `company-profile.md` `ultraman-ip.md` `competitors.md` `stakeholders.md` が（不完全でも）埋まっている
- [ ] 9コマンドすべてを1回は実行した
- [ ] 毎朝 `/morning-brief` を回す習慣の入り口ができた
- [ ] 意思決定ログに最低1件ある
- [ ] 「これは使える／使えない」の感触を得て、プロンプトを1回は自分で直した
