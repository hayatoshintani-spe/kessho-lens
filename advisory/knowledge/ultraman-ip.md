# Ultraman IP — 資産マップと成長仮説

> IP戦略参謀 (ip-strategist) の一次参照。IPを「作品」ではなく「収益化可能な資産の束」として捉える。

## IP資産の構造（棚卸し）
- **キャラクター資産**: 初代ウルトラマン〜令和シリーズ、ウルトラ怪獣。多世代性が最大の武器。
- **世界観/ナラティブ資産**: M78星雲、光の国、防衛隊 等。拡張・再解釈の余地。
- **映像アーカイブ**: 過去作の膨大なライブラリ（配信・リマスター・二次利用）。
- **商標/意匠/肖像**: グローバル権利関係（特に中国圏の権利history は要確認・要注意）。
- **ファンダム**: 多世代（親子3世代）。ここをD2C/CRMで直接資産化できているか？ → 初期仮説では未活用。

## 収益化の面（どこで稼ぐか）
| 面 | 現状（仮説） | 伸びしろ | 担当領域 |
|---|---|---|---|
| ライセンスアウト（玩具/アパレル/食品） | 主力 | 面の拡張より単価/直販化 | B2B |
| 映像/配信 | 中 | グローバル配信・共同製作 | IP |
| D2C（EC/会員/コレクタブル） | 低（要確認） | **最重要成長領域** | D2C/CRM |

| ゲーム/アプリ | 要確認 | IPコラボ・自社タイトル | BizDev |
| グローバル（北米/東南アジア/中華圏） | 地域偏在 | 市場別戦略 | IP/BizDev |

## 成長戦略の柱（初期仮説 — 検証対象）
1. **ファン直結（D2C+CRM）**: ライセンシー経由でしか会えないファンに、自社で直接会い、LTVを測る/伸ばす。
2. **多世代のライフタイム設計**: 子ども向け玩具 → 大人向けコレクタブル/体験へ、年齢に沿った商品階段。
3. **グローバル×共同製作**: 単発ライセンスでなく、地域パートナーとの継続的座組。
4. **他IP/大企業とのコラボ**: ソフトバンク等の顧客基盤・技術（AI/通信/XR）とIPを掛ける。

## リスク/論点
- 権利の複雑さ（過去の海外ライセンス係争history）→ 案件ごとに権利クリアランス確認。
- IP毀損リスク（安売り/世界観崩壊）とマネタイズのバランス。
- パチンコ用途への依存度と、脱却時の収益ギャップ。
