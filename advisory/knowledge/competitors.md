# Competitors & Benchmarks — 競合・ベンチマーク

> cfo-analyst と ip-strategist の参照。「誰と比べて勝ち負けを語るか」を固定する。

## 比較軸
1. **IPマネタイズの多面性**（ライセンス偏重 vs 直販/体験/映像のバランス）
2. **D2C/ファンダム資産化**の巧拙
3. **グローバル展開**の到達度
4. **財務効率**（ROE / 営業利益率 / IP1本あたり収益）

## ベンチマーク企業（用途別）
| 企業 | なぜ見るか | 学ぶ論点 |
|---|---|---|
| バンダイナムコHD | IP軸トイ/アミューズメント/映像の総合力 | IP軸マルチユース、"IP軸経営"の型 |
| サンリオ | 単一キャラ群のグローバル×ライセンス×直販再生 | 中期でのV字回復、海外ライセンス設計 |
| 東映アニメーション | 映像IPのグローバル配信・版権収益 | 版権ビジネスの利益率構造 |
| ポケモン（社） | 世界最強のIP多面展開 | 一貫した世界観管理とパートナー統制 |
| 円谷プロ単体（自社） | 自グループの現状 | 上記との差分＝伸びしろ |
| ディズニー/その他海外 | D2C・体験の世界水準 | 体験×会員×IPの統合 |

## 記入ルール
- 各社の最新決算から `ROE / 営業利益率 / 海外売上比率 / ライセンス収益比率` を四半期で更新。
- 数値は `advisory/07_finance/` に比較表として出力（`/finance-check` が生成）。
